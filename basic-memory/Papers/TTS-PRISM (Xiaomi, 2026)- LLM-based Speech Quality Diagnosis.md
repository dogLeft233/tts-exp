# TTS-PRISM (Xiaomi, 2026): LLM-based Speech Quality Diagnosis

arXiv 2604.22225。前沿中文 TTS 诊断框架,项目的方法论参照/论文定位论据。

用 MiMo-Audio 骨干 + LLM rationale+score 打分范式,完全不用强制对齐、逐音素或 SSL 帧级分析。项目基于 HuBERT/XLS-R + MFA 的帧级可分离性方法在其中占据差异化、互补的生态位。
