# 模型感知自然音频路由与无损换轨资格验证

## Summary

本实验把两轮 explicit11 候选与独立 holdout 结果收敛为一个可执行的模型感知路由：MuseTalk 保留反对称局部功率/谱形候选，Wav2Lip、Ditto 和未知模型使用固定 RMS，并在候选运行失败时安全回退。

## Protocol

输入保持 16 kHz、单声道、原始样本数和原始时钟。增强 WAV 只送入 TFG renderer；SyncNet 评分与最终成片换轨使用未修改的自然 PCM。holdout 使用 10 个未见 AISHELL 说话人、25 fps、Wav2Lip/MuseTalk/Ditto，各自 candidate 与 RMS 对照。主计划与 Ditto 修复计划分开绑定：主 plan SHA 007495aa3b4cf1fc9b20f506c33593da8bb95e54ea1e0914ac56f3d9a21cad3b，Ditto plan SHA c71e47e7acc2eb2ec92062b6fc0d4c882c96309af2ff770ef40db7a5144213a5。

## Results

- Wav2Lip 20/20 PASS，candidate−RMS full -0.008916、guard20 -0.005989；路由选择 RMS。
- MuseTalk 20/20 PASS，candidate−RMS full +0.014064、guard20 +0.025367；路由保留 explicit11 候选。
- Ditto 修复 run 20/20 PASS，candidate−RMS full/guard20 0.000000；路由选择 RMS。
- 三模型等权路由贡献约 full +0.004688、guard20 +0.008456。

## Boundary

当前交付是安全路由原型，不是单一 candidate 对所有 TFG 都超过 RMS 的统一增强头。实测泛化边界是 10 个未见 AISHELL 说话人、静态 portrait、25 fps、16 kHz mono 和三个固定 model IDs；未知模型只有 RMS fail-closed 契约。shared_audio_head.pt 仍为 FIT_ONLY_COMPLETE research-only，尚未打开 Dev/Confirm，也未接入生产路由。
