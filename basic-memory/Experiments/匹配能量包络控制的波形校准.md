## Observations
- [status] concluded
- [result] v2 calibration_passed；ENVmatched .8/1.2目标包络dB RMSE中位0.01643/0.01821，最大0.2462/0.3376，104/104控制≤.75；R RMS绝对相对变化中位0.688%/0.877%，低于冻结2%门。
- [validation] 3项新增契约测试通过；独立log-gain实现复算104控制/312波形，保存float32最大误差1.49e−8；v1的640项artifact hash完全不变。
- [protocol] 20次sqrt(Ey/Eu)半步更新，sample-level periodic Hann512 reflect包络；中间gain±12dB裁剪后恢复原RMS；N/T×6条件共同headroom，本批g全部1。
- [coupling] ENV控制的矩形包络轨迹近似目标，F0共同有声音分绝对差中位0.258/0.247，voicing判断变化1.440%/1.285%；不能称纯能量真值。
- [result] 算术幅度谱定义20log10(mean_time(abs(STFT)))，v1原RMSE未去全频常数：R .8/1.2为1.520/1.720dB，去常数后0.818/0.822；ENV为1.167/1.069，去常数后0.514/0.402。
- [result] mean-log谱定义mean_time(20log10(floored_abs_STFT))：R .8/1.2原RMSE2.144/2.141dB，常数位移+2.047/−2.001，去常数RMSE0.583/0.737；ENV原RMSE0.489/0.602，去常数0.247/0.286。
- [conclusion] 能量包络匹配且R变化较小的控制已就绪，可供root决定后续G×E；未评分，未识别声学原因，长期谱与F0耦合仍须保留。无v3。
