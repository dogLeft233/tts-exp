# 共同 T 总长残差的逐查询音类与边界定位 2026-09-28

|:--|:--|:--|

## 问题与设计

复用已封存的原 FIXED 均匀语速母实验，研究共同 T 总长下 R_T=C(T_ID)−C(N_WARP) 的背景 B 与最优距离 D 如何分布在不同 MFA 发声覆盖、音类和边界窗口。两项都是各自生成视频与本源音频的自配分数；74 eval 全保留，主支持是旧 common71、15 位说话人、raw/guard20，另外 3 对旧 guard20 结构性空支持单列。无新 GPU、音频或视频。

B 的定义是先逐查询平均 31 条 lag 曲线再取中位数。本诊断先冻结每段/每臂全句中位 lag（31 项第 16 个值，平值取原 lag 首项）与最低距离 lag，再按相同查询分摊 B/D/C 和固定 lag3 anchor；不得按类别自行重取中位 lag。四种共同发声状态直接在同一物理时间 RF 内积分 T 与名义 N 的 MFA 标记；另保留完整 64 种音类对、边界与转移类别。N 原 MFA 区间按 nT/nN 缩放，属于名义 N_WARP 时间，并未测得 Rubber Band 后真实音素边界。

## 结果

15 人等权、20,000 次 PCG64 配对 bootstrap，99%CI。主 raw B +0.189 [0.066,0.286]、D +0.025 [−0.099,0.158]、C +0.164 [0.003,0.316]；固定 anchor C +0.191 [0.012,0.365]。unit B +0.004 [−0.013,0.022]、D −0.014 [−0.031,0.003]、C +0.018 [−0.004,0.042]。raw R_T 主要呈 B 差，但 D 与多数类别区间跨零，不能声称局部匹配变差或音素类别因果作用。主输入 T 已知 speech 占时 0.867，名义 N 0.740；同总长不等于发声覆盖相同。

四个共同 RF 状态的 raw 占时 / B 总贡献 / C 总贡献：双方 speech 0.865/+0.104/+0.126；仅 T speech 0.077/+0.057/−0.026；仅名义 N speech 0.038/−0.017/+0.021；双方非 speech 0.020/+0.045/+0.043。四组 B 的 99%CI 均跨零。按同一主71/15支持的「聚合 B 总贡献÷聚合占时」，单位 RF 占时贡献依次为 +0.120、+0.737、−0.459、+2.205；这只是确定性算术比值，无另算区间。原记录的「先每非空 pair 求类内均值、再说话人等权」依次为 +0.119（71对）、+0.729（41）、+0.357（45）、+1.093（23对/13人）。仅名义 N 一项的两种均值反号，源于非空支持和每对占时重加权，不能拿 +0.357 代表全71对的单位贡献。

边界双方近/仅 T 近/仅名义 N 近/均不近的 raw RF 占时为 0.504/0.182/0.209/0.104，B 总贡献为 +0.091/+0.041/+0.012/+0.045，C 总贡献为 +0.126/−0.031/+0.038/+0.031。按 B 贡献绝对点估计排序的音类对中 silence|silence +0.043（占时 0.016，99%CI[−0.023,+0.124]）、fricative|vowel +0.020、stop_affricate|silence +0.020；排序是结果后的描述，64 类和五套分区全表在 run 内，不作选择性确认。RF 包含周边音频；“双方非 speech”不等于纯静音信号。
