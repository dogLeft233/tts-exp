# 构音属性与口部功能坐标诊断

## 问题与历史边界

全音素分类分离度不等于TFG所需的可见构音区分。本诊断检验三个显式IPA属性：双唇发音部位/闭唇proxy、元音圆唇proxy、元音高度/开度proxy。IPA类别是声学标签先验，不是真人视频标定的可见口形或准确度；同形音素的背景见[CVPR2022原论文](https://openaccess.thecvf.com/content/CVPR2022/papers/Prajwal_Sub-Word_Level_Lip_Reading_With_Visual_Attention_CVPR_2022_paper.pdf)，分类定义见[IPA官方图表](https://www.internationalphoneticassociation.org/content/full-ipa-chart)。历史19/20的SSL viseme PER是另一个估计对象。

此前干净native18端点、物理phone均值谱形6端点已收束于 [[39-native-input-factor-mechanism-screen]]，固定剂量都没有跨样本稳定收益。本诊断是独立CPU观察问题，没有重开旧候选、训练或GPU矩阵。

## 冻结设计与已执行

复用S0053–S0061的18对/36已有WAV对应三TFG native数组及MFA。16k输入的材料化记录绑定N/T各自归一至RMS0.0376838172675746；自然/TTS的原时长不同，本观察比较不声称等实例时长。没有改时钟、重编码或将其直接作为自然时钟增强结果。

仅去除U+02E5..U+02E9 tone符号，保留其余diacritics；高/低类别精确字符串映射冻结于protocol02，不猜未知、复合/双元音、silence、English/Pinyin fallback。每token要求至少2个原生j/25半开所有权中心。逐帧单位向量均值再归一，token方向存float32，anchor/score为float64。

Natural-only LOSO anchors：token→每句basephone→class(phone等权)→speaker(句等权)→其他speaker等权→单位anchor，每class至少3个其他speaker。paired endpoint只取每句两条件共有的basephone标签，全部出现次数均用，不声称N/T实例一一对齐；signed margin=p·own−p·other，token→basephone→high/low等权→句→人。冻结描述门为每模型>=6人、>=2/3人正向、median正；仅全部三模型通过才讨论共同正方向，且不会自动授权GPU。

原Luna/max一次执行完成，6.35秒、rc0；0新encoder/MFA/GPU/renderer/SyncNet/API/训练/依赖/实现测试。attempt01 inventory手抄hash缺一hex，source在读取效应前拒绝；02仅修actual pin，原mapping/cohort/estimand/budget未变，旧件保留。

## 独立实际核验

ROOT唯一一次scientific readback通过：从原materialized native数组和36实际TextGrid重建全部1896 token方向（Wav630/Muse633/Ditto633），与保存float32逐值一致；162 natural-only LOSO class anchors、1972 margins及所有speaker归约/支持/门完全一致。最大单位范数误差5.50e-9，anchor/margin差0。核验没有import/重跑代理source，也没有重算baseline或实现测试。

RMS证据边界：Wav材料化metadata逐文件记录原始N/T RMS均值0.02154467/0.05025079、canonical目标及最大误差4.71e-11；Muse/Ditto protocol与manifest绑定36 canonical WAV和数组，本次未重新测其WAV RMS。native单位范数不等于物理功率，也不消除log-mel对输入增益的方向响应。

## 研究收敛与下一问题

已有结果将问题从“是否找到可复制坐标”推进到“坐标是否对应可用口部功能”。本组三属性未提供共同正方向，不投入新GPU候选。下一步先核实并复用现有540条已见DEV口部轨迹的构音/时间支持，避免只在当前两句稀少a中心上反复render；需要另冻支持、端点和低成本协议，不用已见DEV重选旧head，不将描述性开度/速度变化称准确度，也不直接复活历史LRS3 visual-teacher缺失门或dynamic-specificity近零路线。
