# 固定粗编码的双模型条件补全技术验证 2026-10-23

用户授权最小技术验证，不训练、不运行完整评分。目的是判断同一粗编码序列能否由0.6B和1.7B各自条件补全，并核验重放、内容与时间结构；不把可执行性等同机制已证实。

先从云端同10人旧样本按ID选首个、draw1，不按得分选样。核对旧完整code+reference上下文重解码；两模型各自在自己的隐藏状态与参考条件下处理固定粗编码，不交换不同维度模块。自重放控制通过后才交叉补全，保留完整16码本。检查ASR、音素对齐及原长时钟；若对齐不可用明确保留未验证状态。任何自重放不一致先定位，不扩大到10人或TFG/SyncNet。

## 完成结果（2026-10-23）

单样本BAC009S0002W0122/draw1/seed2026102401，0.6B与1.7B均通过旧全编码解码、原参数自由生成、固定自身粗码生成三种逐编码／逐波形精确重放。随后完成两次交叉补全；粗码、EOS和总长精确保持，细码变化92.199%／92.759%。共6次合成、2次单独旧码解码；4模型进程实际exit0，无新TFG／SyncNet／训练／云调用。

四格统一16k PCM16及RMS0.0376838172675746。Whisper-small对原0.6／1.7编辑距离2／3，换另一模型补全后为7／4；ASR原组本就有错误，不能直接判发音损坏，但内容保持未确认。首轮MFA整句未分词被视作OOV/spn，原件保留；逐字词典覆盖核验后修复，四格35对应音素、0unknown。0.6粗码换1.7补全：中心差中位25ms、p95 120ms、max130ms；1.7粗码换0.6：20／201／245ms，两者均未过预设时间门，包络lag+10／−20ms。强制对齐标签一致不是独立内容证据；边界是自动估计，非人工真实时间移位。
