# 校准音素内谱形动态与清浊覆盖

## 问题与完成范围

用户希望在已有音量/能量实验之外找到局部声学原因。本补充只读既定20条CAL/10人，验证160个固定PCM、WORLD特征、phone map与transfer audit文件。它完成描述性诊断，不含EVAL效果、不做模型前向、不改16类音素选择，也不提供TFG因果效应。

## 冻结操作

exact normalized phone保留声调/送气等标记；谱形为逐帧SP/sum(SP)，动态为同matched phone内连续5ms WORLD帧的mean absolute delta log(shape)，epsilon1e-12。AP在固定活动阈值−45dBFS且recipient/donor共同有声域描述；谱形另报active mapped全域。逐频带0–500/500–1000/1–2k/2–4k/4–8k。phone pooled表按帧/连续帧对汇总，不能当作独立说话人CI。

## 实际结果

170行exactphone×direction汇总完整；16个已由CAL曝光规则预选的labels，在T→N固定自然受体时钟active-mapped域中，全部T mapped相邻log谱形变化低于N。例：a˥˩ N0.661913/T0.507522；n N0.738470/T0.514587；ŋ N0.798322/T0.495200；tɕ N1.021218/T0.746521。same-domain低频AP差中位数各音素接近0，而清浊覆盖不同（n mapped1108帧：N863/T1045有声；ŋ1134帧：N874/T1027有声；tɕ480帧：N319/T391有声）。多数音素T高频谱能占比更低，w/o˥˩等例外全部保留，不挑选正向行。

必须区分映射后和自身native时钟：native active∩voiced全句谱形动态T−N仅13/20小于0，clip等权均值N0.623660/T0.613893，差−0.009768（自然log单位，无区间）。T→N映射将较短donor轨迹拉到受体时钟，可能降低相邻变化量；16/16不是所有native TTS天然更平滑的结论，也不是独立TFG因果证据。当前优先假设是固定phone时钟后的谱形稳定性及清浊覆盖与生成响应相关，交给预设WORLD arm直接检验。

## 反向映射与native音素对照

root另从同一已验证635a7907报告完整读取16类音素两向的recipient-own与donor-mapped动态。各自native matched active域T比N低14/16（j、w例外）；N→T后，mapped N比recipient-native T更高仅4/16，另12/16反而更低。因此双向log-SP插值都可能减少相邻变化量，mapped 16/16低值包含网格重采样效应。表存 `.codex/scratch/root_cal_native_vs_mapped_phone_dynamics.json`；它是报告字段摘录，不新增模型运行或推断CI。

这一对照使后续操作设计更明确：平均log谱形×内部残差四格并列一个recipient→donor phase grid→recipient的SELF_GRID控制；同声源/逐帧SPsum/总RMS/受体clock，记录双插值控制不同于原donor单次插值，不将其叫完全滤波匹配。WORLD现九臂/16labels/局部family保持原冻结设计，新操作另立计划，EVAL效果尚未读。

- [result] native exactphone动态14/16较低，双向mapped结果提示网格插值本身也会平滑，不能把mapped低值全归TTS原声学。
- [decision] 继续物理平均/残差四格并列SELF_GRID控制，将谱形统计线索转成可直接比较的操纵。
