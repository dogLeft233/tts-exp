# 冻结增强头的门控时序与频谱贡献

## 问题与设计

本实验解释固定增强头的收益来自平均频谱整形还是局部时序门控。状态 CONCLUDED，只针对当前 Fit40 可微代理。不是整个 TTS 机制的重新验收，也不是跨 TFG 迁移测试。

冻结 training11/v7、Adam 第120次更新，40条/20说话人，每人两条。九参数 STFT 头使用32ms窗/8ms hop、静态四频带与正负谱通量门控，逐帧去公共偏移、3dB投影并保持全局RMS。四臂共享同一权重和全体评分支持：实际门控；static_only（正负动态门全零，保留同一静态参数）；两动态门共同循环移动±64帧即±512ms。移动在三点反射平滑后、掩码合成前进行，保留门控分布。无优化器更新、候选选择、Dev或Confirm读取。

每臂40条，共160实际完成，78.041秒。评价为冻结Wav2Lip神经生成、原生裁剪几何、原自然音特征的可微代理；保留全源STFT与全部27query×31lag。边界掩码只用于局部描述，不删主评分支持。

## 局部时序的作用

正确时序门控对零延迟D0有小幅改善；移动512ms后大部分Cbest仍保留。静态臂也保留较大Cbest增益。因此当前固定头的Cbest增益主要依赖频谱整形和距离曲线校准，正确局部时序另提供较小的零延迟对齐收益。

根独立按每个query对D²做精确对称分解。设视觉范数v₁/v₀、原音范数a、单位余弦c₁/c₀，则径向项(v₁−v₀)(v₁+v₀−a(c₁+c₀))，角度项−a(v₁+v₀)(c₁−c₀)，两项和精确等于平方距离差，最大误差<1.5e−13。query→clip→speaker之后，actual对+64/−64的角度项均差−0.142834663/−0.133641575，次级边际99%区间[−0.251401167,−0.039735807]/[−0.227390528,−0.031397218]；径向项−0.014875486/−0.016512844，区间跨零。单位余弦改善+0.000604627/+0.000565106，边际99%区间分别[+0.000136880,+0.001095388]/[+0.000047209,+0.001071444]。这说明D0变化包含小幅特征方向对齐变化，不能仅归于特征范数。次级区间没有做12项family校正；D²分解也不能当作平均L2 D0的可加贡献。

两门全源均值约0.5020035/0.4803375、方差0.0189595/0.0090969，循环移位保持这些值。门控带有较大DC均值；置零会改变有效平均频谱与3dB投影，所以static_only不是纯时序消融，也不是重训后的最优静态头。日志显示actual与+64投影摘要40/40完全相同，−64投影摘要微小差异区间跨零；actual相对static投影scale约−0.264、raw mask最大值约+3.010dB、投影后最大值约+0.889dB。未导出逐频点掩码，不把摘要升级为完整掩码恒等。

## Cbest 的精确距离分解

根从全部160条原曲线进一步独立验证 Cbest=B−Dmin、Canchor=B−D0，每条恒等误差为0。实际臂相对RMS：ΔB=+0.101554346、ΔDmin=+0.043737471，二者相减为ΔCbest=+0.057816875。最佳匹配距离均值增加（23/40增加、17/40下降，边际99%[−0.002084242,+0.086086169]），39/40最佳lag不变。背景距离边际99%[+0.064620133,+0.144119333]。因此本轮平均Cbest提升来自背景距离增加超过最佳匹配距离增加；不能把Cbest提升直接解释为最佳匹配距离下降。零延迟D0确实下降，是另一个端点。

相同恒等在static及两错位也成立。此补充的100,000次说话人bootstrap使用seed20261003；区间是次级边际99%，不与12项同时区间混用。独立receipt `.codex/scratch/root_gate_diag02_whole_readback_attempt01/root_independent_confidence_decomposition_receipt_attempt01.json` SHA `1e4cb6c5aa4927981b9554ce51bae0f2ed2a66f05faa04960b0a86bbd62fd756`。该receipt在41文件快照完成之后生成，现已与anchor-gap receipt一起实际保存到独立持久analysis_annex_attempt02，不改既有不可变快照。

实际训练源码将Cbest及far作为正奖励，D0只作变差时的平方惩罚；这一结构与观测一致，为下一轮增加直接D0/单位方向奖励提供具体理由。当前冻结候选不变，先完成Dev。
