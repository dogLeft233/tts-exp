# 同权重关闭输入归一化的编码器增益方向对照

## 问题与完成结果
用户2026-10-19要求关闭报告52的输入归一化，与原结果比较。ROOT完成8个相同权重checkpoint、CAL20/10男性/原663与516支持/±3dB，共512encoder forward。正式证据见[[53-encoder-input-normalization-ablation]]；原52报告和数组不改。

7波形路径仅do_normalize=False，W2vBERT2仅关闭逐Mel CMVN；内部LN/GN保持。首句24次原on重放对旧last帧最大绝对误差0；一次160新NPZ消费者从末层实际帧重建RMS差0、音素方向差≤2.98e-8。7/8模型方向响应恢复至0.0273–0.4026；W2vBERT2仍低于1e-5门。恢复响应与平均方向共性不同：data2vec/XLSR跨人cos0.051/0.032，中文HuBERT0.847。

## 机制与边界
W2vBERT实际feature projection前有160维逐帧LayerNorm，消除log-power输入的纯增益常数平移。额外60次CPU前端重放hash全对，前端相对变化均值0.049201、无仿射LN核心后7.91e-7；0模型权重/0新encoder forward。公式平移不变与学习仿射无关，未执行删除内部LN的新模型消融。关闭输入归一化也改变部分基线表示，data2vec off/on cos0.673，不是语义质量改善证据。0新TFG/SyncNet/训练，暂停head不恢复。
