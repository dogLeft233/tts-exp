# 自然语音格式重采样的四格复核

## 问题与方法

检查自然16→24→16 kHz格式往返是否产生TTS的原生SyncNet正向优势。沿用新男性AISHELL EVAL40speaker×2=80，固定主脸、原时钟、exact-length PCM、k=3/column18，四格把生成输入RAW/sham与评分音频RAW/sham分别操纵。q00也重新前向，与所有其他cell同实际cuDNN benchmark=false；没有复用旧runtime不明的视频。独立消费者不导入producer评分函数，在CPU重算320行cache矩阵与指标，20,000 PCG64 bootstrap seed20260930，clip配对后两clip/speaker等权，99%区间。

## 结果

完整80clip/40speaker，320评分行/0失败、全部hash/视频/评分/PCM长度检查通过。raw guard20 q11−q00 ΔC=-0.015，99%[-0.043,+0.010]；固定anchor=-0.017[-0.044,+0.009]。G=-0.018[-0.045,+0.007]，E=+0.002[-0.002,+0.006]，I=+0.001[-0.003,+0.004]。生成端B上移+0.043、D上移+0.061，评分端B=-0.013、D=-0.015，距离变化会抵消，不能只看一个距离项称增强。

unit guard20 q11−q00 ΔC=-0.003[-0.008,+0.001]；raw guard15=-0.013[-0.037,+0.011]；full=-0.018[-0.039,+0.002]。没有按好看的支持/geometry选结论。

## 结论与边界

此格式往返在本cohort的正向Sync-C上界约0.010，不能解释大的正向原生分差；后续聚焦电平生成路径、声源/谱形和音素动态。这是一次明确限定cohort/转换实现的干预结论，没有预设等效区间，不能称两者严格等效，也不能外推所有codec或所有重采样器。评分变化不自动等于可见嘴型/人类同步改善。
