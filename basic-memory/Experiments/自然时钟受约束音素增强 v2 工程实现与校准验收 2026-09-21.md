## Conclusion
本次续跑在磁盘恢复后完成了正式的 optimization → train → lock → E/XLSR evaluation → mechanisms → report 链路。

- run：`runs/phone_separability_enhancement_audit_v2_20260921`；audit/calibration/独立 checker 均 PASS，checker 检查 336 个 PCM，errors/warnings 均为空。
- 规模：优化表 336 行；pilot FIT/DEV 各 24 句；E_SEEN 40 句、40 个 source groups。E 中 1 句无固定有效 support，因而主配对统计为 39 个完整句对；该行仍保留在冻结队列中，没有按效果删除。
- 锁定：逐句直接规则臂为 `OPT_DYNAMIC_6`；学习臂按预注册规则锁定 seed=20260921、step=1300。机制阶段当前只是诊断注册，static/dynamic 消融和 DAC 四臂实际执行仍未运行。
- DIRECT（标签辅助、逐句优化，非可复用增强器）：HuBERT accuracy 从 0.649969 到 0.848565，配对均值 Δ=+0.198596（39 句）；signed margin 从 0.038730 到 0.105424，Δ=+0.066694。XLSR accuracy 从 0.562609 到 0.644031，Δ=+0.081422；signed margin 从 0.000780 到 0.011145，Δ=+0.010364。40/40 输出通过 PCM/保护约束，平均残差能量比 0.008929、SNR 20.495 dB。
- LEARNED（固定增强器）：HuBERT accuracy Δ=+0.005229，但 signed margin Δ=-0.001428；XLSR accuracy Δ=-0.003903、signed margin Δ=+0.000215，均不构成稳定增益。40/40 质量约束通过；主 seed 的残差能量比 0.007097。
- 解释边界：直接规则证明了“给定本句正确标签时，低维增益场可在本教师上显著抬高局部可分度，并出现探索性的 XLSR 同向结果”；它不证明无标签自然音频增强器可泛化，也不解释 TTS 的成因。E_SEEN 与编码器有历史暴露，故跨编码器结果只能标为 `EXPLORATORY_ONLY_HISTORIC_E_EXPOSURE`；没有 MFA/ASR/人工听检或 TFG/SyncNet。

因此本轮科学状态更新为：DIRECT 局部可行性有阳性、LEARNED fixed enhancer 在当前预算下未复现；自然时钟增强器的可复用 phone gain 仍未确定，下一步应换新 source groups 做冻结确认，并先补齐实际机制消融与 T0/T1/内容质量评价。
