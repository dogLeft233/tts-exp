# TTS 嘴部动作时间校准与自然时间轴迁移实验结果 2026-09-20

## 实现与复现

- 协议：`tts_visual_timing_v1`；正式运行目录：`runs/tts_visual_timing_v1/`；smoke 运行目录：`runs/tts_visual_timing_smoke/`。
- 新增入口和纯测量模块：`scripts/experiments/tts_visual_timing.py`、`tts_visual_timing_metrics.py`、Python 3.8 视觉/媒体 worker、独立 checker，以及条件生成所需的 SyncNet worker。
- 补充了独立的门控合成 fixture，明确标记 `SYNTHETIC_NOT_SCIENCE`，覆盖校准失败、native 无支持、Wav2Lip 原生未确认、identity 不等效和全部门通过五条分支。
- smoke 与正式运行均完成；正式运行的 checker 从 NPZ、原始 valid/PTS、预览图、事件文件和台账独立复算，结果为 `PASS`。针对性测试最终 11 passed；两个 Python 环境的新增脚本均通过 `py_compile`。

## 正式运行结果

- audit：`execution=COMPLETE`，12 条主样本固定分母、4 条固定校准样本；12 条主样本的时钟绑定均为 `RESOLVED`，TextGrid 词/phone 时间、音频元数据、视频 PTS 和哈希已写入 manifest。没有因导入路径产生的伪依赖错误。
- 旧 Ditto-50 VSR 只读复算：47 对；G 均值 0.4323，Gmatched 均值 0.1169，历史 ΔSync-C 均值 1.0682（44/47 为正），Spearman(G,ΔSync-C)=-0.1776。该支线仍标记 `EXPLORATORY_ONLY`，不是英文同步证据。
- 纯视觉校准实际生成并重检测 28 个 cell（4 个 REAL、4 个 REPEAT、16 个局部 ±80/±160、4 个 FROZEN），每个视频保留 478 点 normalized landmarks、valid mask、真实/ffprobe PTS、首中末预览和事件文件。
- 4 条校准记录中只有 1 条通过；另外 3 条均因中心校准区少于 2 个可测参考事件而失败。固定门槛要求至少 3/4，因此 `calibration.execution=PARTIAL`、`calibration.science=NO_CLEAR_SUPPORT`、gate=`NOT_CALIBRATED`。
- 因校准门未通过，native LeapTalk 视觉时间比较和 Wav2Lip/Rubber Band generation 均按协议标记 `SKIPPED_BY_GATE`/`NOT_TESTED`，不是工程异常，也没有降低门槛或用空数组伪造完成。跳过的每个主样本/每个 generation arm 都写入 cells.jsonl。

## 科学解释边界

本次运行证明了新指标链路在工程上可复算，并发现当前固定的四条校准片段不足以满足预注册的视觉时间校准门。它不能证明 TTS 没有改善嘴型，也不能证明 TTS 的嘴部动作时间已经改善；native 和 replacement-safe 生成端问题仍未测试。因而当前最安全的结论仍是：旧 VSR/Sync-C 正迹象不能被解释为独立的嘴型真值，需要更合适且不替补的校准队列后才能继续比较。
