## 问题与设计

旧 uniform 母实验共同 T 总长的 R_T 在 raw 与逐行 unit 几何下差异较大。这个附加 CPU 诊断在既有持久 SyncNet V/A 表征内拆开每行向量范数 R 与单位方向 U：N_WARP 和 T_ID 两来源组成 R_N/U_N、R_N/U_T、R_T/U_N、R_T/U_T 四角，N/N 与 T/T 原角必须原数组 exact，混合角对 V、A 两模态同样逐行重标范数。共享物理 T 索引，不新生成声学或视频。R 表示表征长度依赖，**不等于物理音频电平**，也不是声学因果干预。

74 个既有评估对全保留，主 common71/15 人。raw/unit 的 guard20、valid、guard0、guard15 全视图；四角 C/B/D、固定 anchor 与 lag 指标全留。按每对定义 M_R、M_U 两个平均边效应与交互 I，M_R+M_U=H_TT−H_NN 精确闭合。20,000 次 PCG64 seed20260926 配对 speaker bootstrap 的 95/99%CI 仅描述，不声称独立确认或因果解释比例。
