# 编码器方向与范数对生成响应的分离

## 问题与冻结设计

来源方向与实测输入电平轴u正交，并不保证decoder输入z的范数不变；等delta范数随机对照也不保证最终z范数相同。将已保存的exact baseline z0 / orth_plus z1分解为方向×范数四格，固定原80N/40speaker、原音频时钟/RAW N评分、主脸、d/u/k3和所有支持域；不改变主来源实验。

权威spec：openspec/changes/confirm-latent-angle-radius-20261001/spec.md，root在读取正式EVAL effects前据CAL-only几何冻结，本地commitfcc4438（未push），raw SHA631e76042a523f598e9135de7ff9bf328f3656eabc800a0aa85f38f66bc01252。每帧r0/r1由float64 norm得到；q00原z0，q10 z1*r0/r1，q01 z0*r1/r0，q11原z1。q10方向变化保持baseline范数，q01范数变化保持baseline方向；一次float32 cast，正radius/finite/nonnegative与norm容差QA，端点bit exact。两混合臂记录u泄漏，不继承原严格正交主张。

全部320行fresh生成，post-face-detection恢复benchmark=false并记录实际forward；原缓存z作为该实验固定输入，原video不混入对照。RAW N评分、raw/unit/full/valid/guard20/guard15、同支持/k3，完整缓存cross/zero/lag矩阵。主要联合为方向-only q10−q00与q10−q01，各C/C_anchor的99%下界全正；20k PCG64原seed、clip配对→两个clip/speaker→40speaker等权。报告radius/joint/interaction、null100与独立visual资格，不称中介百分比或TTS-exclusive方向识别。
