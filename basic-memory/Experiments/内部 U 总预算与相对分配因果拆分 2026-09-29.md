# 内部 U 总预算与相对分配因果拆分（2026-09-29）

## Observations

- [status] concluded（历史 WORLD 队列探索性结果；296 eval 新角、8 首校准新角、74/74 评分、独立特征审与独立数值审 PASS）。评分与效果在产物封存和独立评分锁审后才解封。此前 26cal 在异 agent 静审前启动的流程 FAIL、首校准 MFCC checker 32 线程首次失败与修正证据均留账，不能称全流程完美预注册。
- [question] 在固定完整 T 声学 WORLD、全句 RMS、总时长 D、首尾 E，且 S 按剩余 D 比例补偿时，把内部 U（停顿加邻接发声半段）的来源时距拆为总预算 L 与相对分配 p；四格 N/N、T/N、N/T、T/T，四组 S/E 背景平均。U 空或只有一区间的 37 对按预封别名纳入，37 对 m≥2 有 296 个真实新角。不是纯静音、纯时钟或可播放原生波形干预。
- [primary] 主 raw/guard20 Sync-C、71 对/15 说话人等权、PCG64 seed 20260929 20,000 次 speaker bootstrap：M_budget=+0.048070，95%CI [−0.010857,+0.109103]，99%CI [−0.027326,+0.128532]；M_profile=+0.075895，95%CI [+0.015769,+0.141001]，99%CI [−0.001066,+0.161180]；budget−profile=−0.027826，99%CI [−0.120801,+0.085167]。两项的正式 99%CI 均跨零，二者差亦跨零，不能断言某一项独自为正或大于另一项。逐对 M_budget+M_profile=M_U_parent 精确闭合，母 U 均值 +0.123965。
- [threshold] 本轮母 U 的 99%CI [−0.000127,+0.247818] 与旧 E/U 报告下界 +0.00036297 的符号差，独立审计证实只是相同数据和 speaker 均值在不同预设 PCG64 seed（20260929 与 20260926）的 20k 重抽样波动。事后 100 个固定 seed 的下界 84 次正、16 次非正，范围 [−0.002914,+0.005369]；这是阈值脆弱性诊断，不能择 seed 宣称稳健显著。
- [mechanism] 主视图点估计预算/分配的错位背景 B 分别 +0.074547/+0.044337；最优时延距离 D 分别 +0.026477/−0.031558；固定 lag3 C_anchor 分别 +0.055484/+0.069496。方向提示预算更可能抬高负例距离且同时抬高正例距离，分配同时可能改善正例距离；仅点估计，不据此确认分量差或物理中介。U 总预算 T−N 在主 54 个非空 U 对中 28 短、26 长，绝非统一缩短停顿。296 个新角的局部区间 RMS 均有变化，平均相对绝对差约 5.21%，全句 RMS 固定不能隔离瞬时电平。
- [verification] 特征独审 PASS：37 个非平凡样本全部 CPU 重演 296 新角 PCM/WAV/mel/MFCC exact，304 个新角 V/A 与 296 双媒体释放回执闭合；首校准 16 AVI 已独立现场逐帧/PTS/像素审。评分独审 PASS：296×raw/unit 的 592 距离矩阵、2368 视图、133152 逐对效应/边与 3744 bootstrap 统计复算；曲线差最大 1.3173e−6、端点 9.771e−7，全部阈内。正式 296 AVI 依预封资源方案逐格释放，无法事后独立重解码，须保留这一证据限制。生产失败 0，GPU 累计1594.392/4500秒。
- [boundary] 原先 WORLD→原生波形身份桥 FAIL，因此这些分量不能除以原生 T−N Sync-C 差来宣称解释份额，也不证明真实口型视觉准确度。下一关键检验是同样 U 时钟在原生 Wav2Lip mel 与 SyncNet MFCC 输入层的双向 N_gain/T_loss，及目标自然 WAV 从未作提示的新说话人队列；两者结果需另记。
