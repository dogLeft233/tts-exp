## 问题与唯一候选

**问题：在冻结 TFG 上，能否比校准归一化取得更好的电平鲁棒性—口型误差权衡？** 整段 RMS 归一化已能抵消理想全局增益并保留句内相对强弱，因此这两点不作为新贡献。

候选在冻结 Wav2Lip GAN 音频编码后加入逐帧 `512→32→512` 残差适配器（输出零初始化）；编码器/解码器权重冻结、保留解码器梯度。训练目标＝原尺度与增益视图的真人嘴部监督＋`1.0×`嘴部输出一致性＋`0.1×`原尺度基线锚定。不加 TTS/能量支路，不优化 Sync-C。**候选结构和一致性范式均已有先例，新颖性待证。**

## 最强基线

| 层级 | 必须面对的比较 |
|:--|:--|
| 零训练 | 原模型；整段 RMS 目标 `r₀×{0.5,1,2}`，`r₀=0.0376838172675746`；整段去均值后缩到 `r₀`。在 dev 按口型误差选最强归一化 |
| 条件性训练 | 同适配器的原尺度任务适配、随机增益增强、最强归一化后任务适配；相同两视图计算量/锚定/更新预算。候选仅增加一致性，增强臂即 `λ=0` 消融 |
| 文献先例 | PCEN、ΔLFBE、AugMix/音频一致性必须讨论；不同特征不可直接塞入冻结 log-mel 模型充当劣质对照。此版不声称通用前端优越 |

## 最小验证：先 A，满足必要性才考虑 B

**A0，先校准测量：** 旧LRS3真实输入仅2/8、GRID完整几何仅3/8过门；后续通过的是较窄相关性端点。先用旧cal数组与失败案例核对Q/R；完整唇轮廓、像素重检测及真实输入资格未合格前不进入A，不把控制失败写成方法阴性。

**A，零训练筛查：** 提议改用10个LRS3开发来源组，各1个预定5秒真人配对片段；现有16来源组通过声学峰值门，但独立说话人、参考脸/姿态与共同帧支持仍须核验；同一录音 `−6/−3/0/+3/+6 dB`，5条零训练流程，共250输出，另每流程0dB重复一次，共300输出。只筛必要性，不证明方法。若原模型运动变化不高于重复噪声，或校准归一化已稳定且原尺度误差不劣于原模型2%，停止开发候选。仅当增益引起至少5%的最坏剂量口型误差增加、且最强归一化存在超过2%的原尺度误差代价，并在说话人区间上得到支持，才有进入 B 的理由；不确定则保留未决，不自动训练。

**B，后续有界小试：** 另20位训练说话人各10段，dev沿用10位；另20位未用于本项目选择的测试说话人各2段。不再假设现有MEAD提供多人（已核实50条均W025）；B所需独立多人配对数据与曝光资格尚未落实。4个可训练臂×3个配对seed×2,000成功更新，固定末步、同预算；无测试调参。旧AISHELL静态脸队列仅作机制参考。通过后才考虑第二生成器。

## 端点与通过标准

**主要视觉量：** Q＝与匹配真人的唇 landmark MSE（共同对齐/眼距/原时钟），Q₀为0dB，Qall为五剂量等权；R＝各增益相对本方法0dB的最大口部变化。先句内聚合、再说话人等权/cluster bootstrap；帧/剂量/seed不充当独立样本。τ由开发集同输入重复校准。

B须同时达到：**Qall比每个强基线至少低5%（比值95%区间上界≤0.95）；Q₀相对原模型不劣2%（上界≤1.02）；R相对原模型减少≥90%，且不超过最强归一化R＋τ。** 单独报告各seed；另查开度/速度误差防静嘴。SyncNet C/B/Dmin/D0/offset及预选AVS_u为次要诊断，始终用原自然评价音轨。视觉测量通过也不直接称感知改善。

## 停止条件与当前状态

**停止：** A无明确剩余问题；B与常规增强/归一化持平或更差；仅C上升；静嘴换稳定；三个seed方向不一致或预算结束仍不确定。保留阴性/混合结果，不追加剂量、指标或预算追阳性。缺匹配GT、支持失败、削波/时钟或梯度错误记为依赖/控制失败，不能写科学阴性。

**资产审计完成，筛查/新TFG生成/训练均未启动。** 模型权重与环境可复用；还需完成测量、参考/姿态/时钟资格和新流程parity。E/F空间不足，输出位置与预算须重新绑定。下一步先A0，再决定A；方案不构成训练授权。
