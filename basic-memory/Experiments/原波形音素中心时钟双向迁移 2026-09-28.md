# 原波形音素中心时钟双向迁移 2026-09-28

本实验是 [[WORLD声源谱包络双向交换 2026-09-28]] 结束后提出的**后续探索**，不是其未完成分支，也不是新独立队列确认。目标是检验完整原 FIXED 自然/TTS 波形在对方 phone-center 时钟上变时后，原生 Wav2Lip/cloud 的 T−N Sync-C 差异是否随时钟双向迁移。root 负责理论与研究枢纽，scorer 维护此实验笔记；WORLD 正式报告和封存效果不回写。

## 为什么另开实验

WORLD 同一历史 common71/15speaker、raw/guard20 的原生 FIXED T−N C=+0.254；WORLD ID 的 RAW→ID 桥差中差95%CI未全落±0.05，两臂损伤95%CI未全落±0.20。EX/SP/BOTH 都未通过双向 C 迁移99%CI，BOTH 同源双残差未达到±0.05精度。与此同时 SP/BOTH 在 N/T 两侧都有强的 V/A 交叉兼容性损失与自配恢复，主要是匹配 D 组成。其同源 C 残差主要在 B；这只是评分分解，不能叫纯时钟因果。已完成的26cal WORLD-SP谱比与ratio=1 STFT identity是未来谱比路线的技术资产，不是此时钟路线的效果证据。

历史 [[MFA-linear 轨迹增益的匹配项与背景项分解 2026-09-16]] 的 T_100 条件是历史 **MFA-linear 特征来源**，不是完整原始 TTS 波形。该运行的匹配项/背景项分解可提供时钟研究动机，但不能冒称已经测试本实验的“完整原 FIXED 波形搬到对方时钟”。同样，过去声学重组轨迹实验使用重合成链，不等于原波形变时。新的结论须单独通过本轮 RAW→DSP-ID 与 roundtrip 载体桥。

## 当前 cal-only 技术授权
非线性 phone-center map 技术路线已暂停。v3/v4 RubberBand CLI 3.3 R3/Finer、v5 CLI R2/Fast、v6 系统 libRubberBand 3.3 C API offline R3/固定64-sample block 均未通过原冻结 synthetic 时点门，各版失败产物与独立审查记录保留。v5 ID 预定16000/32000 samples，实测16019/32039，误差+19/+39超过1sample门，WARP与真实cal未运行。v6 ID 精确命中，WARP 预定8000/40000、实测7927/39552，第二峰提前448 samples，超过320sample门；独立失败审查 receipt SHA `ff38599dfa36333bdb7cf3f76ea4f1d38eedadbaa1d331cfeb06625b707588f6`。PyTSMod 0.3.8 WSOLA 参数未定、未运行；不接受以 tolerance1 近似 OLA 迎合旧合成门。若恢复 phone map，须另立前瞻 protocol/seal，原1sample ID/320sample WARP门与共同64MiB cap不变。

root 已优先转向完整原 FIXED 波形的整句单一比例检验主要 B 残余是否受总时长影响。系统 libRubberBand 3.3 C API offline R3、固定64sample block、无 keymap，ratio=目标总样本数/来源总样本数。`runs/tts_uniform_rate_cal26_feasibility_v3_20260928/` 已在26cal/13speaker完成156主WAV加首pair六份重复，静审、五档 synthetic、首真实pair、全量26cal四项独立审计均 PASS，见 `final.json` 与 `report.md`。ID 0/52波形或官方mel/chunk/MFCC exact，虽误差很小，后续正式比较须使用同处理路径 ID 桥；ROUNDTRIP 52/52不exact。此为技术可行性，不能替代效果证据。uniform v1 静审失败未运行；v2 synthetic PASS但重复 hash 失败且第二WAV未保留，不能追认 v2通过；v3独立闭合。

均匀总时长不等于共同 phone-center 时钟或相同发音内容。四joint为 `N_ID`、`T_uniform_toN`、`N_uniform_toT`、`T_ID`；匹配 G/E/I 仅是总时长一致下不同内部时序的完整来源兼容性，固定自然RAW配 `T_uniform_toN` 的 G_RAW 可作原始问题直接端点但需披露内部phone时序不同。known-phone event若以后启用，要在各joint按源中心×总时长比选各自q，四q共同满足原目标钟guard20及31lag/媒体窗口，评分前封存共同事件集与缺失账本。正式74eval效果及统计仍需独立预封；此笔记保持 planned/NO_NEW_SCORE，不把uniform技术PASS记为TFG或Sync-C效果。
## 预定科学比较草案（尚未正式冻结）

四个 joint 单元按完整原音源×目标钟：`N_ID`（N声/N钟）、`T_toN`（T声/N钟）、`N_toT`（N声/T钟）、`T_ID`（T声/T钟）。另做 `N→T→N` 与 `T→N→T` roundtrip 并保留载体损伤。root 暂定主“时钟转移”为 `C(N_toT)−C(N_ID)` 和 `C(T_ID)−C(T_toN)`，各自99%CI下界>0；同钟残差为 `C(T_ID)−C(N_toT)` 与 `C(T_toN)−C(N_ID)`，各95%CI全落±0.05才称剩余小。原生外推桥继续要求 RAW→DSP-ID 的 gap差中差95%CI全落±0.05、N/T各臂C损伤95%CI全落±0.20。这是历史主支持内预定实用精度草案，不是普适阈值；共同钟残差不能平均抵消，桥失败则只能限定DSP域。

每个目标钟以同钟 `ID` 与 `swap` 建 `q00=(V_ID,A_ID)`、`q10=(V_swap,A_ID)`、`q01=(V_ID,A_swap)`、`q11=(V_swap,A_swap)`，G/E/I是**同钟来源兼容性**，不能称跨钟独立生成路径。另以自然原 FIXED 音轨对比 `C(V_T_toN,A_N_RAW)−C(V_N_RAW,A_N_RAW)` 作直接 G_RAW 诊断，不冒称纯时钟作用。C/B/D、固定旧k3 anchor、offset和所有预定视图同报，主 common71/15speaker raw/guard20，原74全量附录不重选。

次要固定语义查询：canonical known-phone配对 occurrence 各取N/T中心，SyncNet MFCC20帧窗口的采样中心为起点+0.1075s；用 half-up `floor(z+0.5)` 在每钟选最近 query，k3 是相对视频 query 的音频 lag，不再修正音频中心。只有 q_N/q_T 双方均在旧guard20且31lag窗口完整才进入同一 event 集；重复query保留为不同phone事件。每句先等权平均各event的31lag曲线、再求该句C/B/D，按旧法同speaker句均值和speaker等权bootstrap。空event句仅在次要视图记缺失，不改变均匀帧主71/74；事件支持、空档、原生gap和筛后差异必须首新score前封存。上述定义仍待 cal 技术、root正式裁决与独立静态审核。

## 数量与边界

正式评估仍为历史74条，主71；不因旧WORLD中 a1_075 的低覆盖而删句。旧WORLD是同位置 exact-label 规则，新的 SequenceMatcher 不同，必须重新报告匹配/空档，不可把旧5.67%/4.08%当新剂量。若正式每pair四joint加两roundtrip都需视频，74×6=444新视频是资源上界，约11个新评分矩阵/pair的首版配额；本轮没有批准正式GPU。producer 已闭合的 WORLD run 耗5291.612s GPU、本地新增477,134,848B、云缓存增510,619,648B，根盘free3,172,962,304B；新阶段必须独立冻结 placement/预算，旧门不自动延用。字段/事件/资源草案见 `runs/tts_phone_clock_transfer_feasibility_20260928/design_fields_budget_draft.md`。

本轮同一历史自然/TTS评估队列，已多次用于机制探索；SyncNet不是人工嘴型真值，完整原波形变时仍可能改变相位、瞬态、局部音色和Wav2Lip输入。任何结果都只能在实际操作与桥通过的条件下解释，不是独立新holdout或天然的因果中介比例。
