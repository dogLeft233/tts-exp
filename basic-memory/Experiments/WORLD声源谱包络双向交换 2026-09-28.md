# WORLD声源谱包络双向交换 2026-09-28

本轮目标是解释当前 Wav2Lip/cloud 原生 TTS−自然 Sync-C 差距，而非继续扩大微小 latent 来源方向迁移。root 负责理论，GPT-6 Sol high 执行和独立复核。用户再次授权自主探索、下载/模型与 CloudDrive；不依赖人眼，不按评估结果选择方向、强度或样本。

## 冻结路线与结论

在各自原始时间轴，以历史 MFA 同音素 occurrence 固定映射，从同配对的另一来源取得 WORLD 参数。将参数分成 EX（F0＋aperiodicity）和 SP（随时间变化的谱包络，暂包含局部能量），构造 ID、仅 EX、仅 SP、BOTH 四格，并做 N/T 双向。所有波形恢复到既定 FIXED RMS。配对 donor 是因果诊断输入，不是训练标签，也不宣称可部署自然语音增强；不得按其下游效果改映射。

必须先核查 RAW→ID 重合成桥，再分别计算生成路径 G、评价路径 E 及交互 I。只因破坏 TTS 而消除差距不足以认定增强原因；要报告自然侧增益、TTS 侧损失、两者方向、B/D 组成、固定 lag 及全部预定敏感性。EX/SP 若定位到可靠效应，再细分声源周期性/非周期性或谱形/局部能量。正式 v2 科学协议、输入支持与量化判据均已在新效果评分前封存。独立审计重算全部正式效果：SP/BOTH 在 N/T 两侧均造成显著的声视频交叉兼容性损失与同来源恢复，主要由匹配 D 而非 B 的交叉变化构成；但 EX/SP/BOTH 都未达到预定双向 C 转移，BOTH 双残差精度和 RAW→ID 原生桥均未通过。正向结论只限 WORLD 重合成域内 SyncNet 兼容性，不能声称解释原生 FIXED T−N +0.254、纯谱形/物理声源或人眼嘴型改善。正式报告见 `runs/tts_world_source_filter_holdout74_20260928/report.md`。

WORLD 参数定义与重合成依据：[WORLD 官方说明](https://www.isc.meiji.ac.jp/~mmorise/world/english/introductions.html)、[PyWORLD 实现](https://github.com/JeremyCCHsu/Python-Wrapper-for-World-Vocoder)。这是分析合成参数化，不等同物理声源和声道的完全独立分解。

## 预定科学判据（新评分前）

每种交换 c 的 joint 自配评分记为 C(N,c←T) 和 C(T,c←N)，ID 为相同重合成域的自身参数对照。分别报告 N 获益 C(N,c←T)−C(N,ID)、T 损失 C(T,ID)−C(T,c←N)；两者99%CI同时为正才称该参数组有双向转移证据。所有 EX/SP/BOTH 结果完整报告，不按赢家更换主视图。

近乎完整解释的操作目标是两个共同来源残差分别小：R_T(c)=C(T,ID)−C(N,c←T)，R_N(c)=C(T,c←N)−C(N,ID)。BOTH 的两个95%CI都进入 ±0.05 Sync-C，才达到本轮预定精度目标；不是把双向交换后的 gap≈0 当作成功，也不能用两个残差平均后的抵消证明完整解释。令 Δ_ID=C(T,ID)−C(N,ID)、Δ_swap=C(T,c←N)−C(N,c←T)，(Δ_ID−Δ_swap)/2 只作映射/交互条件下的算术转移描述，不是原生因果中介比例。

原生归因桥要求 raw→WORLD ID 的 T−N gap 差中差95%CI在 ±0.05 内，且 N/T 各自 C 变化95%CI均在 ±0.20 内；另完整报告 C/B/D/anchor 的处理偏移。这些是本轮预定实用界，不是外部公认阈值。未通过时结论限定重合成/映射域，并继续寻找保留原波形的机制检验，不能据此宣告原生差距已解释。

主视图继承 FIXED common71/15speaker raw/guard20，固定 k3 anchor、原74 all-valid 和所有预定历史视图作为完整敏感性。G/E/I 四格既报告相对相同 ID 的路径，也保留原 FIXED 桥；SP×EX 交互明确列出。操作支持、缺失/回退、映射 sham 和所有定量技术门须在正式评分前封存；既有评估暴露与说话人重合如实标为机制探索。
