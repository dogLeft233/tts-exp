# 自然时钟构音与生成口部功能响应

## 问题与边界

已有原生SEP/STAB/radial ENV和物理谱形筛查未形成跨样本增强；三个native构音属性也无共同三模型正方向。下一步检验可重复的“口部功能坐标”：生成视频是否在原自然时刻区分构音类别，历史head−RMS评分变化是否与该响应对应。重点是连接音素语义与实际运动，不把运动幅度或Sync-C直接称嘴型准确度。

这是已见DEV的exploratory诊断。现有v4 head全DEV低于RMS的结论不改、不重新选旧head；本实验不是新确认/新候选。真人视频GT和raw lip outline均缺，功能类别也只是部分IPA proxy。旧LRS3 visual-teacher缺失门/dynamic-specificity近零路线继续停放。
