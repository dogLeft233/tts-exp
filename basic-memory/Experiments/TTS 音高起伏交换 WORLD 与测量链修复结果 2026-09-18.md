# TTS 音高起伏交换 WORLD 与测量链修复结果 2026-09-18

## 实验范围

本结果对应修复协议 `tts_f0_swap_repair_v2`，父 run 为 `runs/tts_f0_swap_f0spec_audit2/`，新 run 为 `runs/tts_f0_swap_repair_v2_audit5/`。严格使用固定 4 对 pilot、8 个接收方和 32 个最终 PCM16 WAV；先完成旧产物审计，再生成修正版音频。没有生成视频，没有调用 Wav2Lip/SyncNet，没有训练或新增 TTS。

修复实现采用普通平均保持公式：CONTOUR 的目标变化在全部原始有声帧上的普通平均为零；剂量在 w≥0.5 的帧上按普通 RMS 计算。所有 QC 和 F0 测量均重读最终 WAV；同时保存 Harvest→StoneMask（H）和 DIO→StoneMask（D）轨迹、时间网格及四格有声计数。时间网格不一致时不插值。

## 诊断

S0765、S0770、S0901 的 `H_RAW→D_RAW` 覆盖率约为 0.679–0.766，说明在重合成前两个检测方法已经有明显有声区分歧；S0906 的对应覆盖率约为 0.845–0.865，较为一致。重合成后 `D_RAW→D_ID` 仍有丢失和新增有声帧，且各方向幅度不同。因此现有证据支持“检测器分歧”和“重合成后变化”同时存在，但不能把失败唯一归因于其中一个，也不能把自动 F0 变化直接解释为听感损伤或收益。

## 结论与边界

- 音高交换的公式、目标构造、PCM16 重读 QC、H/D 诊断和独立复算已经按修复 spec 正确实现。
- 修复后的操作在固定 pilot 上没有达到继续门槛；当前 WORLD + DIO 测量协议尚未验证可行。
- 本结果不能回答 F0 是否解释 TTS 在 TFG 上的增益，也没有提供 TFG/SyncNet 因果证据。
- 若继续，应另写方法 spec 处理检测协议或载体问题；不能在本协议内通过放宽门槛、插值或调弱干预来制造通过。
