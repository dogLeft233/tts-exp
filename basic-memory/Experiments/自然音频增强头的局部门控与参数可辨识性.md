# 自然音频增强头的局部门控与参数可辨识性

## 问题与设计

当前自然音频增强头V3以四频带中的三条自由系数，分别乘static、positive_flux与negative_flux，共九参数。需要确认局部门控是否有真实时间变化，以及九个参数是否能分别影响掩码。这决定下一轮机制方法应优先调整时间条件、参数化还是增加音素特征。

在全部40条原Fit音频上，使用冻结V3源码、真实step120构造参数和原始PCM/clock计算门控；不生成新音频/视频，不运行SyncNet、选择器或SPSA。设计矩阵是实际频带参数到smoothed_log_magnitude_mask_db的导数，采用固定零reference系数、实际门控及频率/时间平滑。Gram计算在frequency common-mode处理、径向tanh、iSTFT和RMS之前。参数快照仅提供现有构造契约，不选择或改变当前20步方法。统计按所有适格STFT transitions汇总，conditioning按全部频率×时间cells汇总。

## 实际结果

40/40音频、40唯一sample ID，missing=failed=0。与既有mask-gates07同源样本的positive/negative/valid数组逐元素完全一致。ROOT重新核验请求和各输入raw/self pins、40WAV raw SHA、实际child0和运行日志，并从每样本均值/标准差/相关性、Gram独立合并重算。

## 结论与方法意义

门控有明显时间变化，当前动态分支有实际局部条件信息。它们同时带有较大非零均值，导致静态和动态参数列高度对齐；可以用多个参数组合产生相近的谱掩码。因而后续方法应检验去均值/正交化或按音素与受者声学分配局部谱形，而不能仅凭九个可训练标量就认定九种独立有效控制。

这份结果描述冻结掩码的线性条件数，不能当作视频评分目标的Hessian，也没有产生新的跨TFG/RMS收益。当前已冻结的20步联合SPSA保持原设计。完成本轮后，依据其三模型完整结果决定下一轮是否采用显式分离静态谱形与局部变化的参数化，再执行原音换轨的封闭泛化验证。

## 参数中心化的数学范围
这是根据已核验V3实现推导的设计结论，没有新增TFG运行。对某个自由频带，当前线性掩码系数为 s+p·g_pos+n·g_neg。任选固定常数μ_pos、μ_neg，定义z_pos=g_pos−μ_pos、z_neg=g_neg−μ_neg及s′=s+p·μ_pos+n·μ_neg，则原表达式严格等于s′+p·z_pos+n·z_neg。频率/时间平滑是线性的；若系数按上述映射且生成相同raw mask，后续公共模式处理、非线性投影、iSTFT及RMS也得到相同输出。

使用全局固定均值中心化或可逆基底正交化，改变优化条件而不扩大波形函数族，不能单独称为新增局部声学机制。有限步优化轨迹仍依赖坐标：SPSA逐坐标扰动，以及每步更新量的逐项限幅，经坐标变换后不保持同一操作。

勘误（2026-10-09源码复核）：前一版将±0.25误写成s/p/n的参数盒约束。实际selector06的_validate_theta只检查九维且finite；tell中updates_i=clip(−a_k·gradient_i,−0.25,+0.25)，随后theta_new_i=theta_old_i+updates_i，参数本身没有该盒约束。±0.25限制单步增量；ask的扰动幅度另为c_k=0.25/(k+1)^0.101。源码scripts/experiments/cross_tfg_audio_head_20261003/fit_only_spsa_selection_attempt06.py，66767B/SHA dda610b985026be7f9328c479358e96c983a582c511964e8c6e72a6d398692e2，第208–215及1201–1203行。旧immutable19:35与19:59 checkpoint中的盒约束文字保留为历史误述，以此更正为准；没有改变优化器或实验协议。

按每条音频自身均值中心化会引入输入相关静态调整，与全局固定均值等价关系不同。下一代方法可检验不能由现有static/两个全局flux线性表示的条件，例如各频带独立局部谱变化、谐波/非周期覆盖或更长共发音上下文。该方向另行冻结Fit内设计与三模型原音评分；当前冻结20步仍用原九参数。
