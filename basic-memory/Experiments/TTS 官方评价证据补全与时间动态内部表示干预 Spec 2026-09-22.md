# TTS 官方评价证据补全与时间动态内部表示干预 Spec 2026-09-22

按 implementation-architect 设计完成实现并通过 CPU 工程验收；GPU 干预渲染、GPU 官方重评分与人工标签仍待后续执行，未将未完成环节写成科学结论。

完整设计：[spec](openspec/changes/audit-tts-evidence-and-temporal-representation/spec.md)。输入冻结：[input-bindings](openspec/changes/audit-tts-evidence-and-temporal-representation/input-bindings.json)。父 run 为 `runs/phoneme_tfg_association_external_visual_cpu_audit_v1_20260922`；5 个顶层输入文件的 SHA256 已核验，执行前仍需逐 cell 验证媒体/PCM/参考帧/权重/对齐。

## 设计

A 复用108条视频（36源组，每组natural+两个TTS），导入已完成官方full-track评分，补充固定校准的局部时间rank、独立landmark时间量尺和72对原生AV盲评。SyncNet内部rank不算独立感知证据，landmark运动变化不等于准确性；没有合格人工标签只能写PENDING_HUMAN。

B 从现有配对中按输入资格、模型配额与固定hash选择4个技术校准组、12个科学组；不读取增益或silhouette选择样本。Wav2Lip逐窗口独立解码，因此完整瓶颈替换不是时间机制证明。唯一干预层为audio_encoder输出512维表示，严格MFA映射到recipient时钟；固定5帧平滑的动态残差、λ=0.5，比较BASE/COHERENT/SCRAMBLED/ERASE，双向N←T、T←N。SCRAMBLED保持扰动范数/均值但错置时间；评价音频始终是recipient原始PCM。

A不新生成TFG视频；B上限128条新渲染（32技术+96科学，精确缓存可减少），GPU总预算120分钟。先CPU审计，再资源锁+成功查询GPU全部进程；未知状态或冲突拒绝启动，不杀进程。旧gpu_processes查询失败会返回空列表，不能直接复用这一不安全语义。

主判断要求同时比较COHERENT与BASE及SCRAMBLED，按source_group统计；仅赢过损坏对照不足以确认增益。人工缺失、低运动、映射不足、跨设备基线漂移均显式处理。当前cohort已经看过，B是探索性定位，不宣称新来源确认或解释原生增益的中介比例。
