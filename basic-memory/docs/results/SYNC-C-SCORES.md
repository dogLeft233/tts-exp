## 关键观察

1. **Wav2Lip 稳居第一**（最简单的架构，最强的唇形匹配）
2. **IMTalker 是新晋第二**，超越 V-Express/MuseTalk/Ditto
3. **Hallo2 表现中性**（ΔC=−0.07，接近零），移除人声分离后绝对分数大幅下降（Natural −0.86, TTS −0.59），但仍未复现 TTS > Natural 效应
4. 所有模型 TTS 条件 Sync-C 均高于 Natural（Hallo2 和 LatentSync 除外）
5. EchoMimic V2 需要真实驱动视频——当前分数反映姿态问题而非模型能力
