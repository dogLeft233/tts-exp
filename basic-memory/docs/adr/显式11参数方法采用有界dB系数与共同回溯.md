# 显式11参数方法采用有界dB系数与共同回溯

## Context

完整9参数final720已科学未准入，四中心各失败9/19门。K15按冻结最小违例规则是后续seed，不能替换为均值最高K10或称为通过。用户要求失败后持续形成可用的跨TFG自然音频增强头，研究转入显式11参数谱形/局部包络方法。Dev/Confirm仍封闭；本决定只冻结新方法设计与SOURCE_ONLY实现，不授权任何训练、模型运行或未来效果读取。

实际已有信号头为 `scripts/audio_enhancement/shared_recipient_local_power_spectral_head_v1.py`，25881B/raw8f22db628ec84f4b67d01e6e9c1bce12edf9280cca88e52cfc55d32d7b94dcfe；依赖V3 raw77acdff03cca22261852f48364cbc75263db58a14cb565c08aa0d268afca6e87。原头保持不变，新helper/profile/controller/source闭包独立命名。继承V3实际已执行constructor，来源 snapshot_step120.json 9223B/raw9519c18b8c95c8291d70871a452417f4fb1cd361828284ad39feaf9cb1b178e1、constructor self eaf51303012125c2de40dc102fc04a983c130b6d2aac31cd96b6e5648c3e27b8；不是engineering-only fixture。ROOT已直接读回该完整constructor及raw SHA。

## Method choice

参数顺序是11个pre-kappa dB系数u：3×3 shape row-major九维，再env(+flux,−flux)两维。head内部scale S为shape2.5dB/env1.0dB，硬优化box U为shape±2.4dB/env±0.95dB。K15从sealed journal.entries[14].tell_result.full_center_spec精确获取九个direct-dB系数，env初始化0；不clip，z=atanh(u/S)，传入实际float32 head。每点同时记录controller u、F32 z及head恢复的S*tanh(z)值/各自hash；F32系数roundtrip绝对容差2e-6dB、rtol0，非finite/界外/超容差失败。它是COORDINATE_SEED_ONLY_NOT_WAVEFORM_EQUIVALENCE，因新共同κ和Parseval补偿改变函数。

20轮黑盒SPSA，仍按已冻结20说话人排序、每轮循环4完整说话人×2片，三TFG顺序生成；renderer seed20261003。新PCG64(20261009)独立状态每次draw11维Rademacher，不能复用旧9 RNG状态。base a_k=0.5/(k+5)^0.602，base c_k=0.25/(k+1)^0.101，单位均在直接dB域。actual c_k=min(base c_k,0.5*min_j(U_j−|u_j|))，c_min=0.01dB；低于c_min则BOUNDARY_LIMITED_NO_UPDATE，保存全证据后再决定新方法迭代。双向候选严格为u±actual c_k*delta，数学分母必须用actual c_k。

g_i=(Lplus−Lminus)/(2*actual c_k*delta_i)，v=−a_k*g。先取共同scalar s=min(1,0.25/maxabs(v))，v=0时s=1；再依次试β=2^(−m),m=0..40，选择首个满足所有|u+β*s*v|≤U−0.02dB的更新。无可行β则typed failure且不写UPDATED。不得逐坐标clip或反射；每tell完整保存base/actual c、a、delta、g、v、s、β/m和before/after u。

数值no-op单独记账：若拟议更新后的controller F64 u完全相同，或同一固定TorchCPU系数映射得到的实际F32 recovered coefficient vector与before逐元素完全相同，不记UPDATED，记TELL_COMPLETED_NO_EFFECTIVE_CHANGE并保存两侧损失/完整梯度与步长/参数/原因。iteration及PCG64按完整tell推进，继续另一方向，不因一次zero-gradient终止探索。11 full20资格为UPDATED与NO_EFFECTIVE_CHANGE合计20完整tells，每次48原生行、原数组及数学门不变；boundary/nonfinite/missing等失败不tell、不advance。no-op仅表示参数编码无变化，κgauge导致波形相同而系数不同的情况不据此声称音频变化。旧9的20UPDATED证据和规则保持原样。保持首轮seed至少0.02dB box安全边际。

目标继承原科学含义：tau0.050；对identity目标0及RMS目标+0.050的三模型logmeanexp损失，再平均两参考；三模型×两参考×D0/Canchor softplus护栏外系数2。正则固定为0.001*mean((u−u_initial)^2)，u_initial始终为新的11维seed；raw C目标、guard、regularizer分开记录。最终full Fit的19门、equal-model≥+0.050、feasible排序及fallback规则不变。

## Signal and support policy

实际V3 constructor继承：16k/512FFT/128hop/periodic Hann/center reflect，band[0,500,1500,3500,8000]Hz/reference3，源magnitude activity floor1e-6、flux denominator floor1e-8，positive/negative quantile0.6、temperature0.15、gate及freq/time smoothing3/reflect，remove_per_frame共同频率项，mask3dB，RMS0.0376838172675746/epsilon1e-12/no peak cap/baseline atol2e-5，25fps/640样本完整窗、frame power floor1e-12。新11 STFT Parseval power support floor明确选1e-12，是新方法设计选择，不能伪称V3已有该层。one-sided Parseval DC/Nyquist权1、内部权2；包络在固定有效源transition上算术中心化，invalid为0。

每次forward同时返回rms_reference/envelope_only/shape_only/full四cell，使用同一源、同一κ=min(1,3/(2A+B))，不能分别关分支重跑而声称剂量相同。记录每source A/B/κ/有效κu与κactive比例。该投影在dose-active区域存在共同正比例缩放gauge：共同scale u与反向κ可给出相同有效mask；正则仅锚定未识别尺度，不能说11个绝对幅度均由分数辨识。四cell是固定剂量下的构造比较，后续iSTFT/overlap-add/全句RMS可能产生交互，不宣称可加的独立因果效应。

STFT补偿只保证无tiny clamp时的系数功率关系，不等于最终40ms波形功率守恒。实际资格必须记录supported source/masked功率最小值、全部support/clamp数组且clamp_affected_count=0；否则FAIL。理论mask界不能替代实际核验。

最终波形诊断固定使用原source-only支持，完整保存floor(N/640)窗口的source/RMS/output功率、output/original与output/canonicalRMS比例、source低功率/invalid flags及每cell output failureflags，尾样本数单独报告。V1现有名为valid_source的mask实含output门，必须独立存为legacy diagnostic并禁止用来缩分母。source-supported窗output≤frame floor为失败；源总能量零/非finite或无任何valid source transition为失败。所有source低能量窗口仍保留全窗分母，原TFG评分行和时钟支持不因诊断mask改变。零哨兵明确为invalid，不当真实0比例；每cell实际RMS/peak及输出编码headroom保留。

## Alternatives and consequences

直接z域固定步长会在边界将等效dB扰动压缩约10倍，且把旧dB步长机械带入；逐维clip或反射会改变所声明的成对方向/梯度分母，所以本版本选共同缩步与整体回溯。旧shape scale0.5不能表示K15，不采用；不靠裁剪seed凑域内。common κ保留可核查3dB总mask边界，但存在gauge和分支交互，需完整诊断。

新初始族initial360=一份实际11seed full120+exact240已接受自然/RMS参考；旧initial720仅参考与K15谱系来源，不能称作11评估。初始seed可完整但NOT_ADMITTED以继续训练，失败/缺行阻断。后续20pair960实际候选、四full120中心480及final720完整门与参考共同支持按新schema封存。三模型真实容量/source/runtime/进程与CPU共享波形资格仍须独立通过，SOURCE_ONLY不等于execution released。

未来只有实际11 Fit通过才生成portable及冻结真实候选/runtime/newbase360，修复Dev旧固定引用并540NEW；cohort/policy01/ADR031/原自然PCM及原时钟/全部统计门保持，Confirm仍封闭。9科学原件与已接受QA不重跑。关机与归档支线停放，未新增implementation tests。

## Observations

- [decision] 11方法以明确有界pre-kappa dB系数做SPSA，逆tanh传入现头；共同双向缩步和整体dyadic回溯保持可重放方向，旧9源和科学门不变。
- [consequence] 新profile、helper、initial360、selector/controller/packet/renderer适配闭包须独立封存与实际资格；没有11科学收益或训练授权。
- [consequence] 全源窗口分母、output低功率失败、tiny-clamp零数、κgauge和实际RMS/peak必须记录，STFT补偿不得代替真实waveform功率证据。
