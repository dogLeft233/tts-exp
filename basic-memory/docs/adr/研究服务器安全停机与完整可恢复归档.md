# 研究服务器安全停机与完整可恢复归档

## Context

用户已明确要求“请到时候关闭服务器然后歇一歇吧，明天我来重启”。局域网V100 wjj@192.168.50.2:22目前唯一原生训练为coordinator26/session09；科学媒体、原QUEUE和三模型runtime大量位于重启会消失的/dev/shm。远端root空间不足，本地C/E/F也无法容纳完整闭包，B为容量充足的CloudDrive挂载。Linux源树存在Windows大小写冲突和长路径，直接按原名在Windows展开会丢失或拒绝成员。

## Choice and rationale

今晚当前20-pair训练自然结束后，先独立核验121链式events、20UPDATED、无pending/halt/writer.lock、原coordinator与全部子进程退出，再核全部原数组与tell数学并seal journal。四中心、Dev、Confirm及新GPU训练留待用户明天重启并要求继续。真实早期失败则先确认所有writer结束并保留失败/pending及完整恢复闭包，不重新GPU launch。

完整恢复闭包直接SSH二进制流写入B盘create-only TAR，不在远端root或本机小盘暂存大包。保留session/job-control、全部dispatch媒体/NPZ、原自然PCM/frame-map、原QUEUE、package12全部实际source payload、三模型SHM runtime/source/资产、两个venv与两个Conda环境和传递用户目录链接目标。所有regular path含hardlink各自有独立完整body；不以仅manifest、忽略媒体或去重省略body代替备份。

TAR保存原POSIX精确成员名、模式、UID/GID、ns时间、symlink target和hardlink关系；B盘fresh恢复使用确定性短物理路径与精确大小写敏感POSIX member→physical path映射。每个body实际展开、重新打开、核bytes/SHA及完整路径/类型集合，所有执行来源pin经映射绑定实际恢复body。这样避开Windows名称限制，同时保留明天重建原Linux绝对SHM根的资料。Windows材料化本身不是Linux可运行环境；实际Linux重建和cloud sync须独立记录。持久系统/usr、/lib、/lib64、/opt外部依赖显式列出及核验，不能称已嵌入包。

归档前与完整恢复后/关机前分别取得fresh ROOT特权ALL_UID进程资格，扫描cmdline/cwd/exe/fd/maps的可用channel并核双快照及精确PID/start/UID/class。实际宿主证实PF_KTHREAD正常无exe且其他channel可读空；只允许稳定PF_KTHREAD typed exe ENOENT，其他缺失/权限/竞态failclosed，不能泛化跳过transport或自身。初始scan是绑定授权与inventory的时点证据；最终scan单独保存，不称连续无人写入或中途修改原proof。

whole archive SHA、全部member type/mode/bytes/body SHA、fresh完整restore、执行source pins与原绝对SHM路径可重建资料全部合格后，才按用户已有授权正常关闭服务器。既有凭据仅经私有PTY无回显sudo prompt的stdin，不入文件/argv/BM/日志，不改sudoers。保存sudo接受/关机消息和后续外部SSH22不可达；单独断连不足以判定关机。实际关机后Task/HANDOFF标await_user_restart并暂停既有tfg heartbeat。

## Alternatives and consequences

立即关机将丢失尚未归档的SHM科学原件；只存manifest或路径不能恢复媒体和runtime。按原Linux名字直接Windows展开会遇已实测的casefold和长路径冲突。把大包先留远端root或本地C/E/F不满足容量门，故采用B完整包与短路径全body恢复。把B写入成功等同云同步、把Windows恢复树等同Linux环境，均缺少对应实际证据。

该选择增加完整body写入、读回和恢复核验时间，不能再沿用旧13GB估计或旧ETA。任何归档、身份或恢复门失败，保持服务器和科学原件并报告具体原因。科学协议/包/原自然PCM/原时钟、cohort/policy01/ADR031及全部效果准入门不变；后续明天仍沿initial720→20SPSA→四full120中心→final720→portable→sealed Dev/Confirm，完整9门失败继续独立11参数方法。

## Observations

- [decision] 当前20轮自然终局并完成独立全数学/seal及全部恢复门后正常关机，实际off后await_user_restart并暂停tfg。
- [rationale] SHM易失而科学原件与原执行来源必须可恢复；完整TAR与短路径全body映射同时满足容量和Windows名称约束。
- [alternative] 即刻关机、仅manifest备份、省略媒体/runtime或literal Windows restore均未满足可恢复闭包。
- [consequence] 保存完整archive/member/fresh fullrestore/source-pin与原路径重建证据；cloud sync、Windows材料化和Linux实际恢复资格分开。
- [consequence] ROOT特权扫描仅为明确时点资格；密码只经私有PTY stdin，停机消息与外部端口关闭需实际保存。
