# 统一选择输入分离初始与候选数组

## Context

实际index08一次build-index完成，完整11,106,501B/raw9652100422125348ab3a63b103368d9929d4fc6079e018d91c2fd462e48ec26f/self079cd9c4afe809c3f5e54d79a790fe7b3fcd8337854d97c731df015e1c86b659。ROOT独立完整transport/40proposal/4center/全部11617引用及1440候选NPZ-map来源QA通过。原files表9864项包含初始720 NPZ和720 frame-map，合计2160各类；冻结ingest07在读取候选时要求恰好1440。初始验证通过pinned initial index自身的initial_files完成；候选不应混入初始角色。

## Choice and rationale

保留原index01及所有科学原件，使用显式、可复现、create-only的投影适配器生成index02。仅从top-level files剔除与精确pinned初始index文件表完全对应的720 raw_matrix_npz及720 official_source_frame_map。ROOT和独立Fit审阅已确认1440个IDs均未被44个point/block或top-level输入ID引用。初始index完整body/pin仍保留，初始720通过它的transitive closure照常验证；其他files、40proposal、4center和所有字段保持相同。

冻结ingest07/finalizer03/selector06、评分门、原PCM/clock、cohort/policy01/ADR031不改。新index02采用原序、sort_keys/indent2/UTF8/noNaN/newline，只重新计算index自身hash。ROOT独立预期9868413B/raw2607e38cedc4de963f57b2d127c446af4cd7871f9771a158415a346f5c1b5679/self598347850e11a353b29bf8dd585982855bb7390dfbef8e8495770f10009cc682，8424 files/1440候选NPZ/1440候选maps。

## Alternatives and consequences

直接执行当前finalizer会在确定的2160≠1440门失败；修改ingest收宽分母会混淆初始与候选并改变冻结执行来源；重跑builder或覆盖index01会消耗不必要工作并损失原始证据。因此采用窄范围输入适配，执行前另审适配器来源和完整差分、单次release；实际index02完整capture和ROOT QA通过后另绑定finalizer。投影是工程修复，没有科学效果结论。
