---\ntype: decision\nstatus: open\nproject: tts-exp\ndecided: 2026-10-12T14:26:45Z\n---\n\n# Explicit11 routing before another GPU sweep\n\n## Decision\n\nAfter two complete explicit11 initial360 sweeps, evaluate a fixed model-routing hypothesis on an independent holdout before launching a third GPU sweep.\n\n## Context\n\nThe zero-envelope coordinate produced equal-model full Δ(candidate−RMS)=+0.008278 and guard20 Δ=−0.010243. Adding the frozen anti-symmetric transition envelope (+0.25 dB on positive flux, −0.25 dB on negative flux) improved these to +0.014598 and −0.002323, with Ditto guard20 improving from −0.029825 to −0.012072 while Wav2Lip guard20 became −0.024014. A post-hoc routing arithmetic suggests Wav2Lip→zero-envelope, MuseTalk→envelope, and Ditto→RMS fallback would yield full +0.018632 and guard20 +0.006314, but this estimate uses the same 40×3 cohort and is exploratory.\n\n## Rationale\n\nA third full sweep would cost roughly 85–95 GPU minutes and would optimize against the same cohort without resolving whether the routing generalizes. A small, independently frozen holdout tests the practical question directly while preserving the original PCM, clock, model roster, and RMS comparison.\n\n## Alternatives considered\n\n- Launch a third envelope magnitude/sign sweep immediately: deferred because the current guard margin is small and model-specific.\n- Treat the post-hoc routing arithmetic as a confirmed result: rejected because it reuses the selection cohort.\n- Stop after the two sweeps: rejected because a holdout can still establish whether a usable model-aware head exists.\n\n## Consequences\n\nThe two explicit11 runs remain the complete exploratory evidence. No third GPU job is authorized until a holdout inventory and fixed routing packet are available. If no reproducible holdout exists, report the routing as exploratory and avoid claiming a general method.\n\n## Affected artifacts\n\n- /dev/shm/native11_fallback_initial360_attempt04_final_attempt02_byteshex/results.jsonl\n- /dev/shm/native11_env_pos025_neg025_initial360_attempt02/results.jsonl\n- HANDOFF.md\n- Basic Memory task 开发跨 TFG 的自然音频增强头\n
