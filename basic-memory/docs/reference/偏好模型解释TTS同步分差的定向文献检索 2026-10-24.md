# 偏好模型解释TTS同步分差的定向文献检索 2026-10-24

用户询问是否可以训练类似 reward model 的偏好模型来解释 Qwen 1.7B 与 0.6B 的归一化后 Sync-C 差异。本轮仅定向检索与方案判断，没有训练、下载部署或调用外部模型处理项目音视频。

结论：有相邻成熟方法。最贴近问题的是从配对表示差异中发现可解释特征，再预测偏好，最后独立验证特征。单独训练黑箱奖励模型只能学会排序，不自动解释原因。SyncNet 标签学习的是评价器排序；人类同步偏好标签才可研究感知排序；两者应分别建模。预测成功依然不等于因果解释。

## 检索范围与阅读边界

2026-10-24，使用网页检索与作者论文/会议网站原文，查询包含 interpretable reward model、concept bottleneck reward model、preference data explanation、speech preference explainable、audio visual synchronization reward。优先阅读方法和限制相关章节。这是问题驱动的定向检索，不是系统综述，不声称检索穷尽、论文完整精读或首次方法。仅保存文献链接与阅读判断，未下载全部PDF，也未复现论文。

## 对现有证据的定位

已读研究地图、实验指令和三处短语核对正式笔记。当前没有稳定跨来源的“1.7B总更好”：两批方向不同；三处短语是事后案例，S0002排除自动末字区间后第三draw翻负；S0014没有找到跨三draw重复的明显动作缺失。这使自动发现并验证差异有价值，但4句28音频和20来源不能视为大规模独立偏好训练集。重叠滑窗及同来源三次生成不增加同等数量的独立来源。

## 建议的最小路线（仅建议，未执行）

1. 首先限定问题为“哪些可观察差异能预测现有官方Sync-C排序”，保持人类嘴型同步偏好为另一个需要独立标签的目标。短语局部对比度与整句官方Sync-C分开，不混作标签。
2. 使用共同冻结编码器表示每条音频，必要时加视频运动及音视频关系表示；不能直接相减两个不同TTS模型未经对齐的隐藏空间。优先试小型正则化成对预测器，比较旧手工声学特征、音频表示、视听表示等。任何特征选择/标准化/稀疏字典训练都只能在训练折内完成。
3. 同来源全部draw/短语放同折；同文本和说话人重复也审计并分组，交换A/B顺序检查一致性；使用同一模型不同draw的比较降低“认模型就赢”的捷径。保留连续分差并预设近零/不确定样本规则，不默认微小差异是可靠偏好。
4. 现有新旧两批均被反复查看，分组交叉验证只作为探索；不能重新称为未触碰确认集。需要新的未分析来源验证才可推进泛化结论。
5. 若共同表示在组外无法胜过多数类/旧特征基线，先不训练大RM或SAE，排查表示、标签稳定性、支持量；该失败也不否定所有机制。
6. 若有稳定预测信号，再学习少量稀疏特征或概念瓶颈，抽取高低激活原始片段，由不知道分数/模型身份的评审命名与核验。不要先展示分数让模型事后编理由。
7. 特征必须能预测增益的正反例，不只是区分TTS型号。解释模型与原SyncNet的归因分开；attention/SHAP只能为替代模型提供候选线索。
8. 最后只对1–2个得到验证的新候选做局部可控反事实：约束内容/时间与其他声学变化，设置破坏程度匹配的对照，尝试反向或恢复操作，并观察原评分及独立视觉/人类端点。单纯破坏后掉分不足以解释自然优势。概念数值干预不等于真实声学干预。

建议的研究贡献是“识别哪些可验证的声学/视听因素预测或造成评价器排序，并检验与人类同步判断是否一致”，不是仅新训一个RM或画注意力图。本轮检索未找到直接闭合本项目特定Qwen规模差异解释的工作；这不是新颖性证明。

## Observations
- [evidence] WIMHF与VibeCheck直接研究从配对数据发现差异并检验偏好预测；ArmoRM提供属性分解；AVC-Reward提供视听事件定位理由。
- [limitation] 文献中的可解释偏好预测不自动给出生成器或评价器的因果机制；文本论文向中文音视频迁移未经验证。
- [recommendation] 先做冻结表示的小型成对可预测性检查，成功后才考虑稀疏概念发现；当前未授权或启动训练。
- [scope] 本轮保存论文入口、选读方法与适用边界，未下载全部PDF、未复现论文、未使用项目私有媒体调用外部模型。
