# I2V口型同步模型调研 2026-10-30

问题是为 tts-exp 寻找比 Wav2Lip 更新、能接受单图和既有语音、适合批量自然/TTS配对实验的 TFG。本文是官方资料调研和推荐，不是本项目新模型实测。🔄 表示候选待验证，不代表部署完成。调研截至2026-10-30，速度均保留作者条件。

## 推荐

🔄 LiveTalk 是新增候选中适合先做24GB卡速度smoke的选择。官方为Wan2.1 1.3B的四步蒸馏，接受图片、WAV和prompt；README称约20GB推理显存，测试过4090/A800/H800。官方宣传24.82 FPS和0.33秒首帧延迟，不能据此保证3090速度；公开脚本暂不支持流式I/O，输出16FPS，须与吞吐率分开。它强调交互速度，尚不能断言中文Sync-C高于InfiniteTalk。[官方仓库](https://github.com/GAIR-NLP/LiveTalk)

🔄 AptAvatar 是同步优先的探索候选。2026-06-29公开代码，使用两步学生和chinese-wav2vec2-base。作者内部720p短片表给出AptAvatar Sync-C 7.865/Sync-D 7.739、InfiniteTalk 7.172/8.010、SoulX-FlashTalk 7.743/7.912；仅同表协议可比，非本项目结果，数据与独立复现不足。GitHub约233星，是早期候选。README仍写待发布，但官方HF文件树已有8个模型分片和54.5GB总资产；文件存在不等于本机已下载验证，也不是所需显存。[官方仓库](https://github.com/TaoLiveAIGC/AptAvatar)、[作者模型卡及评测表](https://huggingface.co/TaoLiveAIGC/AptAvatar)、[权重文件树](https://huggingface.co/TaoLiveAIGC/AptAvatar/tree/main)

🔄 LongCat-Video-Avatar1.5 于2026-05-21发布，支持图像+既有音频+文本、单/多人及长视频；将Wav2Vec2换成Whisper-Large并使用DMD2八步蒸馏，值得覆盖与旧模型不同的音频条件。母仓库约9.3k星，包含通用Video及Avatar，不等于Avatar1.5使用量。它适合质量/音频编码差异对照，但大型底座加八步不保证在单24GB卡快过现有模型；先测加载、耗时、显存。作者称同步改善，不等于必胜InfiniteTalk。[官方仓库](https://github.com/meituan-longcat/LongCat-Video)、[官方模型卡](https://huggingface.co/meituan-longcat/LongCat-Video-Avatar-1.5)

## 已有或次优候选

✅ SoulX-FlashHead Pro 与 EchoMimicV3-Flash 已有本项目报告76、77，Echo另有报告78配置敏感性，不作为全新候选。FlashHead Lite可作同家族速度对照：官方README报告Lite96FPS单4090，Pro10.8FPS单4090；Lite不是Pro的等质量加速。论文v1对效率硬件写H20，与README不同，不拼接成同机实测证据。[FlashHead官方仓库](https://github.com/Soul-AILab/SoulX-FlashHead)、[论文v1](https://arxiv.org/html/2602.07449v1)

🔄 MuseTalk1.5 于2025-03-28发布，引入sync loss等训练改进，支持静态图，但主要是在256×256脸部区域单步重绘；可作为高效同步基线，不能当完整自然头动I2V的同类替代。官方30FPS+V100说法是项目性能声明，不保证本机整段含前后处理速度。[官方仓库](https://github.com/TMElyralab/MuseTalk)

🔄 Sonic 是CVPR2025完整单图+音频模型，官方代码权重、ComfyUI生态已有，仓库约3.3k星，官方测试32GB卡；不是实时速度路线，作为成熟学术对照比解决当前推理慢问题更合适。[官方仓库](https://github.com/jixiaozhong/Sonic)

🔄 FLOAT 是ICCV2025单图+音频方法，在运动latent而非像素latent做flow matching，适合增加架构多样性，已有官方代码权重；其优势是效率与表情联合建模，不能从摘要推出本项目中文同步必胜。[官方项目页](https://deepbrainai-research.github.io/float/)、[官方代码](https://github.com/deepbrainai-research/float)

🔄 TalkLikeYou 是2026年10月新工作。官方示例采用一阶段18维唇部运动生成，图片的音频头动由Ditto提供；流式demo声称3090上30+FPS、<4GB。约40星，先按前沿候选而非常用成熟基线看待，组合系统也要单列。[官方仓库](https://github.com/BQ-Wang0511/TalkLikeYou)

🔄 LiveAvatar和SoulX-FlashTalk虽强调实时，但宣传分别基于多H800及8×H800等条件；不把机房多卡实时移植为单3090实时结论。[LiveAvatar](https://github.com/Alibaba-Quark/LiveAvatar)、[FlashTalk](https://github.com/Soul-AILab/SoulX-FlashTalk)

## 实验选择建议

新增两模型时，先LiveTalk检查速度，再AptAvatar检查同步；资源允许再加入LongCat1.5作质量与音频编码对照。若优先成熟生态，可先选LongCat1.5，但须接受速度不确定性。若只要求静态脸说话，MuseTalk1.5应单列高效基线。

同一批自然/TTS音频、同一图片、冻结prompt/seed/电平；记录冷启动和热推理耗时、峰值显存、视频原生fps、失败率、Sync-C/Sync-D及盲看。16FPS转25FPS属于派生评分协议，不能仅改容器fps导致时长改变。速度、Sync-C和人类同步质量分别解释，不按本批分数反复调参数。

## Observations

- [finding] 当前证据未确认单卡速度、中文同步、完整I2V和社区成熟度四项均占优的新模型。
- [recommendation] LiveTalk偏速度，AptAvatar偏同步探索，LongCat1.5偏较成熟大模型对照。
- [boundary] 作者表格、仓库星数和demo不是本项目复现；本次未登录服务器、下载权重或执行推理。

## 公开榜单筛选补充（2026-10-30）

用户明确要求开放权重、本地部署、单图+已有音频，并希望从公开榜单挑靠前模型。以下只是公开排名与部署证据筛选，无新增推理。

[StreamEval](https://streameval.ai/) 的 Avatar Performance 更接近给定语音的表演任务：LiveTalk1.3B全榜第2、Overall75.85/A–V Sync86.44；AptAvatar14B第3、70.37/98.89；QuarkLiveAvatar14B第4、62.83/98.89。三者均有本地权重；第一名Vidu S2在本轮[官方仓库](https://github.com/shengshu-ai/Vidu-S)只找到服务/API入口，无公开checkpoint，排除。不能称LiveTalk在所有TFG或中文唇形上开源第一，只能说在这个赛道已评模型中Overall最高的开放权重候选。

StreamEval Dialogue另一个任务中，AVTR-1第3（开放权重模型最高）、84.14/A–V69.38；MuseTalk1.5第4、79.66/38.09。两者不能与Performance跨赛道排一张总榜，MuseTalk是局部重绘。AVTR-1已在本项目历史中测试过，不自动算新增候选。

重要限制：[评分协议](https://github.com/StreamEval/StreamEval/blob/main/docs/evaluation.md)明确 A–V Sync 为provisional，基于嘴部开合/音频包络相关与偏移范围，并非SyncNet Sync-C。校准和完整执行结果未随发布提供；总榜还混合画质、稳定、执行和身份指标，包含自定义人像+5分。只能作为候选线索，不能直接视为独立精细音素同步证明。

部署条件改变排序：[LiveTalk官方](https://github.com/GAIR-NLP/LiveTalk)约20GB推理，优先单24GB卡smoke；[AptAvatar榜单适配](https://github.com/StreamEval/StreamEval/blob/main/models/selfhost/aptavatar/README.md)使用4GPU，不能从两步蒸馏推出单24/48GB可跑或实时；[Quark官方](https://github.com/Alibaba-Quark/LiveAvatar)称FP8可用48GB，但实时45FPS来自多H800，单卡须另测。AVTR-1的[官方模型卡](https://huggingface.co/avaturn-live/avtr-1)报告4060Ti每5帧166ms，适合作轻量完整头像对照，且有研究/非商用组件条款。

另外找到[Tight Studio部署测评](https://github.com/tight-studio/open-source-talking-avatar-benchmark/blob/main/REPORT.md)：单一人像与3.63秒英语、各模型不同GPU/配置、冷启动计时，无Sync-C或盲评排名。因此仅用于部署参考，不作为“最高同步模型榜”。[MoChaBench](https://github.com/congwei1230/MoChaBench)有SyncNet榜但模型覆盖较旧、偏电影单/多人任务；[THEval](https://newbyl.github.io/theval_project_page/)有评价研究，尚不提供适合本轮2026候选的统一最新公开排名。

推荐更新：LiveTalk是最有榜单支持且资源条件明确的新增首试；AptAvatar是同步探索候选，先审资源；QuarkLiveAvatar仅作较大显存候选。若限定单24GB并要求三个全新高排名模型，目前证据不足，不能凑数。LongCat1.5没有在本次主要StreamEval榜上，保留架构对照而非宣称榜首。

## 按Sync-C筛选的修订（2026-10-30）

用户进一步明确要Sync-C榜。没有找到覆盖最新全部模型、独立统一运行的成熟持续榜；可追溯的主要是作者同协议比较表。公开[MoChaBench](https://github.com/congwei1230/MoChaBench)虽有SyncNet榜但覆盖旧，不以StreamEval A–V代替Sync-C。

最新且资源匹配的新增候选为🔄TalkLikeYou。[论文表1](https://arxiv.org/html/2610.06658v1)作者比较HDTF/CelebV-HQ：TalkLikeYou8.730/7.970、Sonic8.620/7.680、SadTalker7.660/6.360、Hallo2 7.330/6.320、FLOAT7.040/6.440、Ditto5.230/5.800。仅同表排名，不可与其它论文HDTF直接拼接。两数据集第一仅限此作者所比六方法。论文表2模型32.43FPS，未将该数与demo3090绑定。[官方代码](https://github.com/BQ-Wang0511/TalkLikeYou)推荐Linux、>=12GB GPU；另demo报告3090 30+FPS/<4GB，不含加载等。单图使用预置habit ID，不强制参考视频；当前发布版唇部由TalkLikeYou生成、头姿由Ditto提供。代码与[权重](https://huggingface.co/doubi-killer/TalkLikeYou)已公开，研究组件许可保留。论文与现版pipeline等价性尚待复现；仅约41星，不能称常用成熟模型。

[AptAvatar论文表1](https://arxiv.org/html/2607.24013v1)作者自建100条15秒短视频/20条1分钟长视频上，Sync-C短/长：AptAvatar7.865/8.398，FlashTalk7.743/7.976，InfiniteTalk7.172/8.178，QuarkLiveAvatar5.986/6.654，Wan2.2S2V5.626/6.173，LongCat1.5 4.140/7.492。短片顺序与长片不同，不给单一混合名次；AptAvatar两组第一。NFE为作者表120/80/8/4/4/2，不等于去噪步数、倍速或本机成本。属于作者评测而非独立公榜。

[LiveTalk论文表1](https://arxiv.org/html/2512.23576v1)：同HDTF的OmniAvatar14B6.290、Hallo3 6.010、LiveTalk4.500、OmniAvatar1.3B3.850、FantasyTalking2.920、AniPortrait1.170。因此此前依据StreamEval综合排名的优先级不能推广成Sync-C优先级。

推荐修订：高Sync-C+单3090速度的新模型先TalkLikeYou；成熟对照可看Sonic但慢且官方32GB测试；大模型同步候选AptAvatar/FlashTalk，资源另审。LiveTalk保留速度对照，不称高Sync-C首选。无本次部署或新实验。
