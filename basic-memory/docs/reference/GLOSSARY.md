# TTS 差方向实验术语

本术语表区分声音差异、生成变化和评价变化，不记录实现参数。

## Language

**来源语句**：
一条自然发声及其同文本TTS变体共同对应的来源。多个变体不构成多个独立来源。
_Avoid_：把draw数称为独立样本数。

**静态差**：
对应音素在共同相位表示中的TTS−自然平均特征偏移。
_Avoid_：质量方向、已确认增强方向。

**动态差**：
对应音素去掉各自相位均值后的TTS−自然轨迹差；迁移时保持实际特征扰动零均值。
_Avoid_：完整发音动态、时长迁移。

**联合差**：
静态差与动态差共同施加的特征修改，不默认与单独干预能量相等。
_Avoid_：未经验证的协同机制。

**音素相对相位**：
一个音素内部从开始到结束的相对位置，独立于该音素的绝对起止时刻和时长。
_Avoid_：已经验证的声学阶段对应。

**共同干预支持**：
静态、动态和联合条件共同满足要求、实际允许修改的音素与帧集合。
_Avoid_：把不同覆盖率的条件直接当作同范围比较。

**投影分数**：
表征在指定差方向上的位置。计算该分数不会改变声音或视频。
_Avoid_：投影增强。

**方向干预**：
沿指定差方向修改表征的操作。它是否产生预期声音变化或下游收益，需要分别验证。
_Avoid_：自动TTS化。

**零偏移重建**：
编码后不修改特征、直接解码得到的声音，用于观察重建链本身的影响。
_Avoid_：无损原音。

**生成端评分响应**：
固定评分音轨，只改变生成视频时出现的评分变化。
_Avoid_：未经独立验证便称真实口型收益。

**评分音轨响应**：
固定视频，只改变评分音轨时出现的评分变化。它可能包含音轨时序或可辨识性变化。
_Avoid_：直接称评分器作弊、纯评分偏好。

**原生配对总变化**：
各条件生成视频配各自驱动音轨时的评分变化，包含生成、音轨及两者交互的影响。
_Avoid_：纯生成增益。

**自然音轨迁移评分收益**：
候选视频统一配回原始自然音轨后，相对指定基线视频的评分提高。
_Avoid_：未注明基线的替换增益。

**真实同步收益**：
在目标音轨下，口部发音事件或感知同步准确性的改善，需要独立于单一评分器的证据。
_Avoid_：仅凭Sync-C提高判定真实收益。
