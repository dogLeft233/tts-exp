# 工具指令

本笔记覆盖 tts-exp 项目里工具/部署备忘的规范。

## Folder map

- `ToolNotes/` — 工具笔记,标题 = 工具或主题名
- `docs/deployment/` `docs/reference/` — 仓库里的部署文档(只读镜像,不写)
- 写入用 `directory="ToolNotes"`(大写 T);permalink 全小写是正常现象,严禁照抄进 directory 参数

## Schemas in play

| 类型 | Schema | 必填观察 |
|:--|:--|:--|
| ToolNote | `Schemas/ToolNote.md` | tool |

## 命名约定

- 工具笔记: 工具名或主题名(`SyncNet 本地部署`、`Basic Memory 技能`)
- 状态词汇: `active` / `deprecated`

## 工作流

1. **新工具**: search → 建 ToolNote 笔记(active)
2. **环境问题解决后**: 更新 gotchas(如果已有笔记)或新建 Pitfall
3. **工具废弃**: status → deprecated,仍保留内容供历史查询

## 领域规则

- 工具笔记记部署要点+踩坑,不重复仓库 deployment 文档全文 — 给指针
- 环境特定坑(代理、CUDA、驱动)优先记 Pitfall,便于搜索
