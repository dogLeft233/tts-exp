# 决策指令

本笔记覆盖 tts-exp 项目里决策记录(ADR)与踩坑(Pitfall)的规范。

## Folder map

- `Decisions/` — 决策笔记,标题 `ADR-{NN} - {slug}`(与仓库 docs/adr/ 编号对齐)
- `Pitfalls/` — 踩坑笔记,标题 = 陷阱的简短描述
- 写入用 `directory="Decisions"` / `directory="Pitfalls"`(首字母大写);permalink 全小写是正常现象,严禁照抄进 directory 参数

## Schemas in play

| 类型 | Schema | 必填观察 |
|:--|:--|:--|
| Decision | `Schemas/Decision.md` | date, status |
| Pitfall | `Schemas/Pitfall.md` | area, symptom |

## 命名约定

- ADR: `ADR-{NN} - {kebab-slug}`;轻量决策可用描述性标题
- 踩坑: 用户会搜的短语,如 `SyncNet 短音频无输出`
- 日期格式: `Month D, YYYY`

## 工作流

1. **决策**: search → 建 Decision 笔记 → status proposed → 采纳后 accepted;被替代的标 superseded 并链接替代者
2. **踩坑**: 出问题时立即记(area/symptom/cause/fix),下次同症状搜索即得

## 领域规则

- 决策被替代时,旧笔记 `- replaces [[新决策]]` 关系保留历史
- 踩坑比决策更宽容:哪怕只记 symptom 也有价值,不要求一次写全
