# 文献指令

本笔记覆盖 tts-exp 项目里论文阅读笔记的规范。

## Folder map

- `Papers/` — 论文笔记,标题 = 论文标题
- `Research/` — 研究主题枢纽(论文归属地)
- 写入用 `directory="Papers"` / `directory="Research"`(首字母大写);permalink 全小写是正常现象,严禁照抄进 directory 参数

## Schemas in play

| 类型 | Schema | 必填观察 |
|:--|:--|:--|
| Paper | `Schemas/Paper.md` | status |

## 命名约定

- 论文: 论文原标题
- 状态词汇: `to-read → reading → read`;被项目引用的标 `cited`

## 工作流

1. **新论文**: search(防重复)→ 建 Paper 笔记(to-read)
2. **读完**: status → read + key_insights(每条一行,与项目相关)
3. **链接**: 每篇论文 `- part_of [[Topic]]` 挂到研究主题

## 领域规则

- key_insights 只写与本项目相关的要点,不写论文摘要
- 论文与主题枢纽双向链接(主题 hub 里也列出其论文)
