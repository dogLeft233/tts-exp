# 实验指令

本笔记覆盖 tts-exp 项目里实验笔记的规范。实验笔记是项目的核心记忆:记录测了什么、数据是什么、关键数字、结论。

## Folder map

- `Experiments/` — 实验笔记(正式家)。编号报告镜像在 `docs/experiments/` 保持只读,记忆侧放这里
- `Research/` — 研究主题枢纽与分步研究报告
- 写入用 `directory="Experiments"` / `directory="Research"`(首字母大写);permalink 全小写 (`tts-exp/experiments/...`) 是正常现象,严禁照抄进 directory 参数

## Schemas in play

| 类型 | Schema | 必填观察 |
|:--|:--|:--|
| Experiment | `Schemas/Experiment.md` | status |
| ResearchTopic | `Schemas/ResearchTopic.md` | status, question |

## 命名约定

- 实验: `{NN} - {kebab-slug}`(与仓库 docs/experiments/ 编号对齐)或描述性标题(下游评估等)
- 研究枢纽: 主题名,如 `TTS Feature Alignment and Duration Model Research`
- 研究步骤: `Ralph Step {N} - {描述}` 或类似分步命名
- 日期格式: `Month D, YYYY`(如 August 12, 2026)

## 工作流

1. **新实验**: search → 建 Experiment 笔记(planned)→ 跑实验 → 更新 result/conclusion/status
2. **实验结论**: 必须有 result(如 ΔSync-C = +1.25)和 conclusion 观察;完整报告链接写在 report 观察
3. **研究步骤报告**: 链接回主题枢纽(`- relates_to [[Topic]]`),主题枢纽链接步骤

## 领域规则

- 实验结论与文档镜像不重复:记忆笔记记要点+指针,全文在仓库
- 实验用中文写(项目文档语言)
- 负面结果也要记 — 负面结论防止重复实验
