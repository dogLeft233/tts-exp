# 模型与评分器使用清单

整理日期2026-11-02。✅表示有对应历史实验／部署证据，不表示服务此刻在线或所有配置都已评分。精确commit、checkpoint SHA、输入与参数以各run的manifest/protocol为准；仅同名不能合并版本。

## 九评分器

|端点|主结果含义／协议边界|
|---|---|
|SyncNet V2|Sync-C=B−Dmin、Sync-D=Dmin与offset；高C可能背景距离上升。官方pipeline内部MP3和约69ms延迟按run记录；无损输入不等于全链无损|
|CoGenAV|保持原生前端、脸检有效门与距离数组；不可测不补分|
|PEAVS|原生回归端点；batch依赖及旧时移控制不足保留，不能直接当感知真值|
|SyncReward|版本/FP32或BF16按run分别；部分旧时移控制未通过|
|AVS_u|原生共同支持与质量门；DyStream部分脸检不可测|
|MTDVocaLiST|主表用官方检索K5口径，不混旧logit；部分队列移音响应未达门|
|VocaLiST|原版官方Release、K5与完整支持；不等同MTD版本|
|Synchformer|原生固定窗口P0；概率差常用百分点，不与Sync-C单位混合|
|SparseSync|原生固定窗口P0；天花板与极端来源影响单列|

每个分层内九项联合Holm校正；单项95%CI不跨零不等于通过Holm9。不同指标缺测导致有效说话人不同，不作简单“九项投票”。历史中文Wav2Lip未发布统一Holm9的地方为NA，不写成不显著。MTD/Voca/Synchformer/SparseSync的精确口径随正式修正链读取，见报告68–74和75–84。

## 编码器与方法模型

已用HuBERT、XLS-R、WavLM、wav2vec2、Whisper，以及报告52/53所列多路预训练编码器；MFA用于强制对齐。各自是表征、生成前端、监督或度量角色，不能视为TFG模型数。AVE是SyncTalk音频特征路径，May/Patrick是身份数据，不是数据集或TTS模型。

旧waveform enhancer、feature-head、alignment policy、cross-attention、Ridge/L6校正头及shared_audio_head.pt均保留原科学状态。FIT_ONLY、HOLD、NO_GO、PAUSED和完成阴性不相互替代；模型感知路由不是已证实的通用增强器。
