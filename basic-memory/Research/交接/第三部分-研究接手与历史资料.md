# 第三部分 研究接手与历史资料

## 1. 已被收窄或修正的旧说法

早期“英文不成立”不再作为总判断。LibriSpeech因来源重合风险不用于独立正负推断，LRS3和EARS后来有英文正差，其他小批负结果保留其条件范围。

早期将自然和TTS交叉换轨后的强烈下降解释为评分器偏好，证据不足。报告44显示同类声音不同发声也会大幅降分；报告45说明局部时间修正可以恢复部分配对，但覆盖不足。相同文字和总时长不能证明具体发音时刻相同。

早期均匀切片得到的部分发音分离或强关联已被真实发音时间分析修正；报告13撤回旧强相关，报告15没有找到稳定逐句分差预测指标。报告41的MuseTalk失败包含输入与观察位置错配，报告42已修正；功能动作改变仍不是同步准确度证明。

MTDVocaLiST旧自定义连续分数已被报告69指出不能当作官方检索指标，正式比较读报告70。PEAVS、SyncReward等的已知控制不足和批量依赖不得因计算完成而省略。

May的TTS训练分数下降必须与报告66的数据时序缺陷一起读。低尺度训练的单次正差也必须与报告67的反向无添加噪声结果一起读，不把局部结果升级为通用训练建议。

## 2. 当前暂停、未完成及仅有方案

HDTF20 TalkLikeYou由用户暂停。已经完成80生成、120个SyncNet评分，但九项及完整归档未闭合，不能恢复评分，也不能形成九项最终结论。

PC-Talk与DyStream的Chinese-LiPS全量生成、九项计算和本机自动核验均已完成，完整视频检查及正式最终报告待补。旧任务记录的运行中状态不表示仍有评分进程。DyStream冻结报告有沿用PC旧结果复用的文字，真实209视频为DyStream新生成；正式报告应纠正文案，冻结原件保留。

PC-Talk运动模板比较尚未执行。现有全量结果来自官方单图、未传运动参考的固定姿态路径；不能写成论文动态模板条件。DyStream用HDTF人物图配Chinese-LiPS声音，也不是已经完成HDTF音频基准。

Patrick同初始化复跑及旧增强路线保留原暂停边界。逐发音差方向仍停在拟合侧内容质量检查，开发和确认数据不动。二百人自然声音准备完成不等于4200个完整合成媒体已经完成。

## 3. 技术失败怎样保留

人脸无法检测、视频太短、输出没有正常停止、训练出现非有限数值、时间网格验证失败和依赖阻塞分别说明。它们不能直接用来证明研究假设错误。恢复执行时保留失败原件、修复内容和输入身份，不能只留下成功运行。

这次文档整理不连接服务器、不生成声音或视频、不重评分、不训练，也不恢复任何暂停任务。后续是否执行按单独任务授权和服务器要求处理。

## 4. 数据与产物从哪里找

工作资料以项目仓库根目录为基准。数据位置和用途见[[数据与队列使用清单]]，模型输出按results中的模型和运行目录保存。PC-Talk、DyStream全量产物在本机；HDTF TalkLikeYou的完整80个视频尚未全部下载，不能仅凭本机检查点认为视频可直接打开。

历史Windows盘符与旧Linux路径是当时执行位置。恢复时先查统一网盘根与路径映射，不改历史凭据伪造新位置。密码和API密钥不写入交接文件。

## 5. 继续研究前要核实什么

应先判断所用数据是否具有来源独立性、语音内容是否完整、每项比较是否具有相同有效时间范围，以及评分方法能否识别已知错位。确认这些条件后，再讨论能否区分真实同步变化与声音来源引起的额外评分变化。

目前缺少能够覆盖主要比较的合格独立同步判断。更多评分器或更高分不自动填补这个缺口。后续研究方向可以讨论，但本交接不把新建议混入已做实验。

| Wav2Lip 生成，40 人 | 仅替换放大后编码方向 ΔC＝+0.161；仅替换长度 +0.020，前者区间为正、后者跨零 | 方向变化能产生生成端评分响应；限定已测模型 |
| 增益共同方向移植 | 20 人估计、另 10 人验证：共同方向 +0.055，实际 +3dB 为 +0.122 | 复制部分响应；未通过完整等效门，也未证明优于残差 |
| 11 个预训练编码器与 Wav2Lip 参照 | 统一 RMS 后 TTS 编码差异仍存在，方向共性依赖编码器 | 不代表这些方向有利于生成；未逐一生成视频 |
| 同权重开关输入标准化 | 8 路径中 7 个关闭后明显恢复音量响应；W2vBERT 后续逐帧标准化仍抵消 | 处理步骤比“编码器家族”标签更准确 |

编码方向＝向量各维的相对组成；长度＝向量的整体大小，并非音频音量。

入口：[[46-amplitude-gain-independent-validation]]、[[增益共同方向与残差的留出说话人生成验证]]、[[52-encoder-direction-commonality]]、[[53-encoder-input-normalization-ablation]]。仅有“特征差值”不等于已找到“训练有益成分”。

#### 固定粗编码的模型内部技术验证（2026-10-23）

[[固定粗编码的双模型条件补全技术验证 2026-10-23]] 对旧同10人ID首条、draw1验证0.6/1.7自身全码解码与自由／强制粗码生成，均逐值重放通过。两交叉补全保持粗码/EOS/总长，细码改变约92%，但ASR内容保持未确认，修复分词后的MFA中心差p95达120／201ms、最大130／245ms，未通过预设时间门；自动边界不等于人工真实移位。技术接口可用，纯内容／时钟固定假设未获支持，当前HOLD，不进入TFG/SyncNet或训练。先复核既有四格疑似异常词段，不重复旧局部能量损伤路线。

### 四、Q3：训练效应的证据与尚未闭合的解释

#### 4.1 哪些训练结论已观察到？

| 实验 | 结果 | 证据资格 |
|---|---|---|
| Patrick，AVE，三档粗训练，固定自然驱动／评分 | 训练−6／0／+6dB 的 C＝8.213／8.068／7.770；九种同驱动／评分设置排序相同 | [[SyncTalk Patrick coarse10 seed42 27格描述性预览]]；单人单 seed，实际成功更新不等，原 CONTROL_FAILED 保留 |
| May，AVE，三档各 60,000 成功更新 | 固定自然驱动／评分 C＝9.199／8.909／8.568 | [[50-synctalk-may-gain-training-pilot]]；单人单 seed；评分排序不是感知质量证明 |
| May，HuBERT／wav2vec2，归一化开关 | 推理音量响应几乎消除；重建误差未一致改善 | [[54-may-encoder-normalization-pilot]]、[[55-may-gain-normalization-factorial]]；不能称归一化普遍有害 |
| May，归一化后再缩放输入 | wav2vec2 固定推理尺度下 C＝1.626→1.718；HuBERT 指标混合 | [[56-may-postnorm-scale]]；一次先导；不是原录音降低 6dB 的同一操作 |
| May，新噪声实验中的无添加噪声组 | 同批新训尺度 1／0.5，C＝1.714／1.638 | [[67-may-four-noise-training]]；方向与 56 相反，低尺度收益尚不稳定 |

**先核验收益是否可重复，再解释为什么有益。** 56 与 67 的编码特征已有逐值桥接，但训练模型分数不同；跨批初始化、执行版本和数值轨迹还需核对，不能直接称为严格重复失败，也不能忽略反向读数。详见 [[低尺度训练与噪声解释的证据边界]]。

#### 4.2 “低音量等于降噪”目前只得到局部支持

**噪声训练已完成，不能再记为运行中或待做。** [[67-may-four-noise-training]] 新训 18 个模型，每个 12,000 成功 FP32 更新，固定自然测试音频和评分音轨。

- 背景讲话 30dB 条件：标准尺度训练加噪 ΔC＝−0.112；加噪组低尺度减标准尺度 ΔC＝+1.383，扣除无添加组尺度效应后的交互为 +1.460。
- 其余七个噪声／强度条件，低尺度减标准尺度的 C 点估计均为负；部分交互为正，也不代表低尺度模型本身更好。
- 单 May、单训练 seed、每类一个干扰实例、短预算，尚不能确认该大差异稳定，也不能归因于原录音未知噪声。

#### 4.3 哪些机制已定位，哪些仍是假设？

| 解释 | 当前证据 | 应如何使用 |
|---|---|---|
| 历史低音量波形被量化成零 | 57 重放未发现新增波形零点 | 不支持该历史解释；AVE 的 mel 截断另论 |
| 首层 GroupNorm 的数值稳定项引入尺度残差 | 58／62 在所测 HuBERT／wav2vec2、May 片段内，通过干预消除编码响应 | 编码机制已有定位；没有证明该残差导致训练涨分 |
| 低尺度统一压低弱信号／噪声 | 59／61／63／65 的响应依通道、片段、噪声强度变化，有反向条件 | 不支持普遍降噪解释 |
| 人工干扰影响低尺度训练效应 | 67 有一个较大的数值差异条件，但无独立训练重复或总体显著性 | 有针对性的后续核验入口，不是原录音噪声成因证明 |

GroupNorm＝按一组特征的统计量调整尺度；其分母中的 epsilon 是避免除零的小常数。报告 60 的直接换参数同时改变基线，后续解释优先读保持原基线的 62。

### 方法贡献候选：电平鲁棒性（SPEC_ONLY）

2026-10-22 用户授权继续定向检索并形成一页设计，暂不训练。[[电平鲁棒方法的定向文献与创新边界]] 核对 PCEN、ΔLFBE、增强一致性与邻近 TFG 工作：整段标量归一化已保留句内相对能量，不能把“抗电平＋保留相对能量”直接作为创新。条件性候选为冻结 Wav2Lip 的小型残差适配器及输出一致性；价值须体现为相对校准归一化和等预算常规增强更好的口型误差—鲁棒性权衡。[[电平鲁棒口型生成方法最小验证设计]] 先设零训练必要性筛查，再考虑有界小试，包含停止条件。阈值和方法均为 agent 提案，数据资格未核验；本轮无新实验结果，不恢复暂停路线，也未改动三条既有研究问题的证据资格。

**资产核查补充（2026-10-22）：** [[电平鲁棒零训练筛查资产核查 2026-10-22]] 已完成，只读容器/波形/权重与依赖导入，无新TFG生成或训练。现有MEAD50条均W025，不能承诺多人；LRS3有35个足够长度来源组，其中16个通过保守声学峰值门，可提出10个开发来源候选，但独立人/参考脸/姿态/时钟未核验。Wav2Lip等权重可复用。旧LRS3输入QC仅2/8、GRID完整几何3/8失败；后续GRID16eval已完成，只支持较窄相关性端点且不能重置未见。最小设计v2在300输出前增加A0测量资格，不能直接以未校准Q决定方法生死。
