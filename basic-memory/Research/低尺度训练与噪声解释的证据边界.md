# 低尺度训练与噪声解释的证据边界

**已有低尺度训练的正向先导，但后续新训基线方向相反。当前应先确认现象的可重复条件，不能先假定“低音量有利”再寻找解释。**

本页综合正式报告 56、58–63、65、67，不新增实验，不替代原报告。所有训练结果来自 May 单人物、单 seed 和短预算，测试的两个相关片段不是两次独立训练。

## 1. 两个不能遗漏的基线

主推理尺度均为 1，评价音轨固定原自然音频；低／标准训练尺度分别为归一化后乘 0.5／1。

| 批次 | 标准训练 C | 低尺度训练 C | 直接观察 |
|---|---:|---:|---|
| 56，标准模型复用、低尺度新训 | 1.626 | 1.718 | 低尺度 C 较高 |
| 67，无添加合成噪声，两组均新训 | 1.714 | 1.638 | 低尺度 C 较低 |

67 已核验六份无添加噪声编码特征与 56 缓存逐值一致。因此，差异不能简单解释为“换了一套音频特征”。但尚未逐项核对两批训练的完整初始状态、运行时、执行代码与数值轨迹，不能把这张跨批表当严格重复实验，也不能把差异归给某个未经检验的原因。

同 seed、同采样、同更新次数可以减少混杂，不自动保证跨批优化轨迹逐值相同。当前不能给出一般性最优尺度，或断言默认归一化让模型丢失稳定收益。

## 2. 噪声训练实际回答了什么？

67 新训 18 个模型：四类人工干扰×30／90dB 两强度×两尺度，加无添加噪声两尺度。各 12,000 成功 FP32 更新、0 skip，同批初始化、实际采样与学习率配对，测试不额外加噪。

| 干扰 | SNR | 标准尺度下加噪 ΔC | 加噪组低−标准 ΔC | 扣除无添加组尺度效应后的交互 ΔC |
|---|---:|---:|---:|---:|
| 背景讲话 | 30dB | −0.112 | +1.383 | +1.460 |
| 背景讲话 | 90dB | −0.024 | −0.042 | +0.034 |
| 四人混合讲话 | 30dB | −0.010 | −0.044 | +0.033 |
| 四人混合讲话 | 90dB | −0.032 | −0.032 | +0.044 |
| 起伏语音谱形噪声 | 30dB | +0.050 | −0.189 | −0.113 |
| 起伏语音谱形噪声 | 90dB | −0.043 | −0.049 | +0.027 |
| 合成点击 | 30dB | +0.042 | −0.024 | +0.053 |
| 合成点击 | 90dB | +0.115 | −0.253 | −0.177 |

交互＝`(加噪低尺度−加噪标准尺度)−(无添加低尺度−无添加标准尺度)`。它表示加噪改变了多少尺度效应，不等于低尺度模型直接胜过标准尺度。

背景讲话 30dB 是值得核验的条件：C、D0 和嘴部误差的交互方向均有利，但仅有一次训练实例。其余七组低尺度 C 均较低；四人讲话 30dB 等条件虽有正 C 交互，D0／口部误差却恶化。不能只摘录“5/8 交互为正”作为降噪成功率。

SNR＝信号功率与添加干扰功率的比值，越高表示添加干扰越弱。90dB 是极弱人工干扰，不是“已知有害”的标签；无添加组仍含原录音本底，不能称无噪干净语音。

## 3. 已定位的是编码响应，不是训练收益原因

| 链条 | 当前状态 | 入口 |
|---|---|---|
| 浮点波形减半是否让弱值量化成零 | 历史输入未出现新增波形零点；AVE 频谱截断另有观测 | 57 |
| 归一化后幅度是否仍能改变编码 | 所测两编码器首层 GroupNorm 的 epsilon 引入残差；保持基线的干预可将响应消除 | 58／62 |
| 两编码器为何放大程度不同 | 不止首层残差大小；扰动方向、仿射参数与后续路径共同参与 | 60／62 |
| 这种变化是否统一抑制噪声 | 不成立为一般规律；依片段、通道、干扰类型和剂量变化 | 59／61／63／65 |
| 编码残差是否导致低尺度训练收益 | 尚未证明；新训无添加组也未复现先前 C 方向 | 56／67 |

上述编码诊断不包含生成器训练。对 epsilon 的干预不能直接换算为训练涨分的解释比例，也不是部署修改建议。

## 4. 若继续，先验证哪个问题？

**优先问题：背景讲话 30dB 的大幅训练差异能否重复，而无添加组的尺度效应有多稳定？**

先只读核对 56／67 的初始化、训练源码版本、数据与帧／ray 序列、实际更新、EMA 和运行时身份。若可比性仍不足，保留为不同批次结果，不强行归因。

若用户另行授权执行，最小后续可围绕 67 的“无添加／背景讲话30dB×尺度1／0.5”四组做配对重复；固定自然驱动与评分音轨，同时报告 C、D0、嘴部误差及完整距离曲线。新 seed 检查训练波动，独立背景录音检查是否仅某个干扰实例有效；二者回答不同问题，不混为一次确认。

只有先稳定复现干扰损害及尺度交互，才值得进一步解释其编码或优化机制。若大差异不重复，应缩小主张为条件依赖和训练不稳定性，不通过追加扫描挑选阳性。

本页是核验顺序，不是新执行授权；旧暂停训练保持暂停。

## Observations

- [result] 56 与 67 无添加噪声组的低尺度 C 方向相反，跨批训练可比性尚待核实。
- [result] 67 的八个加噪条件只有背景讲话30dB直接表现为低尺度 C 较高；正交互不等于低尺度直接获益。
- [limitation] 编码器 epsilon 机制未闭合训练收益因果链；没有原 May 未知噪声真值或感知收益证据。
- [next_step] 只读核对两批训练身份与可比性，再决定是否值得申请有界配对重复。
