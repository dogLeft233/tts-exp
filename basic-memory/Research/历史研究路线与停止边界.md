# 历史研究路线与停止边界

**本页保留旧路线的研究问题、结果与停止边界，防止把失败方案重新包装成计划。当前问题优先读 [[研究交接总览]]，全部编号入口见 `docs/experiments/README.md`。**

本页从原地图提炼导航，不修改正式实验报告、失败现场或冻结凭据。旧路线有实际阴性、小样本筛查、未完成控制与工程阻塞，不能合并为“所有其它因素都无效”。

## 1. 从 TTS 原生高分到自然音轨迁移

| 路线 | 当时要解决什么 | 实际结果与边界 | 证据入口 |
|---|---|---|---|
| 音素可分性、稳定性、时长 | TTS 是否更易被模型读取 | 有表征与时长差异，但 n=100 可分性指标不能稳定预测逐样本下游收益 | 09、11–15、19–20 |
| phone-local warp、MFA-linear | 将 TTS 发声映射到自然语音时刻 | 所测方案没有保留原生优势；停顿错误可局部修复，但不能闭合整体迁移 | 16–18、31–38 |
| ASR 错误与局部替换 | 识别错误是否定位可改善片段 | 相关性／局部原型与稳定同步收益分开，未形成通用修复器 | `LRS3 ASR-SyncNet correlation result`、`ASR-targeted local replacement prototype` |
| 旧 HuBERT 特征／波形增强头 | 把自然特征推向 TTS 是否带来生成收益 | 有局部特征移动；目标梯度冲突、原生前端差异及泛化门失败 | 21–30 |
| 共享可训练音频头 | 一套增强能否跨三种 TFG | Fit v4 三模型开发结果均低于 RMS；留出 Wav2Lip 接近零且异质 | [[跨 TFG 自然音频增强头的训练与原音换轨验证]] |
| 模型感知路由 | 对少数模型保留局部候选 | MuseTalk 局部小信号；Wav2Lip／Ditto 回退 RMS；仍是原型 | [[模型感知自然音频路由与无损换轨资格验证]] |

自然音轨迁移的正确比较是：用处理后的声音生成，最终与原自然声音配对，并对比原自然声音生成的基线。候选声音与自身视频的高分，不能替代这个比较。

## 2. 原生因素与构音坐标

| 路线 | 已知内容 | 停止／继续边界 |
|---|---|---|
| 分离度、稳定性、局部特征长度分布 | 两人×三模型固定剂量筛查，无因素在同模型两人都通过；可播放谱形波形也未形成一致收益 | [[39-native-input-factor-mechanism-screen]]；小样本筛查，不证明所有同类干预无效 |
| 声源／谱包络联合移植 | 受体时刻、音高、能量保持时，所测 TTS→自然移植相对自身重建下降 | 回到该重建方案与支持集，不归因“TTS 来源本身有害” |
| 口部功能响应坐标 | 自然时刻与模型响应位置不同，输出测量需绑定实际所有者 | [[40-functional-response-coordinate]]、[[41-native-articulatory-response]] |
| MuseTalk 输出所有者修正 | 修正输入行→输出事件关系后两句功能控制成立，但同步端点仍未一致获益 | [[42-output-owned-native-coordinate]]；功能控制≠自然音轨增强 |
| 真实波形实现共同坐标 | 32 参数局部波形族的保存 Jacobian 在线性有界分析中可分开推动三个标量 | [[接收端局部构音响应坐标]]；有限剂量与视频收益未确认，旧任务 paused，不自动扩预算 |

原生坐标的代数纯度，不等于该坐标能由真实波形独立实现；真实波形可实现，也不等于生成口部更准确。

## 3. 评价与来源归因的修正链

- **交叉换轨低分：** [[31-lrs3-mfa-linear-scorer-effect]] → [[44-repeated-take-crossover]]。同文本不同发声的正常时序失配已足以产生大幅降分；不能单独证明 TTS 来源偏好。
- **局部时间校正：** [[45-local-clock-crossover]] 合格子集改善，但大部分映射越界，完整来源均衡门未通过；不外推为稳定校正方案。
- **处理链能区分来源：** [[43-processing-chain-predictive-audit]] 主队列分类 AUC＝0.972，但分差回归 R²＝−0.140；来源可分不等于能解释分差。
- **旧频带／编码修复：** 固定视频、同一发声的处理说明评价端点受损伤影响，不能换算成 TTS 总优势的原因比例，也不能由高频修复推出只有高频重要。
- **TTS 换轨训练下降：** [[64-may-purified-tts-training]] → [[66-may-tts-alignment-loader-audit]]。约24.5%相邻重复、最长1.8秒有声段固定同图；不能从该处理链失败推断 TTS 训练一般无效。

## 4. 训练工程状态与资源

- Patrick 未归一化 coarse10 的 27 种组合是描述性预览，实际更新不等导致 CONTROL_FAILED；不写成严格训练音量因果结论。
- 原多身份 FP16 数值失败、RMS 原版本失败、独立 RMS repeat 暂停是不同事件；见 [[Patrick同AVE逐录音RMS归一化三档粗训练与27格评测]]、[[Patrick RMS归一化同初始化独立复跑]]、[[SyncTalk FP16 非有限训练失败的适配与官方环境核查]]。
- 更新前保护资格通过不等于完整训练数值稳定；错误版本、原预算与失败现场保留，不盲重跑或更改精度。
- 归档与恢复位置见 [[编码器扩展的执行环境与资产存储]]、[[049-unified-baidu-project-root]]。旧绝对路径先转换，不修改冻结历史记录；SHM 与 scratch 不能当持久完整备份。

## 5. 哪些旧说法不能再直接复用？

| 旧说法 | 当前正确表述 |
|---|---|
| 英文没有 TTS 优势 | 英文有正向队列；负向结果、来源风险及模型错误分别核对 |
| 音素分离度／稳定性更好，所以生成更好 | 表征差异存在；与下游收益之间没有稳定充分关系 |
| 各种移植都失败，所以幅度是唯一原因 | 仅约束已测干预族与剂量；未排除其它因素 |
| 同文本交叉低分证明评分器偏好 TTS | 局部发声时刻不一致本就会降低同步分数 |
| 编码方向变了，就是找到有益方向 | 编码差值、可迁移评分响应、训练收益分别验证 |
| 低音量会把噪声截掉，所以训练更好 | 历史浮点波形未归零；频谱／编码／训练证据未闭合这一解释 |
| 已完成实验就是假设证实 | 完成表示执行与核验交付；科学结论可为阴性、混合或不确定 |

## Observations

- [decision] 历史失败、反向条件与控制失败原样保留；本页用于防止重复路线和跨端点误归因。
- [limitation] 通用自然音频增强方法、人类感知收益及完整 TTS 优势机制均未确认。
