## 一句话算法

把对应音素的TTS−自然特征差拆成平均偏移与内部轨迹差；分别或联合加到自然音频特征上，保留自然时间轴，解码并生成视频，再交叉更换评分音轨，区分生成端与评分音轨响应。

## 全流程

配对波形 → MFA分别对齐 → WavLM L6特征 → 同文本位置音素配对 → 相对相位表示 → 静态/动态差模板 → 映射回自然时间轴 → HiFi-GAN解码 → Wav2Lip → 四格评分与自动口部检查。

### 2. 分别对齐各自的音素

固定MFA 3.4.1、mandarin_china_mfa词典和mandarin_mfa声学模型及哈希。自然与每次TTS分别对齐自己的波形，核对实际文本、重复、漏读、数字和多音字。

配对键为“来源语句＋文本位置＋音素标签＋声调”。重复的/a/不能仅按标签互配；标签/顺序不一致的片段不硬凑。保留声调，不把spn当静音或有效配对。现有FunASR字级时间戳不能代替MFA音素边界。

先在拟合集做自动异常检查；首轮不做人评或人工边界复核，因此零spn、文本一致、覆盖率高均不等于时间真值准确。

### 3. 提取可解码特征

资格检查须核实上游get_features真实取层、输入处理、hop320、帧时间原点及尾帧规则。不能凭1024维认定层号。历史普通g_02500000.pt的WavLM重建STOI 0.928不能直接作为本次prematched版本的质量保证，须独立校准重建。

### 4. 时间不对齐时，如何估计静态与动态差

**先对应音素位置，再各自在原生时间轴取特征，不做同时间戳逐帧相减。**

例如，自然/a/位于0.80–1.00秒，TTS同位置/a/位于0.65–0.78秒。对各自区间[a,b]定义相对位置u=(t−a)/(b−a)，两者的中点都是u=0.5，实际时间分别为0.90和0.715秒。

首轮建议以少量等宽相位段表示音素，如前/中/后三段；具体分辨率及每段最低真实帧数用拟合集校准冻结。每段从真实帧求均值，不能把两个帧插值成丰富动态证据。模板在相位中心间平滑插值；外侧取最近相位模板值并由边界窗衰减，不推断更细的动态。

记同一相位网格上的特征为H_N(u)、H_T(u)，使用相同固定权重求均值：

μ_N = mean_u H_N(u)，μ_T = mean_u H_T(u)。

每个配对音素的静态差为μ_T−μ_N；动态差为去掉各自均值后的轨迹差：

R_N(u)=H_N(u)−μ_N，R_T(u)=H_T(u)−μ_T；
动态差 = R_T(u)−R_N(u)。

先平均同位置draw，再在说话人内平均该类音素，最后对支持该类的说话人等权平均，得到静态模板M_p及动态模板D_p(u)。D_p在相位网格上均值为零。长音素、多句、多draw不增加独立说话人权重。

**公平比较要求：** M、D、J使用同一批可相位比较的token、draw和说话人，同一相位网格及均值定义。短音素、未知语音或支持不足类别在三臂均不修改；报告按音素/声调/时长的覆盖率。原先全部原生帧均值可作描述，不与这里的相位均值混算。

在拟合集按20/40/60/100人重复抽样，检查模板稳定性；组外验证必须重新估计模板，不能含测试人。

相同u只是假设相近发音阶段，并非声学事件真值。三段平均也可能遗漏细节，跨上下文动态可能抵消；本方案不检验绝对音素时长或停顿机制。

### 5. 如何迁移到自然音频并重建

对自然音素[a_N,b_N]的原始帧t，计算u_N(t)=(t−a_N)/(b_N−a_N)，查询该相位的动态模板。**不移动自然音素位置，不复制TTS时长，不替换整条自然特征。**

先固定有效帧掩码和边界平滑窗w_t。为防插值、帧采样和平滑重新引入平均偏移，在实际施加帧上计算：

c = Σ_t w_t D_p(u_N(t)) / Σ_t w_t；
g_D(t) = w_t [D_p(u_N(t))−c]；
g_M(t) = w_t M_p；
g_J(t) = g_M(t)+g_D(t)。

Σw_t为零则该token不修改。g_D在实际自然帧上的向量和为零；这是编码空间的零均值，不保证解码波形的谱形、RMS或声学属性不变。

分别干预h'_t=h_t+αg_M(t)、h_t+αg_D(t)、h_t+αg_J(t)。正向α=0.25，负向−0.25，不按评分搜索。三类修改相同的音素、帧和边界窗。

联合臂使用相同系数叠加，通常不是同能量干预。J高于M不能单独证明动态更有效或存在协同；各臂记录实际扰动能量，各自设置匹配能量的随机对照。

所有解码臂使用同一声码器，统一匹配原音整体RMS，保留局部包络与频谱变化。检查内容、削波、长度、统一延迟及发声事件时序，并重新编码检查静态/动态变化是否保留。相同帧数或样本数不保证发声时间不变；明显时序变化会限制纯声学属性解释。

### 6. 生成对照视频

同一Wav2Lip、人像和推理设置；不按评分重抽、不按最佳lag重定时。零偏移重建R=Dec(E(A))用于控制声码器影响，Dec表示解码器，区别于动态模板D_p，原音A用于检验实际增强价值。

已确认完整11臂：

| 类别 | 条件 |
|:--|:--|
| 基线 | 原音A、零偏移重建R |
| 正向 | 静态M+、动态D+、联合J+ |
| 负向 | M−、D−、J− |
| 随机 | 随机静态M_r、随机动态D_r、随机联合J_r |

40人各1句共440个逻辑视频，替代原五臂预算。既有基线只有在输入、模型、人像、随机设置、生成及评分合同一致并读回通过时复用，不默认重复渲染全部440段；技术校准/重复基线单列。

随机模板预定种子，保持各自的编辑区域、时间结构、平滑和实际扰动能量；动态随机臂也须在实际帧上零均值。只支持本次预定随机对照，不概括所有随机扰动。

预算较小的替代是7臂：A、R、M+、D+、J+、J−、J_r，约280视频。但静态/动态各自缺负向及随机对照，其方向特异性结论更弱。

### 7. 交叉评分，拆开生成端与评分音轨响应

对每个候选音轨X，V_R=G(R)，V_X=G(X)，分别评分：

| 视频 / 评分音轨 | 基线重建R | 候选X |
|:--|:--|:--|
| 基线视频V_R | q00 | q01 |
| 候选视频V_X | q10 | q11 |

生成端评分响应=q10−q00；评分音轨响应=q01−q00；原生总变化=q11−q00；交互=q11−q10−q01+q00。总变化不一定是前两项简单相加。

另将所有视频统一配原音A，比较C(A,V_X)−C(A,V_R)及C(A,V_X)−C(A,G(A))。只超过重建基线不算超过原音驱动。

直接绑定无损PCM，固定ROI/track、共同时间支持和guard规则。报告C、零时滞距离、完整lag曲线及最佳offset；C显示3位小数，统计保留原精度。

### 8. 分析与结论

已确认唯一主比较：联合正向J+相对原音驱动，即ΔC=C(A,V_J+)−C(A,G(A))。静态M+和动态D+属于次要拆解，不能按结果改成主检验。

M+/D+/J+都报告；J+−M+、J+−D+及对应负向/随机对照用于拆解。可描述C(A,V_J+)−C(A,V_M+)−C(A,V_D+)+C(A,V_R)这一评分尺度上的交互，不称真实声学协同。次要结果为探索性，不能以“任一臂成功”替代唯一主检验，也不能将未经校正的次要区间当作确认性机制证据。

主对比按说话人等权汇总，固定bootstrap种子/次数，报告95%区间。窗口、token和draw不是独立人数。进入确认阶段的候选需主端点区间下限>0且增益超过重复推理波动，同时由重建/随机对照支持，原时钟指标无明确恶化；容差只在拟合集校准后冻结。区间跨零记为证据不足，不自动扩大或使用60人确认集。

| 结果 | 解释 |
|:--|:--|
| 仅固定视频换音轨提高 | 评分音轨响应，未见生成收益 |
| 固定音轨换视频提高，独立口部证据不改善或不可用 | 生成端评分收益，真实同步收益未确认 |
| 原音轨收益及合格独立口部证据同向 | 支持所测自动端点下的生成改善 |
| 静态无效、动态/联合有效 | 支持进一步研究所测动态模板，不证明全部TTS动态机制 |
| 三类均无效 | 不支持本次分辨率、支持集与剂量的模板干预，不能排除其他动态或时长机制 |

首轮只做自动评价。口部指标须先校准可测性，不以开口更大代替更同步；不可测就明确缺失。AISHELL无配套真实口部视频，不能计算真实嘴型重建误差；没有人评，不认定感知同步收益。
