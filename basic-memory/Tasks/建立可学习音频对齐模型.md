# 建立可学习音频对齐模型

## Context

目标是借鉴 VC/音频转换的思路，把当前已经能改善 TFG/SyncNet 的 MFA-linear 音频对齐，发展成一个可学习、可解码、可部署的音频时序对齐模型：保留 TTS 的内容与目标声学风格，在 natural 音频的时间轴上生成严格等长、可由冻结声码器解码的音频。

当前已知事实：

- MFA-linear 已经能在部分数据上带来 TFG/SyncNet 增强，但它是规则式 pseudo-target，不是可学习的对齐器。
- 直接用 WavLM-L6 → prematched HiFi-GAN 不是无损重建；因此 decoder 域变化必须单独控制。
- 仅用 WavLM feature loss 训练 natural-only 或 conditional adapter，虽然 feature loss 改善，但没有稳定转化为下游 SyncNet 改善。
- 在由某条音频生成的视频上替换回另一条音频，分数下降，说明 TFG 生成的嘴型会适配驱动音频；该现象不能直接当作 natural 对齐标签。
- 因此，训练期应优先使用固定且独立于候选音频的视觉时间参照；不要把“候选音频 → TFG → 同一 SyncNet”闭环作为主监督。

## Overall plan

### 1. 冻结数据与评估协议

- 选择单语言、已有自然音频/TTS 音频/MFA/TFG 产物的数据集，优先复用已有中文数据，减少语言和数据协议混杂。
- 固定 speaker-disjoint train/validation/test split、音频采样率、mux、Wav2Lip/TFG、SyncNet checkpoint 和独立工作目录。
- 保留 natural raw、raw TTS、MFA-linear、direct WavLM-resynthesis 等基线。
- 所有输出严格匹配 natural sample count，并记录音频、视频和模型 hash。

### 2. 验证监督信号是否真的提供时间信息

- 用 natural 音频预先生成 TFG 视频后冻结视频流；训练时不重新生成视频。
- 预计算并冻结 visual embedding，仅让候选音频经过可微的 SyncNet audio branch。
- 对配对音频人为加入 ±40/80/120 ms 时移、局部 phone-duration 扭曲和随机错配，检查分数是否在正确时间附近达到峰值。
- 先只训练一个可学习全局 offset 或极小的 monotonic warp，确认梯度非零、能从已知偏移恢复、不会出现 NaN。
- 加入 cross-sample、wrong-speaker、static/repeated-frame、random-shift 和独立评估器负控。
- 若固定视频的 SyncNet 曲线不能识别已知时移，则停止视觉监督路线，不进入模型训练。

### 3. 学习受约束的 MFA residual time warper

- 以 MFA-linear 映射作为初始化，不直接从随机状态生成任意 1024 维特征。
- 模型只预测每个 phone 或局部时间段的小幅 duration/boundary residual。
- 强制时间映射单调、连续、有界，并严格输出 natural clock 长度。
- 对 TTS WavLM feature trajectory 做可微时间插值，再交给冻结 prematched HiFi-GAN 解码。
- 保留 phone 顺序、MFA boundary、pause/silence 和 voicing 约束，避免模型通过异常拉伸或压缩取得分数。

### 4. 加入音频内容、说话人和质量保护

- 将固定视频的音视频对齐损失作为辅助或逐步增大的目标，不再把 feature pseudo-target loss 当作唯一目标。
- 同时保留 MFA/phone consistency、WavLM 或 phone posterior 内容约束、speaker embedding 约束、log-mel/响度约束和 warp smoothness。
- 监控 PER/WER、speaker similarity、音质、停顿、边界连续性和削波，防止 SyncNet reward hacking。
- 如视觉信号有效，再比较 SyncNet、另一同步模型或 landmark-based critic；TFG/Wav2Lip 只作为冻结下游评估器。

### 5. 训练与下游验证

- 先做小规模 smoke，再做 speaker-disjoint 训练和 held-out 评估。
- 统一比较 natural raw、raw TTS、MFA-linear、direct resynthesis、residual warper。
- 对每个条件运行相同的 Wav2Lip/TFG + SyncNet 协议，报告 Sync-C、Sync-D、offset、paired delta、speaker-cluster CI 和失败样本。
- 额外做固定视频换音轨、random-shift、不同 SyncNet/同步模型和自然视频（若可获得）的验证。
- 只有在固定视觉目标和独立评估器上都改善时，才扩大数据量或模型容量。

### 6. 部署方向：视频特权监督到 audio-only student

- 如果训练时能获得 natural talking-head video，但部署时没有视频，先让 teacher 使用固定 visual embedding 学习 phone-duration residual。
- 再把 teacher 产生的时间映射或 residual 蒸馏给只输入 natural audio + TTS audio 的 student。
- 部署时只运行 student → frozen HiFi-GAN，不依赖视频或 TFG。
- 若没有真实自然视频，只能把现有 TFG 视频用于工程验证，不能宣称获得真实口型监督。

## Decision gates

- Gate A：固定视频能正确区分配对音频与已知时移/错配音频。
- Gate B：tiny offset/warp 能从人为偏移恢复，且 gradient audit 通过。
- Gate C：residual warper 在 held-out speaker 上相对 MFA-linear 有稳定 SyncNet 或独立音视频指标改善，同时不损害内容、speaker 和音质。
- Gate D：收益不只存在于 candidate-driven 视频和训练用 SyncNet 上；否则判定为循环自洽或 reward hacking，不扩大模型。

## Current step
固定视频监督验证已完成。Gate A 的固定视频曲线对受控偏移敏感，但 SyncNet 存在约 -80 ms 的系统性参考偏移；Gate B 的 30/30 梯度非零，但只有 2/30 次已知偏移优化能回到一帧以内，方向不可靠。因此暂停 MFA-linear residual 训练，不把当前 frozen SyncNet objective 作为 phone-duration 学习信号。下一步先校准 visual/audio window offset 和官方 vshift，再重新验证 Gate B。
## Observations

- [description] 需要把规则式 MFA-linear 逐步变为受约束、可解释的 phone-duration residual warper
- [decision] 视觉监督优先使用固定视频和冻结 SyncNet visual embedding，不把候选音频生成视频的闭环作为主监督
- [constraint] 所有输出必须严格 natural-length、可由冻结 HiFi-GAN 解码
- [learning] feature loss 改善不等于下游同步改善，训练目标必须包含独立验证和音频质量保护
- [next] 先用单语言已有 TFG 数据验证固定视频对已知时移的响应
