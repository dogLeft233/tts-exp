# 主流语音编码器的方向共性扩展

## 结果与范围
已由ROOT直接完成，没有委派代理。正式结论见[[52-encoder-direction-commonality]]。11新checkpoint覆盖HuBERT英base/large及中文base、wav2vec2 base/XLS-R53、WavLM base-plus/large、Whisper base/small、data2vec audio base、W2v-BERT2；另复用Wav2Lip已验证缓存作为同支持原生参照。

CAL20/10位男性每人2句，12路径共同663对音素，中央50%为516对，20句全部保留。11×121=1331正式前向，W2v-BERT首尝试另有2个前向因native padding零向量在首句控制失败，原件保留；修复attention mask后仅重跑该模型，其他10不重跑。新TFG/SyncNet/训练均0。

末层统一RMS的TTS跨人cos在11预训练编码器为0.165–0.506，Wav2Lip为0.015；其RAW为0.329。纯+3dB在Wav2Lip/WavLM base-plus/Whisper base/small变化RMS为0.0721/0.0350/0.0275/0.0311，跨人cos0.884/0.479/0.613/0.577；若干归一化路径只1e-6–5e-5量级。TTS平均共同分量存在于多种编码器，电平耦合和局部方向共性依赖具体原生路径。均值轴不是逐音素统一改变量；没有新增生成收益或感知结论。
