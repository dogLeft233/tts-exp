# Why

我们已确认英文 LRS3 存在 TTS 原生 Sync-C 优势，但“得分更高”还不能解释 TFG 对输入的偏好。

上次有效 run `runs/lrs3_tts_gain_mechanism_review_v15`：

| 证据 | 总 ΔSync-C | 最佳距离改善 | 背景距离变化 |
|---|---:|---:|---:|
| Ditto，50 条记录的等权历史均值 | +1.124 | +0.008 | +1.116 |
| LeapTalk，50 条记录的等权历史均值 | +1.389 | +0.474 | +0.915 |
| LeapTalk，12 来源 INTERIOR | +1.253 | +0.286 | +0.967 |

历史推断实际按 45 个 source groups 等权；上表前两行只是便于核对原记录的描述。12 来源的 ΔC 校正区间为 `[+0.658,+1.801]`，最佳距离改善区间为 `[-0.343,+0.811]`。INTERIOR 相对 FULL 的增益差为 −0.003，区间跨零；这支持边界裁剪不是明显主因，**没有证明两者等效**。人工同步尚未评估。

训练于自然音频并不意味着每一段自然音频都更容易处理。TTS 可能保留清晰的发音线索、减少录音干扰与韵律变异，让输入更接近模型能稳定处理的区域。另外，模型和评估器可能共享偏好。以上均需拆开验证。

# What Changes

- 增加固定视频的音频干预实验 A，区分评分变化与口型变化。
- 增加同一 LeapTalk 的生成输入 × 评分输入交叉实验 B，量化固定音轨的生成效应、固定视频的评估效应和交互。
- 对两个阶段统一实施严格等时钟、完整矩阵、配对 seed、冻结支持、分组统计和独立验收。
- 增加特征范数/方向、错误内容对照、节奏描述和匿名人工评估包。
- 记录 checkpoint、训练数据与模型选择方式的可核实证据；未知项保持未知。

# Scope

这是 12 来源的机制诊断，可证明具体干预影响了哪条路径；它不能单独证明训练分布密度、全部 TTS 优势的因果中介比例、所有 TFG/语言的通用机制。

本 change 要求完成 A/B 自动实验及人工包。音素级节奏因果干预、两 provider 新合成、第二生成器复现、重新训练及新来源确认属于后续独立 change，不用于本轮挑选参数。
