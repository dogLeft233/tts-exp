# TTS 原生增益来源：假设与识别设计

## 1. 先定义问题

`N` 是自然录音，`T` 是同内容的 TTS；`G(A)` 是用音频 A 驱动的人像视频；`S(V,A)` 是视频 V 配音频 A 的评分。所谓原生增益是：

`native_gain = S(G(T),T) − S(G(N),N)`。

这两个系统同时换了声音和口型，不能仅凭这个差值将原因归于 TFG。replacement 则将候选音频生成的视频配回自然声音；它还依赖时间兼容性，因此既有 replacement 失败不能直接否定原生效应。

本轮只操纵录音干扰和幅度。每条录音 A 生成保持采样点数和时钟不变的处理版 H(A)。N/T 无需互相对齐；每个交叉实验内部具有相同的语音事件时间。

## 2. 假设及可证伪预测

### H1：评估器的特征几何/声学可辨认度贡献了原生优势（最高优先级）

TTS 可能改变 SyncNet 音频特征的长度、方向或随时间变化的清晰程度，使正确配对与错误配对的距离差更大。口型完全不变也可能发生评分提高。背景项上升本身既可能是有用辨认度，也可能包含尺度效应，不能先叫它“作弊”或“偏差”。

预测：固定既有视频，仅改变音频的增益、噪声或谱抑制，C/B/D 会变化；真实视频也可能出现同方向变化。如果单位范数诊断下 TTS 优势的方向一致性及标准化效应减弱，而错误内容检索排序没有改善，更符合尺度解释。如果正确内容相对错误内容的排序也改善，则支持声学可辨认度解释，仍不等于真实时间更准。raw C 与 C_unit 数值单位不同，不能直接相减或报告原始数值的“衰减百分比”。

削弱证据：固定视频效应很小且区间足够窄，而固定音轨的生成效应明确存在。区间跨零但宽不能排除 H1。

### H2：TFG 偏好干扰较少、可稳定提取发音线索的输入

自然视频训练集通常经过筛选。真实录音中的噪声、混响、呼吸或录制差异可能难以映射到嘴部运动。TTS 即使整体听感不如真人，也可能让特定音频 frontend 更容易提取驱动信号。这是对“任务相关信息更容易利用”的假设，不能把 TTS 参数少与音质差直接等同。

预测：自然录音经固定谱抑制后，重新生成的视频在**相同原音轨**上评分改善；向 TTS 加入噪声后，重新生成的视频在**相同原 TTS 音轨**上评分下降。两方向同时出现、且声学操作确实有效，比单向加噪使模型变差更支持该解释。

边界：谱抑制也会损伤语音，加噪也会破坏发音线索。只能称为这两个操作的路径效应。没有独立听评及真实噪声依据时，不称“音质介导了原生增益”。

### H3：TFG 偏好规则的节奏和较低的局部动态复杂度

TTS 的停顿、发音时长或能量起伏可能更符合有限时间窗口的模型处理能力。平均语速更快或慢本身没有预设正确方向；真正可能相关的是变化是否稳定、关键发音是否跨过足够帧数。

本轮先做低成本、音频独立的描述：共同 VAD 下的发声比例、停顿长度分布、活动段长度变异系数、能量包络调制谱及活动段谱通量。不得将 VAD 活动段称为音素时长，不跑 12 样本多变量筛选/中介分析，不把某一相关性写成节奏因果解释。

要因果检验 H3，后续需“同一波形的保音高时间伸缩 + 恒等变换/sham + 视频等时重映射 + 固定原时钟评分”，音素级规律性还需独立可靠对齐。简单全局快放只能检验平均速度，不能验证音素时长均匀性。本轮将 H3 固定为 `DESCRIPTIVE_ONLY`，不因 A/B 阴性临时扩大节奏搜索。

### H4：训练筛选/模型选择与 SyncNet 共享偏好

Ditto 论文报告采用清洗的广播视频训练，并用 lip-sync 分数选择 checkpoint。这使“模型被选择为擅长产生高评分输出”成为合理线索，但不是本项目偏差已被证明。LeapTalk 必须单独核验，不能把 Ditto 的训练细节移植过去。

预测：SyncNet 的改善与固定音轨的人类同步偏好、错误内容区分度不完全一致。若人类也稳定偏好处理后口型，则支持真实可感知的改善；若只提升 Sync-C，结论限于评分协议。

本轮不识别“训练中的指标选择导致了偏好”的因果性；需要不同 checkpoint/选择策略的独立比较才能识别它。无真实训练样本时，禁止把某自然语音参考集合的 kNN 距离叫训练分布距离。

## 3. 实验 A：固定口型，只干预评估音频

每条 ID 用既有 LeapTalk 自然视频 `V_N`、TTS 视频 `V_T`，以及对应真实视频 `R`。视频像素、帧序列、crop、PTS 在各自五个音轨条件中保持相同。

| 视频 | 评分音轨 |
|---|---|
| `V_N` | N_ORIGINAL / N0 / N_GAIN / N_NOISE / N_DENOISE |
| `V_T` | T_ORIGINAL / T0 / T_GAIN / T_NOISE / T_DENOISE |
| `R` | R_ORIGINAL / R0 / R_GAIN / R_NOISE / R_DENOISE |

ORIGINAL 是各自评分 crop 解码出的 PCM。为避免加噪时裁剪，同 ID 的 N/T/R 及全部变体共用一个冻结的 headroom 缩放常数；N0/T0/R0 是缩放后的基线，保留原时间轴。ORIGINAL 的额外评分专门测量这一公共缩放的影响。R0 与 N0 的 codec/裁剪可能不同，因此 R 作为单独固定视频对照，不与 V_N 做逐帧像素差或强行视为同一音频文件。

改变评分得到 `E_h = S(V,H(A)) − S(V,A)`。口型完全不变，所以这是评估输入路径效应；它可能反映声音更可辨认，不自动意味着评价无效。

A 的主要推断为自然 DENOISE 效应、TTS NOISE 的损害、真实视频 DENOISE 效应。GAIN 与特征几何、错误内容分析为事先定义的诊断。

## 4. 实验 B：生成输入 × 评分输入

对每个 ID、原始 source `s∈{N,T}`、seed `r∈{42,43}`，新生成 `V0=G(A0;r)`、`Vn=G(NOISE(A0);r)`、`Vd=G(DENOISE(A0);r)`。同 ID 的 N/T 共用参考肖像；同 seed 在所有音频条件中复用随机初态。每次独立进程或完整 reset，避免流式历史串入下一个 cell。

对每个 h∈{NOISE,DENOISE}，构造四格：

| | 评分 A0 | 评分 H(A0) |
|---|---:|---:|
| 基线视频 V0 | q00 | q01 |
| 处理后生成视频 Vh | q10 | q11 |

定义方向统一为更好为正，Q 可取 C 或 −D：

```
generation_h = q10 − q00
evaluation_h = q01 − q00
interaction_h = q11 − q10 − q01 + q00
own_audio_total_h = q11 − q00
own_audio_total_h = generation_h + evaluation_h + interaction_h
```

`generation_h` 使用同一评分音轨，差异必须通过生成视频出现；但 **SyncNet 上的视频改善仍不是人工同步改善**。`evaluation_h` 固定视频，度量评估音频变化。交互是改变两者产生的额外差异。换一条分解路径会改变交互分配，故不把三项算成唯一“原因占比”。

为对称展示，可另报 `G_sym=0.5*((q10−q00)+(q11−q01))`、`E_sym=0.5*((q01−q00)+(q11−q10))`，两者和等于总变化；这仍只是该四格实验的对称分配。

每 seed、source 两种 h 共用 q00，故 7 个唯一科学 cell，不是 8 个。全 B 为 `12×2×2×7=336`；视频为 `12×2×2×3=144`。

新基线 `Δnative_fresh = C(V0_T,T0)−C(V0_N,N0)` 在 seed 内配对、先平均 seed。用它确认**本次生成配置下**还存在原生优势。若优势未明确复现，B 仍完整运行，但应称一般音频扰动响应；不得说它解释了历史 LeapTalk 的优势。

共同干预下的优势差 `Δnative_h−Δnative_0` 可描述增益是否缩小，不能当自然/TTS 差异的因果中介比例，因为 h 同时改变了两边且只覆盖部分声学属性。

## 5. 指标：保留完整信息，区别几何与匹配

官方距离矩阵 `M[t,j]` 共有 31 个 lag 列。先对预定支持 U 求时间均值 `d[j]=mean_t M[t,j]`，再计算：

```
D = min_j d[j]
B = median_j d[j]
C = B − D
official_offset = 15 − argmin_j d[j]
D0 = d[15]
search_gain = D0 − D
```

使用官方 float32 距离计算与归约顺序，允许落盘升为 float64；不能改成每帧算 C 再平均。保留 FULL 与共同 INTERIOR；INTERIOR 是主端点。

特征诊断必须保存实际 SyncNet `forward_aud`/`forward_lip` 输出。在相同 U 上报告两模态的范数分布、音频相邻帧变化、点积与平方距离分解；额外用单位范数特征计算欧式距离矩阵及 C_unit，明确标为**非官方诊断指标**。若官方 pairwise_distance 使用 epsilon，几何恒等式需显式计入该修正，不能拿未修正理论值冒充官方距离。零范数窗口报错，不能悄悄 eps 修补后当正常样本。

两套指标的原生效应只做同量纲内部的标准化后比较：分别报告12组配对差的正向比例与 `d_z=mean(delta)/sd(delta,ddof=1)`，另用相同来源bootstrap重算 `d_z_raw−d_z_unit` 的描述区间。方差为0的原值或抽样标NA并报告次数；不偷偷加eps。它是小样本描述，不是新的主检验，不能用一套显著另一套不显著代替直接差异。

数学上，对所有 lag 加相同常数不会改变 C；按正数整体缩放距离会同比缩放 C。因此“背景上升”不能自动归于常数偏置。范数归一化消除了径向信息也可能损失有用信号，不能把归一化后效应消失单独当偏差证明。

A 另用所有其他 11 个来源的同类 baseline 音频作错误内容对照，只算特征距离与匹配排序。排序改善与 C 上升一致时较支持内容区分度；排序不变而 C_unit 优势缩小时较符合距离尺度解释。全部为描述性三角验证，不能用 396 个配对充当 396 个独立样本。

## 6. 如何回答科学问题

| 观察组合 | 可报告的判断 |
|---|---|
| 固定视频 C 变化，生成效应不确定 | 已定位评估音频路径效应；生成端证据尚不足 |
| 固定音轨生成效应明确为正，fresh native 复现 | 该声学操作影响 LeapTalk 输出，并与原生优势机制相容 |
| 自然谱抑制改善、TTS 加噪损害，两者生成端都明确 | 支持模型对该类声学干扰的偏好；仍需区分语音损伤与降噪 |
| 单位范数下标准化优势/方向一致性减弱、错误内容排序没有改善 | 与特征尺度解释相容；不能单独证明评分偏差 |
| 同音轨人类偏好与生成效应同方向 | 对可感知口型改善有独立支持 |
| C 改善，但人类区间很宽或无评分 | 感知未知；不能宣称“只对指标有效” |
| 两 provider 排名不同 | 本轮不产生此结论；另一个 bridge spec 才比较 provider |

报告对 H1/H2 输出 `SUPPORTED_FOR_THIS_INTERVENTION` / `INCONCLUSIVE` / `COUNTEREVIDENCE`；H3 为 `DESCRIPTIVE_ONLY`，H4 为 `NOT_CAUSALLY_IDENTIFIED`。没有阳性不等于无机制，也不能为了得到阳性更换参数或样本。

- [LeapTalk 论文 §4.1](https://arxiv.org/html/2608.00079v1)：报告 VividHead 训练。须核验项目的实际 LeapTalk/ViBT 代码、基座和适配权重对应关系；只凭文件夹名不推断训练数据或没有用过合成数据。

外部资料核对日期为 2026-09-15。当前可说“论文描述的主要训练素材是真实说话视频”；不能断言所有 frontend 预训练、蒸馏、数据清洗和实际 checkpoint 都从未接触 TTS，也不能证明当前样本绝无训练重合。
