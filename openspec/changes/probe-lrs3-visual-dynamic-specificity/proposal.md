# probe-lrs3-visual-dynamic-specificity

## Why

视觉教师 missingness 审计界限跨零，绝对几何还混合静态嘴形与动态轨迹。用同一已见缓存分解几何误差，并加入固定时间反转对照，检验是否有值得独立确认的动态证据。

## What Changes

- 在冻结三臂共同支持上分解平均嘴形误差与去均值轨迹误差。
- 以原时间顺序相对反转轨迹的响应检查动态指标辨识力。
- 保留133条/23组分母与缺失界限；仅CPU、零模型调用。

## Capabilities

### New Capabilities

- `lrs3-visual-dynamic-specificity`: 独立续验/诊断命令、固定科学判定及可重算验收。

### Modified Capabilities

无。旧 change、旧 run 和主流水线保持只读；本实验在独立命名空间实现。

## Impact

仅新增本 change 对应实验包、对应测试与 run；新视频/评分上限 0/0。训练、TTS、下载模型均为0。执行契约见 [并行入口](../../parallel-next-experiments-20260910.md) 和本目录 design.md。
