# Shared frequency-profile family v1 with fit-selector contract v2

This fit-only profile family tests small, recipient-local spectral changes. It
keeps each source waveform's phase and sample clock and does not copy a donor
speaker's spectral shape.

## Transform contract

- Input: canonical finite 16 kHz mono IEEE-float32 PCM.
- Optional local compression: centered 32 ms envelope, ratio 0.90, gain bounds
  [-6, +6] dB. The profile family includes both this stage and two raw-audio
  profiles; the existing ratio-0.80 local-compression method remains a separate
  control.
- Spectral stage: 512-sample periodic-Hann STFT, 128-sample hop, center padding;
  compute local contrast from log magnitude minus a separably Gaussian-smoothed
  log magnitude (sigma 2 frequency bins, 2 STFT frames). Apply a real magnitude
  mask, preserving the original complex phase.
- Center each mask frame to zero mean in dB, then scale it into the hard [-3,
  +3] dB bound. The low-to-high tilt is symmetric around zero and at most 0.25 dB
  at either edge. Reconstruct to the exact input sample count.
- Apply the same 0.0376838172675746 RMS target and uniform 0.98 peak ceiling to
  every profile. If the peak limiter activates, record the resulting RMS; do not
  call the RMS target exact for that row.
- Score generated video against the untouched natural PCM. Never score the
  transformed audio as the audio track, retime the video, or optimize lag.

Implementation: `scripts/audio_enhancement/shared_frequency_profile_v1.py`.
Single-file conversion CLI:

```text
python -m scripts.audio_enhancement.shared_frequency_profile_cli_v1 INPUT.wav OUTPUT.wav --profile-id PROFILE_ID
```

The CLI writes a float32 WAV and a sidecar receipt, refuses overwrites, and
records source/output PCM hashes and RMS/peak/mask diagnostics.

## Fit-only selection contract

- Use the preassigned eight historical fit utterances from four speakers,
  two utterances per speaker. These speakers/audio are historically exposed and
  are not fresh-held-out data. Use one paired render seed for each context and
  the same planned context roster for every model and method.
- After all planned arms are present, calculate one sorted common query support
  across all 15 methods for each model/sample/seed context. Failed or missing
  methods stay in the denominator and make that context incomplete; they are
  never removed to improve another method's support.
- Selector v2 requires `split="fit"` on every expected context and result row,
  plus the exact frozen predeclared eight-row fit roster (four speakers, two
  distinct utterances each) crossed with each qualified model. It rejects
  confirm/dev rows and any context outside that roster.
- The shared selector consumes per-context 31-lag float32 curves and sealed
  `B`, `Dmin`, `D0`, `Cbest`, `Canchor`, lag/offset fields from the independent
  consumer. It pairs every profile to `rms_fixed` on the exact same context and
  support digest. It verifies that `B` is the curve's float32 median, `Dmin` is
  the curve minimum, `D0` is the zero-lag entry, and best lag uses the first
  minimum in the declared `-15..15` order. It also checks `Cbest =
  float32(B-Dmin)`, `Canchor = float32(B-D0)`, and
  `official_av_offset_frames = -best_lag_frames`. Support digests must be
  exactly 64 lowercase hexadecimal characters.
- First average paired contexts within each speaker, then speakers equally
  within a model, then the qualified models equally. The candidate objective is
  per-model `delta_Cbest + min(0, delta_Cbest) - max(0, delta_D0) -
  max(0, -delta_Canchor) + 0.25 * delta_far_lag_contrast`; then average model
  utilities and add the worst negative model utility as a penalty. Here
  `far_lag_contrast = mean(D_k - D0)` over `|k| >= 4`. This keeps Cbest primary,
  penalizes per-model Cbest/D0/anchored regressions, and gives a small reward to
  zero-lag versus far-lag separation. It does not reward offset movement.
- The `0.25 * delta_far_lag_contrast` term is an auxiliary weighted objective
  term, not a tie-breaker.
- Report every model's `B`, `Dmin`, `D0`, `Cbest`, `Canchor`, far-lag contrast,
  best lag and official AV offset. Return at most three shared profiles to the
  untouched development stage. The fit result is descriptive candidate
  selection only; it has no confidence intervals and is not evidence of
  cross-model utility.
- Use the untouched development speakers only after the three-model shortlist
  is frozen. Keep the complete planned denominator for engineering failures.
  Fresh confirmation remains separate and is not opened by this fit selector.

Selector implementation: `scripts/audio_enhancement_eval/shared_profile_selection_v2.py`.
