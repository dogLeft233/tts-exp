## 与 7 度量分析的对比

| 指标 | 7 度量分离度分析（Script 16） | 近同音词 L2 分析（Script 34） |
|---|---|---|
| **特征** | HuBERT L0/L6/L11 帧嵌入 | HuBERT L11 逐音素嵌入 |
| **度量** | 类内余弦紧致度 / 类间余弦中心距 / Fisher / Silhouette | 成对 L2 距离 |
| **粒度** | 11 视位类（宽泛） | 单音素级（精细） |
| **对齐** | MFA IPA → 11 Preston Blair 视位 | MFA IPA 直接使用 |
| **结论（L11）** | Natural > TTS（inter=−6%, d=0.73, p=0.099） | 无显著差异（p_FDR=1.0 全部） |

**这种差异本身提供了信息**：TTS 不改变单个音素在特征空间中的位置（L2 距离不变），但改变了跨视位类的布局（余弦中心距缩小）。这可能是因为 TTS 音素的分布更分散（intra_class 增大），导致类中心向彼此靠近。
