# 实验一：多 TFG 模型下的 TTS 优势（中文，n=13）

## 1.1 实验设置

```
样本: AISHELL-1 中文语料库 13 人，每人一句话（4-8秒）
条件: natural（真人录音） vs tts（Faster-Qwen3 0.6B 合成的同内容音频）
生成: 5种 TFG 模型 + 1种 Ditto 基线，各自生成 26 个视频（13 natural + 13 tts）
评估: SyncNet v2 统一打分
```

**研究问题**：TTS 的 SyncNet 优势在 5 种不同架构的 TFG 模型上都存在吗？效应大小与架构有关吗？

---

## 1.2 模型清单

### 我们测试的 5+1 种模型

```
┌─────────────────────────────────────────────────────────────────┐
│ 音频 → [音频编码器] → [生成器架构] → [输出视频] → SyncNet 打分   │
└─────────────────────────────────────────────────────────────────┘
```

| 模型 | 音频编码器 | 生成器 | 
|------|-----------|--------|
| **Wav2Lip**（2020） | Mel频谱（80维，最简单） | GAN | 
| **MuseTalk**（2024） | Whisper tiny | UNet单步修复 | 
| **V-Express**（2024） | Wav2Vec2 | 扩散+运动模块 | 
| **JoyVASA**（2024） | HuBERT | DiT扩散Transformer | 
| **LatentSync**（2024） | Whisper tiny | 隐扩散 | 
| **Ditto**（基线） | HuBERT | 头像替换 | 

---

## 1.3 结果：SyncNet 排名

```
                   natural (真人)    tts (合成)      差距
Wav2Lip    ████████████ 7.39  →  ██████████████ 8.92   +1.53  ← 最大
Ditto      █████████ 5.70    →  ██████████ 6.75        +1.25
MuseTalk   █████████ 5.79    →  ██████████ 6.33        +0.54
V-Express  █████████ 5.98    →  ██████████ 6.51        +0.53
JoyVASA    ███████ 4.82      →  ████████ 5.08          +0.27  ← 较小
LatentSync ███████ 4.65      →  ███████ 4.58           −0.06  ← 零（负对照）
```

**直接结论**：
- 5/6 模型在 TTS 条件下得分更高——现象是**稳健**的，非偶然
- 但效应大小差距很大（从 +1.53 到 −0.06），说明**架构决定效应强度**
- LatentSync 的零效应说明：TTS 优势**不是所有模型都有的**

---

## 1.4 为什么效应大小不同？——三条链路的衰减

```
TTS 音频的"优势信号" → [音频编码器] → [生成器] → SyncNet 打分
                            ↓              ↓
                       编码器越复杂      生成过程越多步
                       信号越容易被      → 信号衰减越大
                       "模糊化"
```

| 衰减因素 | 例子 | ΔC |
|---------|------|:---:|
| 编码器简单 + 生成快 + 评估器同构 | Wav2Lip（Mel → GAN → 用SyncNet训练 → 用SyncNet评估） | **+1.53** |
| 编码器复杂 + 扩散多步 + 自带SyncNet | LatentSync（Whisper → 20-50步扩散 → 自带SyncNet） | **−0.06** |

**LatentSync 为何是"负对照"**：多步扩散过程的本质是在噪声空间中逐步去噪。这个过程无意中起到了"**低通滤波器**"的作用——音频中的细节差异被去噪步骤抹平了。

# 实验二：英文 Wav2Sem 验证

## 2.1 为什么做英文实验？

中文实验告诉我们 TTS 优势 ≈ +1.25，但**为什么是中文**？换一种语言还会存在吗？

前人的工作（Ditto 团队，2024）提出了 Wav2Sem 框架：
```
音频 = 语义（这段话在说什么）+ 发音（每个声音怎么发）
       ↑ Fs                        ↑ Fp
```

我们的假设：
- **如果 Fs 通道是主导**：TTS 的语义更"干净"，中文和英文就应该都有效
- **如果 Fp 通道是主导**：取决于自然语音的发音本身是否清晰（不同语言可能不一样）

> 📖 **Wav2Sem 是怎么工作的？**
> 1. 用一个预训练的 Wav2Bert 把音频变成每帧 768 维的向量
> 2. **Fs** = 所有帧的平均值 → 代表"内容"，训练目标是尽可能接近 BERT(文字转录) 的语义向量
> 3. **Fp** = 原始帧 − Fs → 代表"发音方式"，即每个时刻的残留信息

## 2.2 实验设定

```
样本: LibriSpeech test-clean（英文），13 段对话（4.8-8.3秒）
TTS: Qwen3-TTS 音色克隆（同样的文字内容）
评估两步:
  1. Gate 1: 能否复现中文实验的 TTS 优势？用 JoyVASA + Ditto SyncNet
  2. Fs/Fp 探测: 如果不能复现，找原因
```

## 2.3 Gate 1：复现失败

| | 中文 | 英文 |
|---|---|---|
| ΔSync-C（TTS−自然） | **+0.205** * | +0.160 |
| Cohen's d | 0.79 | 0.31 |
| p 值 | 0.025 | 0.571（不显著） |
| Bootstrap 95% CI | — | [−0.106, +0.423] 跨零 |

> 英文上 TTS 优势**不存在**。这与中文完全相反。为什么？

## 2.4 Fs 通道分析：语义已饱和

```
问题: TTS 的"语义信息"比自然录音更好吗？

方法: 用 Wav2Sem 的预训练 Wav2Bert 提取 Fs，
      与"完美上限"（BERT 从文字提取的语义向量）比较 L1 距离
```

| 音频来源 | 到 BERT 的 L1 距离（越低越好） |
|---------|:---:|
| 自然录音 | 133.83 |
| TTS 合成 | 133.92 |
| 差距 | **+0.09**（几乎相同） |

> **结论**：Fs 通道在英文上已经**饱和**——Wav2Bert 从自然和 TTS 音频中提取的语义信息质量完全一样。语义（Fs）**不是**中英文差异的原因。

## 2.5 Fp 通道分析：视位可分离性（核心发现）

### 测量方法

```
音频 → MFA 对齐（自动找出每个音素的起止时间）
     → 映射到 13 个视位
     → HuBERT 提取每帧的特征向量
     → 计算同一视位内的稳定性 + 不同视位间的距离
```

> **指标解释**：
> - **inter_class_dist**（越高越好）：不同视位间的余弦距离。0.55 意味着两个不同视位的特征向量"有 55% 是不同的"
> - **fisher_ratio**（越高越好）：类间差距/类内方差。越大说明视位之间越清晰

### HuBERT L11 的结果（信息最丰富的层）

| 视位指标 | 自然录音 | TTS 合成 | 差距 | 效应量 d | p (FDR) |
|---------|:---:|:---:|:---:|:---:|:---:|
| inter_class_dist ↑ | **0.554** | 0.379 | −0.176 | **+4.08** | 0.0005 * |
| fisher_ratio ↑ | **1.721** | 1.148 | −0.573 | +1.99 | 0.0005 * |

> **完全反转**：英文自然录音的视位可分离性**显著优于** TTS——差距为效应量 d=4.08（极大）。
>
> 在中文上，这个模式是反过来的：TTS 的视位可分离性优于自然语音。

## 2.6 Fd 融合分析：语义能补救吗？

```
问题: 如果把 Fs（语义）和 Fp（发音）合并（融合通道 Fd），
      能否改善可分离性？改善程度在自然 vs TTS 上是否不同？

三档设计:
  Fp_only  = 只用 HuBERT 原始帧特征
  Fd_zero  = Fp + Fs   （简单拼在一起）
  Fd_random = FC(Fp + Fs)  （用投影矩阵融合）
```

| 增益指标 | 自然 | TTS | 差距 | d |
|---------|:---:|:---:|:---:|:---:|
| 融合带来的 Fisher 比提升 | **+2.33** | +0.44 | −1.89 | **−3.00** |

> 融合 Fs 大幅提升了**自然**语音的可分离性（+2.33），但对 **TTS** 几乎没有帮助（+0.44）。
>
> 这意味着 Fs 对自然音频贡献了大量互补信息，但对 TTS 则没有——TTS 的发音退化压倒了任何语义信号。

## 2.7 XLS-R 跨模型验证

为了验证结论不依赖于特定模型，我们重复了同样的分析，但换成**多语言模型 XLS-R**：

| 层 | 模型 | 自然 > TTS 的优势（d） | p (FDR) |
|:---:|------|:---:|:---:|
| L6 | HuBERT | +2.92 | 0.0005 |
| L6 | XLS-R | **+3.96** | 0.0005 |
| L11 | HuBERT | +4.08 | 0.0005 |
| L11 | XLS-R | **+3.46** | 0.0005 |

> 规律在**单语和多语模型之间完全一致**。英文自然语音的发音清晰度持续优于 TTS。

# 总论：中英文对比与统一模型

## 3.1 中英文核心差异一行表

| | 中文 | 英文 |
|---|---|---|
| TTS 优势（ΔSync-C） | **+0.205**（显著） | +0.160（不显著） |
| 自然语音的视位可分离性 | inter=**0.12**（差） | inter=**0.55**（好） |
| TTS 对视位可分离性的改变 | +49%（改善） | −32%（恶化） |
| 主导机制 | Fp（发音通道）运作了 | Fp 天花板——没有改善空间 |
| Fs 状态 | 未测，推测已饱和 | 已饱和（无差异） |

## 3.2 统一的"天花板"模型

```
TTS 对唇形同步的增益
    ↑
    │ 大（中文）
    │  ●  inter: 0.12 → 0.18 (+49%)
    │     TTS 澄清了本来含混的发音
    │
    │                     ●  天花板效应
    │ 小/无（英文）          inter: 0.55 → 0.38 (−32%)
    │                        TTS 反而模糊了本已清晰的发音
    │
    └──────────────────────→ 自然语音的视位可分离性
       差                  好
```

**核心洞见**：TTS 只在自然语音的发音本身就不清晰时才能改善唇形同步。当自然语音已经达到高可分离性（英文，inter ≈ 0.55），TTS 无法提供帮助——其参数化平滑反而模糊了已有的清晰对比。

## 3.3 三条独立证据的汇聚

| 证据线 | 来源 | 结论 |
|-------|------|------|
| **证据 1**：4 个声学特征全部被身份控制排除 | 实验一（中文因果） | 不存在可分解的单一声学机制 |
| **证据 2**：Fs 在英文上已饱和，中英文不对称全在 Fp | 实验二（英文 Wav2Sem） | TTS 优势运作于发音通道（Fp），非语义（Fs） |
| **证据 3**：LatentSync ΔC ≈ 0 做跨模型负对照 | 实验一（多 TFG） | 扩散模型的内部归一化过滤了音质差异 |

三线汇聚于同一点：**TTS 优势不是简单特征，是模型对音频中发音细节的系统级敏感度**。

---

# 最终结论

### 一句话总结

**TTS 改善唇形同步不是因为语义更清楚，而是因为发音更干净——这只有在自然语音本来发音不够清晰时才有效。**

### 可操作含义

1. **评估层面**：SyncNet 作为唇形同步指标，其分数受限于音频-视频生成器-SyncNet 三者的训练耦合，不等于人类感知的"好"
2. **工程层面**：选择 TFG 模型时需权衡——Wav2Lip 口型最准确但分辨率最低，JoyVASA 最快最省但口型模糊，LatentSync 最鲁棒但对 TTS 没有额外增益
3. **研究层面**：跨语言验证至关重要——中文的结论在英文上完全反转

### 局限（诚实声明）

| 局限 | 说明 |
|------|------|
| 样本量（n=9-13） | 统计检验力有限；逐样本相关性不显著 |
| 单一 TTS 模型 | 中文用 Faster-Qwen3，英文用 Qwen3-TTS-VC，未做跨 TTS 对比 |
| HuBERT 特征仅对 Ditto 提取 | 4 个候选表示机制无法在其他 TFG 模型上验证 |
| 仅 SyncNet 评估 | 无人类主观评测，所有"好坏"基于机器指标 |
| 英文 n=13 逐样本检验力不足 | Δinter_class 与 ΔSync-C 的相关性可能因 n 太小而不显著 |

### 后续方向

1. 在英文上测试多种 TTS 引擎，确认发音退化是否是模型特异的
2. 用中文 MFA 对齐运行相同的 Fd 三档分析
3. 扩大样本量（LibriSpeech-100）以获得足够检验力的逐样本相关
4. 测试中间语言（日语、韩语），探索自然发音清晰度的连续谱
5. 引入人类主观评测，校准 SyncNet 指标与人类感知的关系
