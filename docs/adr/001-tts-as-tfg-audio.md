# ADR-001: 使用 TTS 合成语音作为 TFG 驱动音频

## 状态

已接受 (2026-07)

## 背景

Talking Face Generation 研究标准做法是使用自然语音驱动口型。我们假设 TTS 合成语音可能产生更好的唇形同步，因为：
1. TTS 音素边界更清晰（无协同发音变异）
2. TTS 频谱更干净（无背景噪声）
3. SyncNet 训练数据可能偏向 TTS 般的干净语音

## 决策

用 **faster_qwen3 0.6B Base ICL 模式** 生成 TTS 音频，与 AISHELL-1 自然语音做配对对比。

选择 faster_qwen3 的理由：
- 本地推理，不依赖云 API
- 24kHz 输出匹配 Ditto 管线
- ICL 零样本克隆保留说话人音色
- 复现实验的原始配置

## 后果

### 正面
- TTS 确实提升唇形同步（ΔSync-C=+1.25，p=0.0005）
- 效应在 5/6 TFG 模型上泛化
- 建立了可复现的评估管线

### 负面
- 效应在英文上不成立（ΔC=+0.16, ns）
- TTS 响度自然偏高 ~12dB，可能成为混淆变量
- 需要 GPU 服务器部署 TTS 模型

## 替代方案

| 方案 | 状态 |
|------|------|
| `dashscope_vc` 云 API | ❌ 已弃用——R128 响度归一化后效应消失 |
| Fish Audio S2 | ❌ 云 API，不稳定 |
| F5-TTS | ⚠️ 可用，但非原始实验配置 |
