# ADR-002: TFG 参考帧使用视频第一帧（而非质量筛选抽帧）

## 状态

已接受 (2026-08-02)

## 背景

多数据集 TFG 实验需要从源视频为每个样本选取一张参考帧（master frame）驱动 Ditto 等 I2V 模型。初版策略（`38_prepare_frames.py`）从视频均匀采样 12 个候选帧，按 yaw/人脸大小/清晰度加权打分选出"质量最优"帧。此策略在真实 Ditto 推理中发现严重问题。

## 决策

**默认使用视频第一帧（`--frame-strategy first`）**：取满足质量门（`|yaw|≤30°`、人脸面积≥20000px）的**最早**帧；若第一帧不合格（无脸/侧脸/过小），回退到质量筛选。保留 `--frame-strategy quality` 作为显式选项。

## 理由（配对实验证据）

HDTF 3 样本配对 A/B（Ditto TRT + SyncNet，同一驱动音频，仅参考帧不同）：

| 样本 | 质量筛选抽帧 Sync-C | 第一帧 Sync-C | Δ |
|------|:---:|:---:|:---:|
| RD_Radio47 | 3.475 | 6.408 | +2.93 |
| WRA_FredUpton | 3.567 | 4.505 | +0.94 |
| WDA_AdamSchiff | 4.830 | 5.225 | +0.40 |
| **平均** | **3.957** | **5.379** | **+1.42** |

3/3 样本一致：第一帧显著优于中段质量筛选帧。

**机制**：Ditto 从参考帧提取初始运动状态（`m_ref`）、情绪（`e`）和眼睛状态（`eye`），作为生成序列的初始条件。视频中段帧通常处于"说话状态"（嘴张开、眨眼、表情丰富，如 WDA 抽帧 EAR=0.007 接近闭眼），该状态被模型当作初始状态污染整个生成；视频第一帧通常是中性状态（嘴闭合、眼睁开、正面），是最佳初始条件。这也与论文协议一致（SadTalker/Ditto 等均使用第一帧）。

## 后果

### 正面
- Ditto 同步质量显著提升（平均 ΔSync-C +1.42）
- 与主流论文评测协议一致（第一帧）
- 质量筛选保留为 fallback，防止黑帧/淡入/转场等第一帧退化情况

### 负面
- 质量打分（yaw/清晰度/人脸大小）不再主导选帧，其价值降级为"门控 + fallback 排序"
- 需记录 `frame_idx` 以便复现与审计（manifest 已含）

## 替代方案

| 方案 | 状态 |
|------|------|
| 质量筛选抽帧（初版） | ❌ 已弃用——中段"说话状态"帧污染 Ditto 初始运动，Sync-C 平均低 1.42 |
| 强制闭嘴帧（嘴开合惩罚） | ⚠️ 未实施——第一帧已足够且更简单 |
| AI 超分/修复参考帧 | ❌ 已拒绝——引入身份幻觉风险，非主实验变量 |
