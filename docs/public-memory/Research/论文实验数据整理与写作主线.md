# 论文实验数据整理与写作主线

整理日期：2026-09-23。用户希望把已有实验整理为论文可用证据，并讨论写作思路。本笔记是论文筹备的证据综合与建议，不是新增实验报告，也不是已获用户批准的投稿路线。

## 当前建议

以“语音重合成对 talking-face generation 的驱动效果及评价机制”为主线，写实证分析论文。现有证据足以支撑开写：TTS 在若干数据域和多个 TFG 上提高官方 Sync-C，但提高幅度依赖生成器、TTS、语料与测量协议；音素可分度差异尚不能充分解释下游收益；Sync-C 增益不能直接升级为视觉或感知改善。

当前不宜以“通用即插即用增强头已成功”为论文主贡献，因为项目最终目标——增强音频驱动视频、换回同一自然音轨后仍优于 natural baseline——尚未获得跨模型独立确认。这个目标继续保留，但不能作为已有结果。

暂拟标题：**Does Resynthesized Speech Improve Talking-Face Generation? An Empirical Study of Driving Signals and Synchronization Metrics**。题目不预设人类感知提升或评分偏差已被证实。是否具有发表新颖性仍需要单独做相关工作检索；本次没有完成系统文献比较。

## 机制证据及其边界

| 问题 | 现有结果 | 可写的结论 |
|---|---|---|
| Sync-C和最佳距离是否一起改善？ | AISHELL100 ΔC=+1.022，但ΔD=−0.069且未显著；multiset Ditto ΔD=+0.117 | 分数不同组成可能产生不同响应；不能仅凭C说几何同步更准确 |
| LRS3曲线分解 | LeapTalk 12来源INTERIOR ΔC=+1.253，校正CI[+0.658,+1.801]；匹配距离改善项+0.286，校正CI跨0 | 该小队列的增益更多表现为背景项变化；属于代数诊断，不是声学因果 |
| 全部历史LRS3是否都没有距离改善？ | 45来源LeapTalk等权ΔC=+1.410，最佳距离贡献+0.475，背景贡献+0.934，两项对应校正下界均正 | 不能从12来源子集推广为所有结果都只是背景变化 |
| 可分度能否预测增益？ | AISHELL100的104个唯一关联指标无FDR阳性；新英文同句差分β=+0.453/0.1 silhouette，95% CI[−0.131,+1.036]，wild p=0.0741 | 现有证据未确认可分度与Sync-C的稳定关联，更不识别因果；不是证明零关联 |
| TTS可分度是否总更好？ | LRS3 n100五臂MFA完成497/500；HuBERT L6 pooled Fisher：natural20.274、cloud27.964、local22.827、Index25.471、Cosy14.555 | 不同TTS的表征差异有异质性，不能统称TTS音素更清晰；pooled指标不能复制成逐句协变量 |
| 局部时间辨识 | A_rank约+0.055，校正CI[+0.033,+0.078]；A_event、B_instance、B_transfer均未确认 | 评价器侧存在局部时间信号，但未定位为事件、实例或迁移机制 |
| HuBERT增强头 | 中文50条：raw TTS +1.081、enhanced +0.062；MDC英文heldout14条enhanced −0.046 | 特征空间移动未展示可靠下游收益；不能据小均值宣布所有增强方法无效 |
| 感知/视觉证据 | 既有VSR没有可靠校准；新人工包PENDING_HUMAN | 尚未确认嘴型更准确，不能以未经校准的VSR或口部运动量替代真值 |
| 自然音轨replacement | 若干MFA/重合成路径失败或未确认；未获得通用跨模型成功 | 原生TTS评分优势不能当作可迁移增强头成功 |

SyncNet官方实现计算 `C = median_lag(mean_time(distance)) − min_lag(mean_time(distance))`；D是其中最小距离，AV offset来自最优lag。来源：[官方SyncNet代码](https://github.com/joonson/syncnet_python/blob/master/SyncNetInstance.py)。因此C增大可以来自背景项增大或最小距离下降；即使D下降，也不自动等于人工感知更好。公式本身是已知定义，论文贡献应是对此任务的系统实证，而不是声称首次发现这个公式。

同一批108视频，在自定义EQUAL_COUNT/固定ROI链路下四种TTS的ΔC约+0.073/−0.004/+0.086/+0.056，官方链路下为+0.736/+0.408/+0.400/+0.613。这里同时改变了裁剪/支持等流程，不能称为只换公式的单因素实验，也不能据此证明官方或自定义一方有感知偏差。它首先说明测量合同会显著影响科学结论。

## 论文叙事与章节

核心摘要逻辑：

“语音重合成改变了talking-face generation的驱动输入。我们在多个语料、生成器和TTS条件下比较自然语音与同文本重合成语音。结果显示，若干条件下官方同步置信度稳定提高，但增益并不一致反映在最佳匹配距离中，且对评价协议敏感。表征可分性与时间诊断提供机制线索，却尚不足以解释或确认视觉收益。本研究据此区分驱动输入的评分优势、生成质量与原始音轨可替换性。”

建议正文围绕三个问题展开：

1. **现象在哪里成立？** 设置同文本/同参考脸的配对研究；中文100、跨域250与最新英文多TTS作为三块证据，报告反例与缺失。跨模型表优先画模型内Δ及CI，而不是不同条件绝对分排名。
2. **评分到底反映什么？** 同时报告C、D、offset；展示距离曲线及C=B−D分解；用同视频官方/自定义流程对比说明评测合同敏感性。避免把代数分解写成评价器偏差的因果证明。
3. **哪些机制与迁移路径得到支持？** 从音素可分性、局部时间辨识，到自然音轨replacement；以证据强弱组织，不按实验编号流水账。增强头失败与窄干预可放附录，正文只保留能改变解释的实验。

Introduction先提出“输入音频也是影响TFG benchmark的重要变量”；Related Work分别覆盖语音驱动TFG、语音表征/重合成、AV同步评价；Methods明确比较对象、时间轴和统计单位；Results按上述三个问题组织；Discussion划清泛化范围、源组复用、单评价器依赖与人工结果缺失。

可辩护的贡献措辞：

- 一组跨语料、跨生成器、跨TTS的配对实证结果，描述重合成驱动优势及边界。
- 对评分组成与评测流程敏感性的实证分析，说明单一置信度不足以确认视觉同步改善。
- 将表征变化、原生评分收益和自然音轨迁移区分开来的受控诊断与可复现资产。

当前不能写：首个通用增强头；全面优于所有TFG；证明音素可分度是原因；证明全部收益来自SyncNet偏差；人工同步显著提升；英文不存在增益。

## 补实验优先级

**P0，现有资产优先。** 冻结可用run清单，统一官方端点命名，按来源/说话人重算关键区间并核验cohort重叠；完成现有人工盲评包。人工需按预设资格、延迟校准、重复一致性与来源层级分析执行，不能拿空模板称已验证。现有108视频足以先推进，不必重跑全量TFG。

**P1，补一组能区分解释的确认实验。** 在未用于探索的来源上冻结文本/参考脸/评分协议，优先两个TFG。样本量由pilot方差和最小有意义效应决定，不凭“12–16条”当充分功效。若论文只主张原生评分现象，可先补多模型与独立感知确认；若要主张增强方法，则必须通过共同自然音轨的replacement端点。

**P1，执行已写好的时间动态内部表示干预。** 该协议已有CPU验收但零新渲染。它能定位具体模型路径，仍属已看来源上的探索，不能自动作为通用方法或中介百分比证明。无需重复从零设计同样实验。

**P2，方法论文升级。** 只有精确自然时钟、内容与质量检查通过，且 `E(G(C),N) > E(G(N),N)` 在冻结模型和独立来源上成立，才增加“音频增强方法”主贡献；否则保持实证/评价论文定位。不同时间轴的raw TTS视频不能直接覆上自然音轨作因果四格。
