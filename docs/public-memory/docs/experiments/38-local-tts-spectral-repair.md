# 38 — Local TTS spectral repair：自然相位下的局部声学引入

日期：2026-09-26。状态：✅ 本轮评估完成；**当前方案未获得有效性支持**。

## 问题与结论

在自然音频时钟不变的条件下，仅在音频规则选出的过渡区引入对齐 TTS 的幅度谱、保留自然相位，能否提升使用原始自然音轨评估的 Wav2Lip Sync-C？该规则是否优于在另一个合格位置施加同类编辑？

最终统一渲染链路的 27 条、10 位说话人结果：目标修补减自然基线的逐句平均 ΔSync-C 为 **−0.003**，说话人聚类 bootstrap 95% CI **[−0.030, +0.029]**。目标减对照选区约 **+0.000**，CI **[−0.031, +0.020]**。所选局部的固定自然偏移距离也没有平均改善。

**不能据此证明过渡区可被当前操作修复，也不能证明选区规则在新样本上有效。** 这不是“所有局部声学修补均无效”的证据。本轮只检验局部声学引入；音素内部事件时间修正是独立的 [实验 37](37-mfa-linear-intraphone-time-warp.md)。

## 冻结方案

- 发现侧：`mfa_linear_heldout_speech_20260925` 的 17 条，只有音频诊断，没有用生成视频的 SyncNet 分数选区。
- 评估侧：`mfa_linear_intraphone_time_20260925` 的 27 条、10 位说话人，与上述 17 条样本及其说话人不重合，但说话人与项目更早的 10 条诊断重合。属于探索性内部验证，不是全项目未接触过的独立测试集。
- Donor 为已静音修复、映射到自然时钟的 MFA-linear F 音频，不是未对齐 raw TTS。
- 用匹配的相邻发声音素边界生成候选；两侧音素均至少 60 ms，避开停顿及端点；自然和 donor 的局部 RMS 均至少 0.003，比例在 [0.5, 2.0] 内。
- 目标区：donor 相对自然的正向谱通量峰值优势最大的合格边界，优势必须大于 0。对照区：距目标中心至少 700 ms 的最低分合格边界。规则不读取视频或 SyncNet 分数。
- 两路均为 400 ms 窗、40 ms 淡入淡出；STFT 对数幅度以 α=0.5 混合，重建使用自然相位，再通过时间掩码与自然波形拼接。这里“保留自然相位”指谱重建操作，不承诺最终拼接波形再次 STFT 后逐点相位完全不变。
- 20/27 条有目标区，18/27 条有对照区。没有合格选区则保持自然基线；主分析保留全部 27 条，未按分数或是否编辑剔除样本。
- Wav2Lip GAN 驱动输入为各条件音频；评估视频全部重新挂同一原始自然音轨，经官方 SyncNet V2 前端与置信度公式评分。

## 渲染控制修正与重复性

初轮复用了上一实验的自然基线（冻结人脸框），而 target/sham 使用重新检测的人脸框，存在渲染链路混杂。初轮表观逐句 ΔSync-C **+0.018**（CI **[+0.006,+0.036]**）**不作为修补有效的证据**，产物保留在运行根目录，并在 `analysis.json` 中标记 `CONFOUNDED`。

最终使用独立的 `matched_render/` 子目录重新生成全部自然基线和编辑视频；三路共用同一份 132 帧人脸框、`inference_cached.py`、CUDA Wav2Lip、batch=4、同一编码与帧数归一化链路。所有评分统一在 CUDA 上运行，没有混用初轮 CPU 分数。没有更改音频选区、混合强度或评分目标。

修正时另固定前三条 ID 做自然音频重复渲染控制，作为工程诊断，不用于挑选哪一次自然基线：

| 样本 | N Sync-C | N-repeat Sync-C | 重复减首次 |
|---|---:|---:|---:|
| a1_003 | 7.275 | 7.275 | +0.000 |
| a1_004 | 8.503 | 8.503 | +0.000 |
| a1_005 | 6.516 | 6.411 | −0.105 |

前两条最终视频 SHA256 相同，第三条不同。**冻结人脸框没有完全消除渲染/编码/评估整条链路的重复性波动；本轮未定位具体来源。** 下述 bootstrap 区间反映说话人抽样不确定性，不包含重复生成的方差分量，不能拿极小均值变化作强结论。

## 最终结果

| 条件 | 全部 27 条平均 Sync-C |
|---|---:|
| 自然 N | 5.960 |
| 目标区修补 | 5.957 |
| 对照区修补 | 5.956 |

主估计量是逐句平均配对差；以说话人为整体有放回抽样 10,000 次，抽中的全部句子按句数加权，seed=20260925。另报告说话人等权敏感性估计，不混称为逐句主结果。

| 比较 | 逐句平均差 | 95% 聚类 bootstrap CI | 说话人等权平均差 | 95% CI |
|---|---:|---|---:|---|
| 目标 − N，Sync-C | −0.003 | [−0.030,+0.029] | +0.002 | [−0.043,+0.059] |
| 目标 − 对照，Sync-C | +0.000 | [−0.031,+0.020] | −0.014 | [−0.069,+0.028] |
| N − 目标，Sync-D（正值才是改善） | −0.001 | [−0.015,+0.019] | +0.003 | [−0.026,+0.036] |

目标相对 N：9 条上升、11 条下降、7 条身份操作保持不变；只有 3/10 位说话人的平均差为正。目标与 N 的最佳整句 offset 在 27/27 条上相同。

### 局部诊断

固定每条自然 N 的最佳偏移，在选区中心落入的 SyncNet 窗口上比较距离。这是描述性距离指标，不是局部 Sync-C，也不是独立嘴型真值。

| 选区 | 有选区条数 | 距离平均改善（N − 编辑） | 改善条数 |
|---|---:|---:|---:|
| 目标区 | 20 | −0.079 | 10/20 |
| 对照区 | 18 | +0.013 | 10/18 |

目标区没有平均改善，不能把少数个例的上升解释成已识别到可修复区域。target/sham 的编辑覆盖率和声学改变剂量不完全一致，目标减对照是完整策略对比，不是严格剂量匹配的纯位置因果效应。

## 工程验收与范围

- 运行前 Tesla V100-SXM2-16GB 为 5 MiB / 16,384 MiB、利用率 0%；没有抢占繁忙 GPU。最终 GPU 回到 5 MiB、0%，本轮无遗留任务。
- 最终 68 个视频：27 个 N、20 个 target、18 个 sham、3 个 N-repeat；27 个完整逐条评分文件。
- 每条所有条件的解码自然 PCM 哈希相同，裁剪帧数与特征支持相同；评分过程断言全部通过。共同的容器解码补帧不强行等同于渲染目标帧数。
- 44 条发现+评估音频的掩码外 PCM 完全相同，样本数不变；评估集远离编辑区的 Wav2Lip mel MAE 为 0。
- 评估集目标/对照的窗内 Wav2Lip mel MAE（无选区记 0）为 0.184990 / 0.209344，确认编辑进入生成器前端。最大波形峰值为 0.475220，没有削波；未做听感/ASR 内容质量评审，不能声称感知质量无损。
- 5 个单元测试通过；Ruff 检查通过。测试覆盖音素匹配、掩码外身份、无选区身份、采样时钟拒绝、句子/说话人加权区别。
- 仅一个 Wav2Lip checkpoint、一个固定脸源、一个编辑强度和窗长。不能外推到 Ditto 或其他 TFG，也不能仅凭 SyncNet 声称真实口型更准确。

## 复现与产物

脚本：`scripts/experiments/local_tts_spectral_repair.py`。
测试：`tests/experiments/test_local_tts_spectral_repair.py`。
运行：`runs/local_tts_spectral_repair_20260925/`。

正式结果以 `matched_render/analysis.json` 为准；其 `provenance` 包含脚本、manifest、Wav2Lip checkpoint 哈希，`protocol.json` 包含冻结框和推理入口哈希。初轮根目录结果只保留用于审计。

```bash
# 已有冻结 manifest/audio 和来源实验产物时：
OMP_NUM_THREADS=2 MKL_NUM_THREADS=2 .venv/bin/python scripts/experiments/local_tts_spectral_repair.py render --matched-render --split evaluation --device cuda
OMP_NUM_THREADS=2 MKL_NUM_THREADS=2 .venv/bin/python scripts/experiments/local_tts_spectral_repair.py score --matched-render --split evaluation --device cuda
.venv/bin/python scripts/experiments/local_tts_spectral_repair.py analyze --matched-render --device cuda
.venv/bin/python -m pytest -q tests/experiments/test_local_tts_spectral_repair.py
```

命令支持断点续跑并复用已存在产物，不是强制重新抽样。正式局部音频仍引用父目录冻结音频；不得删除父目录后只保留 `matched_render/`。

## 下一步判据

本轮应停止把“最大正谱通量差”当作已经验证的修复定位器。若继续，先定位并压低身份重渲染噪声，再在发现集区分“操作本身有可重复的局部收益”与“规则能预先预测收益”；只有两者成立，才将规则冻结后放到新的、未接触说话人的评估集。不要在当前 27 条上调窗口/强度后仍称为独立验证。
