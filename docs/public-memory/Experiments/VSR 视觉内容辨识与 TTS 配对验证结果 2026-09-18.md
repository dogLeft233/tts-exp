# VSR 视觉内容辨识与 TTS 配对验证结果 2026-09-18

- implements [[VSR 视觉内容辨识与 TTS 配对验证实施部署 Spec]]
- run: `runs/vsr_tts_content_v1_audit2/`
- model: CMLR `CMLR_V_WER8.0` visual-only VSR；冻结官方 AVSR fork，commit `84c148a33c14189eda9dcabcc39fed96f8da30d9`
- cohort: AVTR-1 natural/TTS 历史视频 13 对；全部音频说话人 S0764。不是独立验证集，也不代表跨说话人效果。

## Observations
- [status] concluded

- audit 正确绑定 `runs/r2_assets/README.md` 的 WID 与文本；旧 pilot 使用了另一套 AISHELL100 同名编号，旧 JSON 统一标记 `INVALID_REFERENCE_BINDING`，不作为证据。
- 26 个视频全部通过视频流去音轨、帧 hash/PTS 一致、MediaPipe 单脸与检测率检查；每侧保存 native/frozen/reversed/matched/matched_frozen 五种视图，130 个视图均有 encoder 与 CTC logp。
- 测量校准通过：natural native 严格 top1 = 9/13 (0.692)，Q>0 = 11/13 (0.846)，mean Q = 1.173；TTS native 严格 top1 = 11/13 (0.846)，Q>0 = 10/13 (0.769)，mean Q = 1.408。
- 主要配对量 (G=Q(T)-Q(N))：mean +0.234，median +0.251，positive = 9/13，95% bootstrap CI [-0.329, +0.793]。
- 原始内容差 (B=M(T)-M(N))：mean +0.368，95% CI [-0.168, +0.939]；同长度敏感性量 (Gmatched)：mean +0.084，95% CI [-0.485, +0.659]。
- 反转时间顺序的诊断 (R)：mean +1.709，95% CI [+1.181, +2.246]，说明该冻结 VSR 在这批视频上确实利用了时间顺序；它不是 TTS 增益的因果证明。
- 独立 log-space CTC DP 复算 PASS：最大 CTC 绝对误差 (7.1\times10^{-15})，最大 logp 行归一化误差 (1.17\times10^{-6})，统计复算误差 0；同设备 encoder/logp 重复前向最大误差 0。
- 固定判读：`NO_CLEAR_PAIRED_GAIN`。虽然 TTS 的 G 与 B 均值为正，G 的区间跨 0，不能据此说 TTS 视频已被 VSR 稳定识别得更好，也不能把 SyncNet 的 +0.327 历史差异归因于视觉内容。
- 该结果只说明“在冻结 CMLR VSR 对这 13 对、单说话人的合成头像视频上，TTS 的动态内容支持点估计偏正但不确定”。它不检验人类感知、毫秒同步、音频端输入或 replace head。

## Post-hoc VSR–Sync-C linkage

原始 VSR audit 没有把逐样本 VSR 优势与 Sync-C 差值做正式关联；当时只把历史 Sync-C 均值作为描述性背景。随后使用 13 个相同样本 ID，将主指标 (G_i=Q(\mathrm{TTS}_i)-Q(\mathrm{Natural}_i)) 与历史 Sync-C 差值 (ΔC_i=C(\mathrm{TTS}_i)-C(\mathrm{Natural}_i)) 做了事后检查。

- (G_i>0)：9/13 个样本；(ΔC_i>0)：7/13 个样本。
- 两者同时为正：5/13；VSR-only 4 个；Sync-C-only 2 个；两者都不为正 2 个。
- 连续值关联很弱：Spearman (ρ=0.022), (p=0.943)；Pearson (r=0.078), (p=0.799)。
- 若使用原始内容差 (B_i=M(\mathrm{TTS}_i)-M(\mathrm{Natural}_i))，与 ΔC 的 Spearman (ρ=0.203), (p=0.505)，结论相同。

这只是事后探索，不改变主实验的 `NO_CLEAR_PAIRED_GAIN` 判读：样本量为 13、全部来自同一说话人，Sync-C 使用已有历史评分而非本轮重新评分。因此目前不能说 VSR 判定的优势直接解释了 Sync-C 提高；后续若要正式检验，应在更大且同一批次重评分的配对数据上预先定义 (G_i) 与 ΔC_i，并进行逐样本相关及置换检验。
