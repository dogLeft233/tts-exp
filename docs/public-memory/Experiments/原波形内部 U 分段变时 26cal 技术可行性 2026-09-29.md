# 原波形内部 U 分段变时 26cal 技术可行性 2026-09-29

日期：September 29, 2026。状态：concluded（技术几何 PASS；原生因果解释 HOLD）。本轮只是旧 26cal/13 speaker 的 CPU 工程可行性，没有 GPU、视频或 SyncNet 效果；74eval 未触碰，不把技术成功写成科学阳性。

## Observations

- [question] 能否在原 FIXED T 波形上按封存 E/U 内部时钟精确变时，从而绕开 WORLD→RAW identity 桥失败？
- [result] 完整 U 只改变 MFA silence 且要求 N 来源目标时长，26cal 中 19 条非空 U **0/19** 可行。保守可定位静音核＋句端静音补偿只覆盖 6/26 对、5/13 speaker，剂量中位 20ms（10–50.6ms）；不足以替代完整 U 因子。
- [result] 分段 RubberBand R3/64 样本有连续失败版本：全段R3的ID脉冲−2样本超旧±1门；unity复制未护接缝的真实 U 右锚4/19超±320样本；未限保护在短U会吞掉全部内部材料。失败文件完整保留。
- [result] 最终受限 U 右端保护版在 26cal 所有段长 exact、全句RMS最大误差3.56e−11，T ID 波形及官方 mel/chunk/MFCC 26/26逐值exact，真实几何 38/38 U边界合成脉冲锚误差0；734接缝的单样本跳幅无一超过局部导数p95五倍（未护版48）。该 ID exact 来自 ratio=1 逐样复制，**不是 changed R3 相对原始波形的声视频等效桥**。
- [result] 53个变时U段的保护/淡化区占目标U段中位38.5%、最大76.7%；15段伸缩比超[0.5,2]。在相同目标时钟下，保护版与全R3版的 Wav2Lip mel MAE 中位0.110、SyncNet MFCC window MAE中位1.315。可见保护操作本身明显改变输入声学，定时精确不足以识别纯U时钟作用。
- [conclusion] 原波形全U变时当前为 **HOLD**：不启动74eval GPU，不把后续可能的Sync-C变化归为原始U时钟的独立因果作用。若重启需另冻26cal声视频身份/载体桥及changed同map对照；当前更优先用可精确identity的官方原生 mel/MFCC 输入层时间干预，明确其不是可播放原波形。
- [constraint] 本轮无独立 reviewer、无正式效果；26cal反复工程修复均在输入/合成脉冲与前端层，旧v6失败门未放宽。正式统计不得把这批技术探索叫独立新队列确认，也不能把T侧exact ID自动扩展到N侧共同T总长。
