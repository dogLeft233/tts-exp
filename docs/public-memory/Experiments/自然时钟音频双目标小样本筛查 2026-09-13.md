# 自然时钟音频双目标小样本筛查 2026-09-13
固定既有低强度Bridge队列前3条音频与3号静态正脸图，不按分数筛选。完成轻量EQ、自然时序条件FastPitch、DAC高保真identity三方向。主比较为真实自然视频配候选音频的匹配保持，以及静态生成视频配其驱动音频的原生增益，不要求replacement。

## 方法与结果

EQ为固定1500Hz宽高架+2dB、自然STFT相位及全局RMS恢复；DAC为本地16k全码本identity，右裁回自然长度，不改音量；FastPitch使用官方预训练模型，外部指定自然MFA音素时长、自然phone平均F0与能量，直接生成mel后由官方HiFi-GAN合成，不事后warp。FastPitch为LJSpeech单女声，不自克隆；IPA转CMU/allophony/stress有近似，输入边界锁定不证明输出发音边界准确。

|方案|真实视频ΔC|静态生成原生ΔC|原生D改善|双条件样本|
|---|---:|---:|---:|---:|
|EQ|+0.011|+0.002|+0.001|0/3|
|DAC|−0.159|−0.010|+0.022|0/3|
|FastPitch|−1.656|−0.096|+0.561|0/3|

双条件逐样本指真实ΔC≥−0.100且原生ΔC>+0.050，不等于统计显著。EQ原生CI[−0.009,+0.013]；DAC[−0.231,+0.242]；FastPitch[−0.824,+0.918]。n=3区间不稳定、未校正多比较。

第一条FastPitch原生+0.918，自然视频−0.577；第三条DAC原生+0.242，自然视频−0.350。没有方案同时达到两个目标，不能从原生增长推断自然口型兼容，也不能否定三类技术所有实现。

## 核验与边界

14个视频、26个静态矩阵及14个真实视频矩阵。首条独立重复误差0；200ms延迟lag+5、固定lag损伤5.690；LOCAL_SWAP两段双向偏好均通过。控制只覆盖首条。

全量CPU核验14视频逐帧ROI外静态/画面hash、26静态矩阵音视频绑定、共同支持独立重推及27端点差值重算，最大误差0；首条×单图7cell独立官方前向误差0（不是全部矩阵重新前向）。39项相关测试及Ruff通过。

初次目录natural_clock_pilot_20260913中FastPitch官方多卡module前缀导致加载失败，没有评分；修正权重键加载后在v2重新冻结，原目录保留。GPU串行使用，全部任务已退出，没有终止其他任务。新增官方FastPitch/HiFi-GAN权重约241MB。

未做主观盲评、ASR/PER或输出重新forced alignment；不宣称音质/可懂度/真实同步改善。n=3、seen-fit、单图探索，不支持泛化或训练。原生D与C有分歧，不能以D改善代替C增益。
