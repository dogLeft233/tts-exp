# 原生 TTS mel 对齐与视频重定时的生成顺序实验 2026-09-26

## 冻结设计

用户要求继续自动实验。窗口时钟补偿未救回38条迁移残差后，比较G(warp T_mel)与warp G(T_mel)。保留同一38条/13音频说话人和MFA音素边界映射，使用既有静态正脸协议全部3张源图（3/6/9），复用已固定生成框/评分框与hash；本轮不看图选脸，不按新分数选样。历史图集合不是全新未见来源确认。

每图/样本生成N原始mel、T原始mel、PRE将原生T的Wav2Lip 80维mel按自然音素边界时间场重采样后直接输入冻结Wav2Lip、NRT自然mel经逆/正同一时间场两次重采样的损伤对照。另从原生T输出得到POST视频重定时、POST40使用固定校准40ms时钟补偿。全部输出采用相同静态图和固定框，口部框外像素不变，无声码器。PRE/NRT用精确N mel长度和N生成帧数，POST也相同输出帧数。所有迁移评价用同一原始自然PCM，原生T另报自己T PCM分数。

主终点PRE−POST及PRE−N，guard20；次要POST−N、POST40−POST、NRT−N及原生T−N。每条先对3张图等权，再对13说话人等权bootstrap20000，seed20260926；另报每张图，避免把114个视频当114个独立音频样本。95/99%区间、C/B/D与固定N最佳偏移距离；无SyncNet参数搜索。先看基线是否存在原生T优势，不用原生高分代替迁移目标。

固定插值、模型、mel前端、图像hash。首个N重复推理，记录精度、模型sha和完整mel/视觉embedding/距离矩阵。共享GPU lease、外部占用检查，串行生成/评分。静态共同裁剪协议不同于旧动态crop，绝对Sync-C不直接跨协议比较。direct mel是机制探针，不是可播放音频方案；不把成功/失败推广为全部迁移方法或人类观感。

## 静态协议测量对照（主结果揭示前追加）

对每张图固定前2条N视频，共6条，检查冻结中间帧和开头补5帧的已知延迟。共用原N有效窗口及guard20；预设每条N−冻结帧C>0.5，延迟后offset变化与+5帧相差≤1。不以对照分数筛选主队列；失败时限制对该静态协议的判读。对照用于验证动态响应和时间方向，不等于感知真值。

## 发音窗口与处理对照读数（结果揭示前固定）

补充PRE−NRT比较，检查生成前对齐的收益是否超过自然mel同管线往返。另复用既有源音频哈希绑定的自然MFA发音中心窗口（row/25+0.1落在非空word区间），只取当前共同有效支持与guard20交集，比较同自然PCM的PRE/POST/POST40/NRT/N。每个条件使用同样的自然发音窗口，不按分数选窗；该窗口定义仍包含跨停顿上下文，不能称纯音素级真值。作为敏感性分析，不替换整段主终点。

## 主要发现与机制判断

1. **阳性参照存在，但不能直接迁移。** 三静态图平均的原生T−N为+0.553 [0.374,0.724]，每张图均为正；原生最佳距离D差+0.031 [−0.066,0.124]，背景B差+0.584 [0.384,0.786]。该协议中C的提高在算术上主要来自错位背景距离增大，没有确认最佳配对距离改善。这是分数分解，不是“评价器偏好解释百分比”，更不是人眼嘴型质量证明。
2. **生成与时间变形的顺序确实重要。** 先对齐原生T mel再生成（PRE），比先生成后变形视频（POST）高+0.591 [0.450,0.750]；最佳距离降低−0.508 [−0.667,−0.373]，固定自然lag距离降低−0.563 [−0.751,−0.396]。三图均复现。不能把旧视频迁移失败全部等同于T输入没有可用信息；但这个结果也不唯一定位神经模块，因为前后操作改变的局部上下文与重采样表示不同。
3. **顺序修正没有实现自然声音增强。** PRE−N仍−0.411 [−0.537,−0.297]；每图分别−0.432、−0.538、−0.263，95%区间均在0以下。最佳距离增加+0.544 [0.422,0.686]，固定N lag距离增加+0.582 [0.457,0.731]，因此不只是背景B下降导致的低C（本例B反而增加）。本实验固定原始自然PCM、共同静态几何、输出长度、无损视频，不经声码器。
4. **有处理损失，但该诊断不足以解释全部差距。** 自然mel往返NRT−N为−0.108 [−0.159,−0.067]，PRE−NRT仍−0.303 [−0.444,−0.182]。NRT不是PRE严格配对的反事实，不能扣除后声称“净声学损失”或解释比例。它说明往返处理确有损伤，且在此对照下仍观察到额外差距。
5. **固定40ms补偿的收益依协议而变，始终未超过自然基线。** 静态POST40−POST为+0.296 [0.220,0.382]，但POST40−N仍−0.706 [−0.900,−0.518]。旧动态协议对应补偿只有+0.042且区间跨0。因此不能宣称固定时钟偏移完全无作用；它在本静态协议改善了后处理，却没有救回迁移。
6. **非发音窗口不是本轮阴性的唯一原因。** 限定共同自然发音中心窗口后，PRE−N仍−0.420 [−0.575,−0.286]，PRE−POST为+0.488 [0.396,0.590]，PRE−NRT为−0.292 [−0.435,−0.171]。
7. **原生优势对边界窗口敏感，迁移阴性更稳定。** 主guard20去掉首尾各20个窗口；guard15的原生差+0.544，但包含边缘/音频零填充支持的guard0仅+0.169，99%区间跨0。不能把主结果称为不依赖窗口选择的全轨优势。PRE−N在guard0/15/20分别−0.380/−0.395/−0.411，PRE−POST分别+0.677/+0.546/+0.591；13/13说话人在三种guard下均为PRE低于N且高于POST，99%区间仍同向。主guard及敏感性均在评分前固定。

综合当前证据，最可信的工作解释是：原生TTS的视听时间及声学组织能带来自身配对的可辨识性优势；将其用于原始自然声音需要保留与该声音匹配的细粒度运动。音素边界重定时、生成窗口补偿及生成前mel对齐都没有实现这个目标。生成顺序能解释一部分方法间差异，但现有实验还不能唯一分离音素内部相位误差、共发音/运动形状、生成器对输入域的响应和SyncNet的表征偏好。

本轮不再在同一历史队列上按SyncNet分数搜索新的warp或挑选源图。增加类似参数网格的辨识价值已低；要继续区分上述残余机制，需要独立的跨臂事件标尺或具有可验证目标/非目标变化的干预，并在新语音来源上确认。这是当前设计的识别边界，不是“所有自动实验都已穷尽”或“TTS完全没有有用信息”。


## 复核与产物

6/6静态/延迟对照通过，冻结帧C下降4.217–7.198，已知5帧延迟均测得+5；三图首条重复推理像素完全一致。独立复核PASS：1,391次hash、2,088组C/B/D/offset、106,020个距离抽样、444组bootstrap，87,903帧外部静态区域；分数/统计误差0，距离3.815e−6，mel插值2.384e−7。独立checker初版重复起始锚点边界语义有误，修正checker后通过，生成数据/映射/评分未改变。没有进行人工嘴型评分。

报告 runs/tts_prepost_mel_20260926/report.md；protocol.json、analysis.json、speech_analysis.json、controls/、validation.json、execution_provenance.json、score_table.csv、summary.png/pdf。脚本 scripts/experiments/tts_prepost_mel.py、tts_prepost_controls.py、check_tts_prepost_mel.py。38历史音频/13说话人，固定3源图，不是114个独立音频样本；先图内平均再说话人等权，20,000次bootstrap。所有迁移使用精确同一自然PCM，guard20为主，0/15为预定敏感性。GPU先检查占用并使用共享lease，现已释放。
