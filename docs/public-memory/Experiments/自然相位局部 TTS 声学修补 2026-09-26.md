# 自然相位局部 TTS 声学修补 2026-09-26

| Notes | Modification Date | Approved By |
|:--|:--|:--|
| Initial Document：完成统一渲染及重复控制的结果记录 | September 26, 2026 | — |

用户希望在自然音频基础上引入 TTS 特征，提高换回自然音轨后的 Sync-C，并验证哪些过渡区可修复及规则的泛化。此轮只检验局部声学引入：自然时钟不变，MFA-linear 静音修复 F 为 donor，400 ms 窗、α=0.5 对数幅度混合、自然相位重建和 40 ms 淡入淡出。用音频谱通量差选目标边界，另选距离至少 700 ms 的最低分合格边界作对照。没有用生成视频评分筛选位置。

发现侧 17 条仅做音频诊断；评估 27 条、10 位说话人，与发现侧说话人不重合，但和项目更早诊断的说话人重合，不是全项目封存独立测试。20 条有目标选区，18 条有对照区，无选区按身份操作计入全部 27 条主分析。

初轮复用冻结框自然基线，却重新检测修补视频人脸框，表观 ΔSync-C +0.018 不可归因于音频修补。保留初轮产物并标为 CONFOUNDED；另在 matched_render/ 重跑全部 N/target/sham，统一冻结框、CUDA 推理与 CUDA 评分，不改变音频与选区。最终结论仅依据统一链路。

## Observations

- [status] concluded
- [hypothesis] 音频规则能定位过渡区，在保留自然时钟与相位的局部幅度谱引入下，提高自然音轨 Sync-C，并优于非目标位置的相同类编辑。
- [result] 最终逐句平均 Sync-C：N=5.960，target=5.957，sham=5.956。target−N=−0.003，10 说话人聚类 bootstrap 95% CI [−0.030,+0.029]；target−sham≈+0.000，CI [−0.031,+0.020]。
- [result] 说话人等权敏感性估计 target−N=+0.002，CI [−0.043,+0.059]，与逐句主结论一致。目标相对自然为 9 升、11 降、7 不变；3/10 位说话人平均为正。
- [result] 20 条目标区固定自然最佳偏移的局部距离平均改善为 −0.079（即距离增加），仅 10/20 条改善；该指标是描述性距离，不是局部 Sync-C。
- [risk] 前三条固定 ID 的自然音频独立重复渲染 ΔSync-C 为 +0.000、+0.000、−0.105。前两条视频 SHA256 一致，第三条不同；整条链路仍有未定位的重复性波动。bootstrap 不含重复生成方差。
- [conclusion] 未证实当前 400 ms、α=0.5、最大正谱通量差选区方案能修复过渡区，亦未证实规则比对照位置有效；不能外推为所有局部修补无效，更不能声称真实嘴型准确度改善。
- [validation] 最终 68 个视频、27 个评分文件；同条各条件自然 PCM、裁剪帧数和支持一致。掩码外 PCM 恒等，远区 Wav2Lip mel MAE=0；编辑进入 mel 前端且无削波。5 个单元测试及 Ruff 通过。未做听感/ASR 内容质量评审。

- [inputs] runs/mfa_linear_heldout_speech_20260925/；runs/mfa_linear_intraphone_time_20260925/；paired MFA tokens。
- [outputs] runs/local_tts_spectral_repair_20260925/matched_render/analysis.json 为正式结果。父目录初轮 analysis.json 有渲染混杂，只供审计；音频仍存父目录，不可只保留子目录。
- [model] Wav2Lip GAN checkpoint + 官方 SyncNet V2；一个固定脸源。运行前 GPU 空闲，结束后无遗留任务。
- [code_paths] scripts/experiments/local_tts_spectral_repair.py；tests/experiments/test_local_tts_spectral_repair.py。
- [next_step] 若继续，先压低身份重渲染噪声；再分别检验操作有无可重复局部收益和规则能否预测收益；冻结后才上全新说话人。不要在这 27 条调参后仍称独立验证。
