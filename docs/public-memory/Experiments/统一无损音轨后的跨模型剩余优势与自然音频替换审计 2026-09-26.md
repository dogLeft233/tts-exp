# 统一无损音轨后的跨模型剩余优势与自然音频替换审计 2026-09-26

用户授权继续实验，直至现有数据和评价方法下没有明确有信息价值的下一步。沿用GPU占用检查与BM持久保存要求。

## 冻结顺序

1. 从 AISHELL-1 云Qwen n100 历史队列逐条审计原始驱动WAV、生成视频、官方裁剪/轨迹及哈希。优先05原实验，其次12同配置补充；选择只依据资产完整性，记录100条的缺失原因与覆盖，不按分数筛样。
2. 对合格N/T/M（MFA-linear自然时间轴）重新提取官方视觉特征，用统一原始PCM评分；重放历史音轨以验证来源。主分析共同窗口guard20，FULL及guard15为敏感性；以说话人为bootstrap单位，报告语句均值及说话人等权均值。
3. 同时间轴N/M做视频×评价音频四格：N视频/N音、M视频/N音、N视频/M音、M视频/M音。验证样本数/裁剪时间和共同支持。原生TTS仅同臂评价，不把不同时间轴的N/T直接互换当因果分解。
4. 有天然重合成D视频的子集增加同一自然评价音轨对照，区分TTS供体与一般vocoder/生成改变；记录子集范围。
5. 根据统一PCM后是否仍有优势选择后续：评价音频受控频带/时间变化、生成端对照或更严格对齐。每个新增分支先冻结设计再看对应结果，不持续换条件追显著。
6. 停止准则：清晰的可操纵路径已经正反干预，剩余假说需要缺失来源链、未校准独立真值或新增人类评价；不把自动高分等同嘴型改善，不用“不显著”证明没有效果。

## 完成结果

74对、13说话人，Wav2Lip + 云Qwen自克隆；100条历史资产中54条来自05原实验、20条来自12同配置补充，26条缺失已逐条登记；按资产完整性选择，无按分数筛选。N/T存档WAV均16kHz。同一动态源脸视频，不是静态照片；不是未见数据独立确认。

主分析interior guard20、说话人等权均值、说话人bootstrap 20,000次。以下为均值及95%CI，未做多重比较校正：

### 分数机制与有效性检查

- 原生ΔC由ΔB=+0.784、ΔD=−0.151组成。B约占均值算术分解84%，不是因果解释率。B是错位距离背景中位数，D是最佳匹配距离。
- 74/74原生T更短，T/N时长比中位数0.819。共同视听变速影响部分差距，但残余仍正。交换时长后ΔB降至+0.053，ΔD变为−0.535，显示两项可相互补偿。
- 保持特征完全不变，仅把B的lag范围按相对时长换算，诊断C*分差从+0.931到+0.872，变化−0.059 [−0.141,+0.018]。C*不是官方Sync-C。
- 独立MFA3.4.1对齐实际N/M/D波形163条；74/74配对词序通过。逐句词中心绝对偏差中位数跨句中位数5ms，但少数最大偏移可达905ms。
- 正向音频时间映射优于反向+0.240，但比identity差；N视频套同映射也下降−0.503，故此负结果不能排除所有视觉/音素时序机制或插值损伤。
- 15句/3说话人D直接自然重合成子集：自然声音替换−0.145；M较D再低−0.488，子集小，仅作辅助。
- 两个共同ROI轨迹结论一致，原轨迹重建视觉特征误差0；FFV1处理管线identity特征并非完全相同，时间干预采用自身管线identity作对照。
- 旧完整评分重放最大差0.000499293，符合三位小数舍入。独立checker PASS：4979项哈希、9915组分数、402070个抽验距离、243个bootstrap汇总；最大距离误差3.815e−6，分数/区间误差0。Ruff通过。
- GPU各阶段检查占用并串行运行，结束后空闲；保存协议、原始矩阵、特征、音视频、MFA与映射、图表和执行源码哈希。

### 当前结论与停止边界

旧Ditto编码高频损伤机制依然成立，但不能概括新Wav2Lip/云Qwen队列。新数据强烈支持“自身音视频配对高分 ≠ 自然音频可迁移收益”。语速、静音和评价协议是部分来源；剩余最稳妥描述为SyncNet下更强的具体视听配对可辨识性，不能进一步宣称真实嘴型普遍改善或TTS本身完全没有可迁移信息。

完成来源/无损、四格、ROI、频带、时间正反干预、联合变速、lag、去静音及联合控制后，继续自动试分难以区分真实视觉改善和评价偏好。下一项有决定力的工作需要经过校准的独立视觉事件/评价或人类盲评，以及新的源脸/说话人交叉确认。当前MFA-linear未达到自然声音替换目标，不用自身TTS分数代替。停止这轮自动探索，不宣称科学机制已全部识别。
