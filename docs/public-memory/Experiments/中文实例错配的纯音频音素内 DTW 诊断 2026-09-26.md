# 中文实例错配的纯音频音素内 DTW 诊断

## Observations
- [status] concluded
- [question] 独立纯音频细对齐能否恢复实例错配正距离，而非评价器oracle选最小值？
- [protocol] 单一Wav2Lip原80维mel（实际TFG前端的归一化logmel），每音频全时长逐带CMVN std=max(std,1e-8)，原生80Hz中心m/80。每同序同phone内端点约束DTW，步进diag/(1,0)/(0,1)，累计80维平方距离，tie按该顺序。共同路径每源帧取匹配目标帧均值，双向均由同一路径，query中心线性插值，端点外钳制。没有用视觉/SyncNet选映射或参数。
- [seal] 100对音频全部建图：87对Q1/Q2 phone序列兼容、13对不兼容留记录，3004个phone中1空格点路径。原primary/MFA-only所有query均有路径，支持不变。303项音频/mel/路径/控制hash封存后，离散query映射再独立封存，然后才读取评分缓存。audio-only进程审计钩子禁止SOURCE scores/audio_features/control_scores和oracle目录读取。
- [query] 主20条/12speaker、MFA-only48条/15speaker，k3主/k2/4各自原query。目标最近40ms有效audio行，限制原MFA±80ms、同phone、guard20；tie最小原点位移再索引，空池/缺路径回退原点。raw/unit使用同一封存映射，self和visual完全固定。
- [statistics] 先query/条内平均，再speaker等权，20000 PCG64 seed20260926，95/99CI。以下均99%CI；只positive距离，不是q或官方C分解。
- [result] 主k3 raw cross−self：原MFA +1.025[+0.788,+1.242]，纯音频DTW +0.873[+0.660,+1.108]，既有oracle80 +0.097[−0.142,+0.357]。配对DTW−MFA −0.152[−0.278,−0.035]，小幅改善可确认。
- [geometry] 主k3 unit原MFA +0.119[+0.093,+0.143]，DTW +0.100[+0.076,+0.127]，oracle +0.013[−0.015,+0.042]；配对变化 −0.019[−0.034,−0.005]。各几何原生self单独处理，不跨量纲算比例。
- [directions] 主raw DTW−MFA：VQ1→AQ2 −0.090[−0.279,+0.065]；VQ2→AQ1 −0.215[−0.429,+0.009]。两方向单独99%CI都跨0，合并配对改善确认，不宣称每方向都确认。
- [sensitivity] MFA-only48/k3 raw DTW残余 +0.841[+0.724,+0.941]，DTW−MFA −0.082[−0.148,−0.017]。主k2残余 +0.614[+0.368,+0.895]、变化 −0.177[−0.337,−0.047]；k4残余 +0.272[+0.123,+0.442]、变化 +0.100[−0.016,+0.209]。改善未在k+1保持，全部预设结果保留。
- [mapping-diagnostics] 主685query/1370方向：354方向改变audio行，0回退，27路径端点钳制，322目标超出离散候选范围，其中仅8超出原MFA中心±80ms，不能把322都叫80ms限幅。选中位移计数−80:12、−40:153、0:1016、+40:186、+80:3。speaker平均改变比例26.4%，绝对位移10.88ms。
- [controls] 固定cal首ID a1_001/Q1：identity路径全对角、时间/索引误差0。每phone>=80ms前半映至前75%、后半映至后25%，waveform线性取样，时长/边界不变。21phone×3phase×2方向=126点，MFA→DTW时间MAE 20.95→19.47ms，40ms索引MAE .556→.524帧。>=160ms仅2phone/12点，时间MAE32.50→39.17ms，索引MAE .917→1.167帧，反而变差。变形改变局部频谱，是时间操纵检查而非音色保持合成；不据控制/主结果调参。
- [conclusion] 主k3存在独立于SyncNet选时的有限改善，因此oracle效果不必全部视为评分器选择偏差；但DTW留下明显残余、lag敏感性不稳定、已知时间变形恢复弱。当前仍不能把残余归为非时序实例专属效应；时序贡献尚未识别，不能算native优势贡献百分比。没有建立可用于真实自然迁移的可靠时序恢复能力。
