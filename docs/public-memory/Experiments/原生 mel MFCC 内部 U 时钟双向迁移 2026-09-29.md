- [status] concluded；历史共享队列内原生 Wav2Lip mel/SyncNet MFCC 输入特征层因果实验完成。258 AVI/V/A 的不同 agent live 审计 PASS，v2 评分静审 PASS，74 份记录与全部1024项统计不同 agent 数值复核 PASS。首次评分在第9对因短片段空 guard20 几何 query 停止；原8条及失败账保留，事前技术勘误仅令该诊断返回 null，版本化续算66条。全74保留，主支持71对/15说话人。
- [question] WORLD 域中 TTS 句中 U 时距有正效应，但 WORLD→原生波形 identity 桥失败；把自然/TTS 的内部 U 时距在两个模型原生输入特征网格上互换，能否双向改善自配 Sync-C？U 包含内部停顿及邻接发声半段，不是纯静音。条件同全句RMS和总时长；首尾 E 保留来源，S 用来源相对时距补偿。非恒等角是特征时轴重采样，不是可播放音频。
- [primary] 预封 raw/guard20/C、71对/15人、PCG64 seed20260929 20k speaker bootstrap：N_gain=C(N_U←T)−C(N_ID)=−0.139002，95%CI [−0.249998,−0.022274]，99%CI [−0.284744,+0.013411]；T_loss=C(T_ID)−C(T_U←N)=+0.150571，95%CI [+0.049065,+0.256644]，99%CI [+0.019113,+0.289771]；两者差−0.289573，99%CI [−0.460142,−0.121250]。预封两项99%CI下界都>0的双向正门 **FAIL**。T来源原U时序有正响应，移植T时序到自然来源没有提升；来源依赖明确。N负向的99%CI跨0，不宣称确定负效应。

- [interpretation] WORLD U 正响应与本实验T_loss同向，但原波形→WORLD桥失败且干预定义/输入层不同，不能将两数值除以原生T−N差充当解释比例。该结果提示TTS局部时序与其声学轨迹/生成路径配合，而非可直接迁移给自然音频的通用时序表。它不证明物理波形因果、主观嘴型更准、原Ditto TRT或新说话人外推；独立参考句40人RAW/FIXED/COMMON_T另作确认。
