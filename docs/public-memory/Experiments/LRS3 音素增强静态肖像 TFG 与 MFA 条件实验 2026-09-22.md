## 实现级规则定义（repair_v2）

本实验所称“规则增强”不是固定的手工波形替换规则，而是“固定条件语义 + 学习型频谱增益头”。A/B/C 使用同一网络、同一训练样本、同一损失和预算，只改变输入给网络的条件通道；因此 A/B/C 是条件消融臂。

共同音频变换：输入始终是自然音频 N 的 16 kHz 单声道 PCM。先用 512 点 STFT、128 点 hop，将谱功率映射为 24 个频带的 log-power 特征。`MFAConditionedGainEnhancer` 输出每个频带/时间帧的增益，经过 `6 dB * tanh` 限幅；随后对 STFT 幅度施加增益、保留原相位并做 iSTFT。该网络为 64 通道卷积残差结构，dilation=`[1,2,4]`，不是规则表直接决定增益。

共同时间/PCM保护：不改变采样数、不做时域拉伸或重排。仅允许修改每个 speech phone 内部；phone 边缘各保护 10 ms，边界使用 5 ms taper；静音、utterance 边缘和保护区逐样本恢复为原 PCM。导出时还检查 residual energy ratio≤0.01、SNR≥20 dB、RMS变化≤1 dB、无新增饱和。这个合同保证自然采样时钟和停顿位置不被主动重排，但不等于所有候选都已通过独立 MFA 时序审计。

| 臂 | 条件输入 | 实际含义 |
|---|---|---|
| A / `AUDIO_FEATURES` | phone 身份与三路 timing 在模型输入中全部清零（底层 ids 填 SIL） | 仅使用音频自身的 24-band特征；没有 MFA 身份/时间条件 |
| B / `BOUNDARY_TIME` | phone ID全部置为 SIL；保留三路 timing | 使用 MFA 音素内归一化位置、标准化 log phone duration、speech indicator；不使用音素身份 |
| C / `MFA_PHONE_TIME` | phone ID embedding + 三路 timing | 同时使用 MFA 音素身份和 MFA 时间条件；这是本轮的主要 MFA 条件臂 |

每个 STFT 帧的 MFA 条件来自自然音频 N 的固定 MFA 对齐/转写：speech frame 编码为归一化 phone label，silence 使用 SIL；OOV 使用 UNK；SIL/UNK embedding 在模型中硬置零。C 在推理时仍读取 MFA 标签，因此是 text-assisted 的条件增强，不是只靠音频自动预测 phone 的系统。A/B/C 的训练目标是冻结 HuBERT layer 6 的 phone cosine-margin loss，加 keep-energy 和时频 total-variation 正则；它们不直接优化 Sync-C。

N 是自然原始音频，T 是原始 TTS 音频，D 是父实验锁定的 `OPT_DYNAMIC_6` 直接优化基线；D 不是 A/B/C 的条件消融。
