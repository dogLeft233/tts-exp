## 问题与设计

父 S/G 双因子在 Wav2Lip/SyncNet 的 WORLD 合成域中，固定F=T声学束的间隙时间平均分量 M_G raw/guard20 Sync-C +0.154，99%CI[+0.028,+0.299]；S/G的结论不转移至原生 N_WARP/T_ID，因为上游 RAW→WORLD 桥失败。本轮按该已审结果提出的探索性跟进，固定F=T，保留父S=N/T两背景，将旧G精确拆为E=句首句尾两段、U=其余内部G段。E包含发声半段，U也可含未匹配/停顿/未知和发声半段，二者均非纯静音。

8逻辑角S×E×U；4个E=U角只读引用父S/G实际特征/评分，4个E≠U角中76个eval空U alias也 exact 引用，真正新eval视频220个。主common71/15且全74保留，19个eval空U样本（主17）不删除，U对其为空操作。固定共同D和整句RMS，E/U取对应N/T来源各段时长，剩余预算按选定S来源相对时长分配；局部驻留和RMS配平仍可改变瞬时能量，不称纯声学不变的timing。

每对8self+24因素边有向跨模态=32逻辑矩阵/几何；raw/unit×guard20/valid/guard0/guard15、全条件边、E×U条件交互、8角cube分量/三阶余量、事件八钟共同q及全74附录保留。预先指定两项主raw/guard20 C：M_E与M_U，均跨S和另一因素四条边平均，各99% paired speaker bootstrap，20k PCG64 seed20260926；逐对M_E+M_U应exact等父M_G(F=T)。无四项全正门，不按native gap比例解释。
