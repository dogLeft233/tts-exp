## 问题与设计

已结项的R/U四格在共同T钟主raw/guard20发现C交互 +0.142，99%CI[+0.056,+0.216]；R是SyncNet表征逐行长度，不能叫物理电平。本跟进把R再拆成全局表征尺度G和局部范数轨迹P，并保留单位方向U，组成2×2×2八角。对V/A各自独立、每源metadata指向的**完整数组所有行**算行范数RMS作为G，包括评分joint_L后行；P=完整行范数/本源G，U=本源行单位方向。V与A行数可不同，N/T在同模态的完整shape一致。生成G/P/U混合表征后仅评分截到原共同T joint_L。

当G=P同源时四角复用旧R/U记录的全部曲线与端点 exact；G≠P四角才新算，全部74评估对保留、主common71/15。旧交互I_RU精确拆为按另因素两背景等权的J_GU+J_PU，同时报告M_G/M_P/M_U、三阶剩余及全部条件边/交互。raw/unit×guard20/valid/guard0/guard15；20,000 PCG64 seed20260926配对speaker bootstrap，95/99CI均为探索性描述，无新增主成功门。不从评分或某一mask选行求G，不新声学/视频/GPU。

另冻结同71支持mask补充：只取旧G=P原生两角H000/H111，在相同71对/15人上比较raw/unit四mask的C/B/D_anchor/Dmin gap及各mask相对guard20的逐对差和95/99CI。即使同支持存在政策差，valid的lag特异query支持与B/D重选仍可能共同影响结果；不直接叫边界效应。

## 结果与解释

主raw/guard20 Sync-C（说话人等权）旧四角交互 I_RU +0.142，99%CI[+0.056,+0.216]；全局尺度×方向平均二差 J_GU −0.005 [−0.018,+0.005]，局部范数谱×方向 J_PU +0.147 [+0.064,+0.219]，按预封代数 I_RU=J_GU+J_PU 逐对精确闭合。旧正向交互在此表征构造中主要落在 P×U；J_GU 区间跨0不等于真值0，也未直接检验 J_GU 与 J_PU 的差。M_G C −0.085 [−0.158,−0.017]、M_P +0.116 [−0.008,+0.262]、M_U +0.136 [−0.045,+0.333]，三阶余量/4 −0.003，99%CI[−0.0060,−0.0002]；母残差 H_TTT−H_NNN +0.164 [+0.003,+0.316]。M_G 的 B +0.031 区间跨0、Dmin +0.116 99%正，C=B−Dmin 因而为负。完整八角、B/D/anchor、条件边与八视图 CI 在 run 的 `analysis.json.gz`/`report.md`，无选择性删视图。

同71对原生角 raw C gap：guard20 +0.164，95%CI[+0.039,+0.280]、99%CI[+0.003,+0.316]；guard15 +0.194，[+0.039,+0.359]/[−0.006,+0.411]；valid +0.042，[−0.082,+0.177]/[−0.117,+0.219]；guard0 −0.001，[−0.122,+0.131]/[−0.156,+0.174]。guard0−guard20 −0.165 的99%CI[−0.304,−0.020]。guard0所有lag共用q而边缘可读零padding；valid逐lag支持变化且无padding；guard15/20各自共q、guard20是guard15子集，皆无padding。B/D整曲线也会重选lag，不能将差异称为纯边界或纯padding。guard15同支持点值为正且95%区间正，不能说中央正值只见guard20。

本诊断仅 SyncNet 表征的尺度/范数轨迹/方向反事实，不是物理音频电平或生成器、唇形的因果干预，不替代已经冻结的 WORLD 真实音频/视频 C/P/E 八角主实验。
