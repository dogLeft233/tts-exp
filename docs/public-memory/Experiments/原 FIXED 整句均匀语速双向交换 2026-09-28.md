# 原 FIXED 整句均匀语速双向交换 2026-09-28

在 [[原波形音素中心时钟双向迁移 2026-09-28]] 的非线性 phone map v3–v6 均未过 synthetic 时点门后，root 优先采用完整原 FIXED 波形的整句单一语速比例，检验原生 Wav2Lip/SyncNet 的 T−N 差异是否随**总时长**双向交换。共同总时长并不保证相同 phone-center 时钟或相同发音内容。本实验沿用历史74 eval、主71/15speaker，与旧机制探索共享队列；SyncNet 不等于人工嘴型真值。本笔记单列均匀分支，不能将技术门通过视作效果成立。

26cal 技术 pilot：`runs/tts_uniform_rate_cal26_feasibility_v3_20260928/`，系统 libRubberBand 3.3 C API offline R3，64sample块、pitchScale=1、无 keymap，ratio=目标总样本数/来源总样本数；26pair/13speaker、156主WAV和首pair六份重复。静态、五档 synthetic、首pair、全量26cal独立PASS，最终状态 `INDEPENDENT_TECHNICAL_FEASIBILITY_PASS`，见 `final.json`、`report.md`。全部输出长度精确、FLOAT/16kHz/mono；同源 ID 0/52 波形或官方 mel/chunk/MFCC exact，ROUNDTRIP 52/52非exact，故正式比较必须有同处理路径 ID 桥，RT仅描述。uniform v1静审失败未跑；v2虽synthetic PASS，但首pair第二WAV未留且重复hash失败，不追认；v3独立闭合。pilot 未用74eval、视频、GPU或SyncNet，无新效果分数。

root 已在 CPU lag 诊断结果前锁定正式生成与统计设计，并条件授权 producer：74eval的四joint与双roundtrip共444个新视频，加首cal 8视频；814个新评分矩阵加RAW参照。四joint为 `N_ID`、`T_uniform_toN`、`N_uniform_toT`、`T_ID`。主视图历史common71/15speaker raw/guard20，另报旧8视图；all74的valid/guard0视图保留全量并明确逐格缺失。配对 speaker bootstrap：每speaker先汇总句，speaker等权，PCG64 seed20260926、20000抽样。双向主门 `N_gain` 和 `T_loss` 各99%CI下界>0；两个共同总时长残差 `R_T/R_N` 各95%CI整体落±0.05才称残差小；RAW→ID gap差中差95%CI整体落±0.05及N/T各臂C损伤95%CI整体落±0.20作为原生桥。RT描述，不新增等效门。这些是预定精度与可解释边界，CPU lag-scale诊断不能改动阈值或支持集。

辅助 known-phone event：各joint用其 source 原phone center×该cell全句ratio找四个q，四q必须共同满足对应原目标钟 guard20、31lag与媒体窗口；评分前封存事件集、重复事件和缺失账本。固定自然RAW配 `T_uniform_toN` 的 G_RAW 单列，须披露内部phone时序不同；四joint G/E/I 仅是总时长一致下完整来源兼容性，不称纯声学。正式 74eval 生成、评分与独立全量数值审核已经完成；详细主结果及解释边界见下节。

## 正式74eval结果与独立复核

正式运行 `runs/tts_uniform_rate_holdout74_20260928/` 的主71/15speaker raw/guard20、20,000 PCG64 seed20260926 配对说话人 bootstrap：N_gain **+0.091**，99%CI[−0.129,+0.294]；T_loss **+0.239**，99%CI[+0.021,+0.487]。双向99%正门**未通过**，因为N侧区间跨0；只能说两方向证据强度不对称。不能写成N侧无作用，也不能由一侧显著、一侧不显著推出两响应彼此显著不同或TTS特异语速敏感。主R_T **+0.164**，99%CI[+0.003,+0.316]、95%CI[+0.039,+0.280]；R_N **+0.016**，99%CI[−0.251,+0.277]、95%CI[−0.187,+0.213]。两项95%CI均未全落预设±0.050，小残差门失败。这里R_T=C(T/ID)−C(N/WARP)、R_N=C(T/WARP)−C(N/ID)，每个差项都是同目标总时长下两个来源各自真实生成、自配joint分数；它们不是前次CPU lag的虚拟错配尺度、跨来源音视频配对或因果解释比例。

旧RAW→DSP-ID三桥均PASS：主C的gap差中差95%CI[−0.000416,+0.000138]全落±0.050；N_ID−RAW [−0.000053,+0.000474]与T_ID−RAW [+0.000003,+0.000136]全落±0.200。T_loss的B **+0.326**、99%CI[+0.131,+0.527]，D_anchor **+0.135**、99%CI[+0.015,+0.301]；因差值为ID−WARP，T减速后正确anchor距离实际下降，C变小主要伴随背景B收缩，不能称嘴型匹配必然变差。T_loss C_anchor +0.191 [−0.053,+0.464]仍跨0；N_gain C_anchor +0.018 [−0.216,+0.251]跨0，search_uplift +0.073 [+0.014,+0.147]为99%正。RT自身C差N−0.018、T−0.041均跨0，但B N−0.093、T−0.087的99%CI均为负，不能说往返DSP无影响。

八个原定raw/unit×guard20/valid/guard0/guard15视图及all74 valid/guard0附录、70对语义事件均保留；raw/guard0 N_gain均值−0.103、99%CI[−0.236,+0.022]，显示视图方向敏感。各joint事件各用自身封存q，70对raw事件C的N_gain−0.019[−0.288,+0.209]、T_loss+0.200[−0.045,+0.441]，均为99%CI跨0。按封存FIXED samples直接计算，74eval的T/N实际时长比min/median/max **0.537265/0.812170/0.986695**，74/74 T更短；主71为 **0.537265/0.813492/0.986695**，71/71 T更短。输入的`ratio_T_to_N`是反向操作倍率，不可当T/N时长比。

独立特征审与数值审均PASS：452元数据、904持久V/A、444评估新cell+8首cal；814新cell×2几何=1628新数值矩阵。reviewer从V/A重算1924矩阵、7696政策视图、888事件视图，曲线/端点最大绝对差1.91e−6；旧RAW端点33516字段及2160 bootstrap统计exact。正式`report.md` SHA `9d82d01de33fdea04e03903ef59eaf4aa247812a45274e41fa3282819bb7f47b`，`final.json` SHA `aca931a7e4a430a30f3ebf1baa83e2c943514db6efd0ebebc905a1d4c5e5fa32`，独立数值receipt SHA `390aa1da01a1d6cd4d5ead9ecd12c32b25a59f32722957815e1cb93ca4a5f44b`。此为共享历史探索性队列，不是独立确认、纯phone-clock操作或TFG因果中介比例。次要同源事件交叉诊断另有见分前science封存，不得据此结果改方案。
