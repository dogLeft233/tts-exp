# Wav2Lip 等时钟加噪的生成端与评价端四格实验结果 2026-09-20

本实验实现并完成了 `wav2lip_noise_cross_v1`。它在固定 Wav2Lip、固定静态人像和冻结 SyncNet V2 下，把“生成端是否使用了加噪音频”和“评价端是否使用了加噪音频”拆成四格比较。每个来源组包含自然音频 N、原始 TTS 音频 T；每条音频都有 RAW、A0（20 dB 有色噪声的同一增益基线）和 NOISE20 条件。主分析使用 24 个来源组，另有重复渲染和已知延迟控制。

## 实验状态

- [status] 工程实现完整；正式运行与 smoke 均通过独立 checker。
- [protocol] `wav2lip_noise_cross_v1`
- [formal_run] `runs/wav2lip_noise_cross_v1`
- [counts] 144 个主逻辑视频、4 个重复视频、240 个主评分单元、8 个延迟控制评分单元。
- [audit] PCM 条件绑定、音频解码载体、视频像素与 PTS、SyncNet embedding 矩阵、共同支持区间、时序统计和 bootstrap 均通过；`validation.json` 为 `PASS`，`independent=true`。

## 主要观测

- [result] 评价端效应 (E_T=q_{01}-q_{00}) 的 24 组均值为 **+0.000485**，97.5% bootstrap CI 为 **[-0.069764, +0.076740]**；13/24 组为正。预注册效应范围判定为 `WITHIN_PREDECLARED_SCORE_RANGE`，没有清晰的 TTS 特异评价端响应。
- [result] 生成端效应 (G_T=q_{10}-q_{00}) 的 24 组均值为 **-0.003398**，97.5% bootstrap CI 为 **[-0.061419, +0.049409]**；14/24 组为正。该结果同样跨 0，不能支持 TTS 特异生成端响应。
- [secondary] 自然音频的 (E_N=-0.012862)、(G_N=+0.037508)；T/N 交互项 (I_T=+0.040850)，均只作描述性结果，不能当作机制确认。
- [baseline] RAW 条件下 T-N 的 Sync-C 均值差为 **+0.111112**，19/24 组 T 高于 N，但 95% CI 为 **[-0.058394, +0.266044]**；在这个 Wav2Lip 协议中只能说有方向性迹象，不能称为确认性的原始 TTS 优势。
- [control] 24 个来源组的共同 headroom 均为 1.0，实际 SNR 约为 20 dB；支持区间样本数为 26–1917；重复渲染和已知延迟控制均通过。

## 科学解释边界

这次受控加噪实验没有发现“加噪响应”可以解释 TTS 的原生 TFG/Sync-C 增益：在同一静态人像、同一 Wav2Lip 和同一 SyncNet 下，TTS 的评价端和生成端主效应都接近 0，且置信区间跨 0。因此目前不能说 TTS 是因为更抗噪，或因为 SyncNet 对 TTS 的这类噪声变化更敏感，才得到更高分。

这只是一个窄的负结果。它不能证明 TTS 不改变时间轨迹、音素动态或其他声学组织，也不能证明嘴型真实准确性没有改善；可能是 20 dB 有色噪声没有触及 TTS 与自然音频的真正差异，也可能是固定静态人像/Wav2Lip 组合对该干预不敏感。后续仍应优先做 provenance 完整的“分别生成视频、再统一换回自然音频”的生成端交叉实验。
