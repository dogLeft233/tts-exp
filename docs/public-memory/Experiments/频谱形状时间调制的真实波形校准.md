# 频谱形状时间调制的真实波形校准

仅在旧 26cal 的 N/cloud T 共 52 条 16k PCM 上，对频谱形状随时间变化幅度进行工程与声学校准。此项工作不运行 TFG、SyncNet、ASR，不读取 eval48/新80 的波形或新干预评分，不以同步评分挑参数。

| Notes | Modification Date | Approved By |
|:--|:--|:--|
| 冻结 CPU 校准协议；固定 alpha 0.8/1/1.2、±6 dB 增益、512/128 Hann STFT | September 26, 2026 | user/root |
| v1校准完成；独立复算208波形，保留包络/长期谱/F0耦合 | September 26, 2026 | user/root |

## Observations
- [status] concluded
- [result] v1 calibration_passed；52/52臂目标有序，R RMS中位−11.718%/+9.001%；26个共同headroom gain均1。float64 identity最大2.78e−16，保存后RMS相对误差≤9.53e−10。
- [validation] 4项契约测试通过；SciPy独立复算208条波形，保存float32与独立float64最大差1.83e−8；R RMS最大差1.78e−15dB。
- [coupling] .8/1.2包络dB RMSE中位1.332/1.323，线性NRMSE11.74%/10.96%；长期谱dB RMSE1.520/1.720；PyWORLD有声判断变化5.60%/6.14%。
- [result] 旧26cal原T−N的R RMS配对均值+0.110dB、中位+0.022dB，仅描述；未查看eval48/新80波形或新干预分数。
- [conclusion] 固定谱形时间残差操作有效，但不能隔离包络/长期谱或证明TTS同步优势声学原因。root要求后续独立v2校准匹配能量包络控制，v1不变。
- [protocol] alpha固定.8/1/1.2，±6dB，512/128 periodic Hann；每个N/T样本八波形共用headroom。
- [report] runs/tts_acoustic_modulation_calibration_20260926/report.md；protocol.json与artifact_hashes.json封存参数、52来源和全部产物。
- [entrypoint] scripts/experiments/tts_acoustic_modulation_calibration.py:transform_pair；尚未运行G×E或评分。
