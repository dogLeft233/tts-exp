# Ditto TTS 局部时间辨识与共同语速控制结果

## Observations

- [status] 实验、smoke、全量独立复算均完成；工程状态 PASS，独立 checker PASS。
- [data] 父 Ditto-50 来源合格 cohort 共 47 对；六种 arm×mode 逻辑 cell 共 282 个，全部完成。
- [support] 40 对进入主集合 J；ID 3、5、8、11、22、33、40 因共同 phase 的完整窗口支持不足排除。没有按 Sync-C、lag 或局部排名筛样。
- [controls] smoke 中 6 个原生 cell 的官方 SyncNet 距离矩阵最大绝对误差为 1.0490417e-05；独立重复的视觉/音频 embedding 最大误差均为 0；延迟方向、identity、速度音频控制、正仿射 rank 不变性和支持区间不交叠均通过。
- [native_c] 同一 J 上原生 C_interior 的 TTS−自然均值为 +1.4455，95% bootstrap CI [1.1648, 1.7094]，37/40 对为正，原生 C 增益 CONFIRMED。
- [H_native] 交叉 lag 校准后的局部错配辨识差 H_native 均值为 +0.06013；Bonferroni 98.75% bootstrap CI [0.02572, 0.09507]；31/40 对为正，H_native POSITIVE。
- [H_rate] 共同短/长时长控制后的 H_rate 均值为 +0.01978；Bonferroni 98.75% bootstrap CI [-0.00960, 0.05244]；22/40 对为正，18/40 对为负，H_rate INCONCLUSIVE。SHORT 均值 +0.02653、LONG 均值 +0.01303，两个方向的 95% CI 都跨 0。
- [conclusion] 在这批单说话人 Ditto 历史配对上，整体音视频偏移不足以解释原生的局部时间辨识差异；但共同整句播放时长控制后的局部优势没有得到确认。因此当前机制状态是 RATE_TEST_INCONCLUSIVE，而不是“语速已经解释了增益”或“局部优势已被证明保留”。
- [boundary] 结果只反映冻结 SyncNet 的响应，不能证明嘴型更准确、不能证明评价器偏置、不能定位音素时长/停顿/韵律或变速算法伪影中的具体因果因素；共同总时长也不是逐音素对齐。
