# MFA-linear 音素时序渐进修复 2026-09-13

固定上一轮的3条LRS3记录与3号静态正脸图。历史MFA-linear候选与自然音频长度完全一致。本实验不再使用词级回退：先在精确匹配的词内，以固定IPA宽类进行单调音素序列比对，再将候选MFA-linear音频的音素边界按0/25/50/75/100%逐步移向自然边界。

三条候选/自然音素覆盖率为0.904/0.917、0.850/0.876、0.804/0.837，均超过预先设定的0.70门槛；不足匹配不会伪造为音素对。每一强度用同一物理时间坐标场分别作用于可播放波形和Wav2Lip直接mel。波形候选同时在真实自然视频与静态Wav2Lip生成视频上评估；mel仅作为静态生成机制对照。所有评分使用同一冻结图片、人脸框、主支持与lag±15。

## 方法与结果

|条件|P025|P050|P075|P100|
|---|---:|---:|---:|---:|
|静态生成，波形臂 ΔSync-C|−0.219|−0.412|−0.711|−0.711|
|静态生成，直接mel ΔSync-C|−0.437|−0.859|−1.269|−1.401|
|真实自然视频，波形候选 ΔSync-C|−0.405|−0.832|−1.329|−1.425|

所有上述比较均为相对原MFA-linear时钟P000的平均值，且3/3样本均未转正。P025下静态波形臂的曲线中位数仅变化+0.013，但最佳位置距离D恶化0.232，因此C下降0.219；更高强度下D与曲线中位数都变差。真实视频波形臂P025/P050/P075/P100的D改善分别为−0.348/−0.590/−1.031/−1.123。

## 结论与边界

真正落实音素级、渐进式的自然时钟修复后，未出现“同时保持自然视频匹配且保留静态生成增益”的中间强度。至少在这3条、单图、历史seen-fit MFA-linear条件下，MFA-linear的可用输入结构依赖于被修复的局部时间关系；普通波形时域重采样也不是唯一解释，因为同一映射在直接mel路径上下降更大。

这仍是n=3机制筛查。宽类IPA配对不是人工语音学标注；未做主观听感、输出ASR/PER或跨图/跨样本泛化，不能据此授权训练或泛化声称。
