# LRS3 音素优势与自然音频规则增强实现审计 2026-09-20

## Observations
- [status] concluded
- [progress] LRS3 原始 TTS 的音素可分性优势得到支持，但当前纯规则 natural 增强未达到预注册改善门槛。
- [implementation] 完成并修复了 runner、metrics、audio、worker、独立 checker、固定 YAML 配置和测试；本轮没有改动旧 TTS/TFG/SyncNet 流水线。
- [resource_check] 运行前确认本地 `[redacted-ip]:7890` 代理可访问 Hugging Face；GPU 为 Tesla V100，约 5 MiB 占用且无竞争 compute app；可用内存约 21 GiB；full run 启动时磁盘约 20 GiB 可用，运行期间未抢占或终止其他任务。
- [assets] 通过代理下载并固定本地模型：HuBERT `facebook/hubert-base-ls960@dba3bb02fda4248b6e082697eee756de8fe8aa8a`（layer 6）和 XLSR `facebook/wav2vec2-large-xlsr-53@c3f9d884181a224a6ac87bf8885c84d1cff3384f`（layer 10）；worker 仍使用 `local_files_only=True`。
- [audit] 固定 cohort 审计通过：240 对，200 train / 40 evaluation，evaluation 为 40 个 source groups，train/evaluation source_group 互斥；自然/TTS 音频与 480 个 TextGrid 的来源绑定和哈希通过。
- [stage_a] Stage A 为 `ADVANTAGE_SUPPORTED`。HuBERT：natural=0.70905，TTS=0.79022，TTS−natural=+0.08117，95% source-group paired bootstrap CI=[+0.05019,+0.11355]。XLSR：natural=0.62916，TTS=0.70270，差值=+0.07354，CI=[+0.03977,+0.11168]；两模型均为 40/40 eligible pairs。
- [stage_b] 规则增强共 5 arms（spectral_drc、spectral_only、drc_only、gain_control、identity），生成 200 个 WAV 并完成两套 encoder 重提取。HuBERT 的 spectral_drc 均值=0.70901，`D_E`=−0.00003，CI=[−0.00432,+0.00434]；XLSR 均值=0.63036，`D_E`=+0.00120，CI=[−0.00562,+0.00812]。两者都未达到 +0.010 且 CI 跨 0；identity 与 natural 完全一致。
- [timing] 两侧 MFA（natural/enhanced，各 40 条）均执行；median boundary error=0 ms、p95=10 ms，但最大 speech edit rate=0.05882>0.05，timing gate 为 `TIMING_NOT_ESTABLISHED`。
- [decision] Stage B 终态为 `NO_IMPROVEMENT`，reason_codes=`ENHANCEMENT_EFFECT_BELOW_THRESHOLD`、`ENHANCEMENT_CI_CROSSES_ZERO`、`GAIN_ONLY_NOT_EXCLUDED`、`TIMING_NOT_ESTABLISHED`；不能据此宣称规则增强保留 TTS 音素优势。
- [engineering] 独立 checker 通过：Stage A 统计可复算，200/200 规则 WAV 的 waveform/非编辑区 PCM 契约通过。初次 smoke 暴露的 undefined accuracy `NaN` 与 checker 空统计 `NaN` 已分别改为 JSON `null`，并补回归测试。
- [validation] 新增测试 23 passed；既有相关回归 73 passed（6 个已有 sklearn warning）；Ruff 与 py_compile 通过。smoke 仅作为工程验证，标记为 `SMOKE_NO_SCIENTIFIC_DECISION`。
- [artifacts] full run：`runs/lrs3_phone_rules_full_20260921_proxy/`；报告：`07_report/report.md`；独立 checker：`07_report/checker.json`。
- [interpretation] 这里的“音素可分性”是冻结 HuBERT/XLSR 层、MFA 标签和共享最近中心 probe 下的操作性指标，不等同于人耳可懂度、ASR 或 Sync-C；本轮没有做 TFG/SyncNet 下游验证。
- [next] 后续若继续，应优先设计保留 natural 时钟的更直接 phone-local/contextual 干预，并先修复 timing gate，再与当前规则 negative result 分开立项。
