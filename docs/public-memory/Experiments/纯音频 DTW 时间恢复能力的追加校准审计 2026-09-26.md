# 纯音频 DTW 时间恢复能力的追加校准审计

## Observations
- [status] concluded
- [amendment] 看到原a1_001控制中>=160ms仅2个phone后追加，非原预注册控制；没有更改主实验或据结果选新算法。
- [cohort] 固定原26cal的N与Q1，共52臂全部纳入；26个Q1均记录EOS，无来源/缺失/停止排除。各总体/长phone子集均含26clip，无零支持clip排除。未读取eval音频，无TFG/GPU/新生成实验。
- [algorithm] 原80维Wav2Lip mel、全音频逐带CMVN、同phone端点DTW/平局规则/双向路径均值映射完全不变。原identity和前半映至前75%、后半映至后25%的waveform线性变形、25/50/75%相位双方向、时间/40ms索引误差定义不变。原a1_001/Q1 decoded PCM、路径及逐query数值完整重放一致。
- [statistics] clip内phone/phase/方向等权，再clip等权，20000 PCG64 seed20260926 clip bootstrap99CI；DTW−MFA负值改善。clip CI不另行校正同speaker相关，不当speaker独立推断。时间分位数使用clip等权经验CDF；双向及索引MAE完整保存。
- [result-N-all] N全部原控制>=80ms：26clip/621phone/3726相位方向；MFA→DTW时间MAE22.140→19.917ms，变化−2.223ms，99%CI[−2.866,−1.576]。精确40ms索引命中率45.87%→51.51%。
- [result-Q1-all] Q1全部原控制>=80ms：26clip/548phone/3288相位方向；MAE20.297→18.814ms，变化−1.484ms，99%CI[−2.076,−0.803]。索引命中率48.54%→52.25%。
- [result-N-long] N >=160ms：26clip/141phone/846相位方向；MAE35.563→30.269ms，变化−5.294ms，99%CI[−7.642,−3.140]。索引命中率21.55%→32.78%。
- [result-Q1-long] Q1 >=160ms：26clip/74phone/444相位方向；MAE34.558→29.743ms，变化−4.815ms，99%CI[−7.673,−2.011]。索引命中率22.10%→29.07%。
- [identity] 全52臂identity误差为零。长phone的量增加至N141/Q174，修正了原单clip仅2phone的不足。
- [conclusion] 四个总体/长phone臂均确认已知时间变形下的平均误差改善，原单条长phone变差不能代表整个校准集。支持此固定DTW有有限、可复现的恢复能力；长phone残余MAE约30ms、精确40ms索引命中仅约29–33%，仍不等于已准确恢复真实语音时序，也不能把主实例实验残余直接归为非时序效应。
- [boundary] waveform线性变形改变局部频谱，不是音色保持合成；该校准结果衡量这一操纵下的恢复能力，不改变主实验数字、证明声学真值或native因果贡献。
- [verification] 7014个相位方向的已知真值/路径映射/时间和索引误差独立复算，clip权重/计数/20000次bootstrap99CI/加权分位数复核，最大误差8.95e−13，PASS。2项必要测试通过。FLOAT WAV PEAK头含创建时间，字节hash不同而decoded float32 PCM精确相同；重放检查因此使用PCM而非容器字节，未修改波形。
