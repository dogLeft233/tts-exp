# TTS 原生增益音轨审计与时间表交叉实验 2026-09-26

用户授权执行发音时间表双向交换与生成端/评价端交叉，并在说服力不足时自主推进后续实验；GPU 使用前检查占用。

## 冻结顺序

1. 先对现有 Ditto-50 的全部 47 个合格配对做固定视频的评分音轨审计：复算旧曲线、用原 WAV 统一 16 kHz PCM16 后直接抽取音频特征；使用一致有效窗口支持比较原生 TTS 优势是否保留。音视频偏移和首帧时间须核验，保留 FULL 与去边界 INTERIOR，不能将改变支持造成的差异归因于编码。
2. 若优势因音轨链消失，优先做固定视频的受控编码干预与其他模型/数据复核，定位可复现的评价端原因；不在失去阳性参照的条件下继续解释时间机制。
3. 若优势保留，构造 NN/NT/TN/TT 双向时间表交换、恒等重建和原音控制。在可用模型上先确认原生参照，完成同时间表内驱动来源×评价来源四格。只把通过操纵与质量检查的干预用于机制解释。
4. 自主选择后续诊断属于探索；所有后续假说在查看对应新结果前写入独立协议。固定分母、配对区间、处理伪影与失败记录都保留；不把持续试验到显著当作证据。

## Observations
- [status] concluded；前置音轨审计触发冻结的编码因果分支，本轮未执行新的音素时间表交换或 TFG 生成。
- [result] 固定视频、FULL 共同窗口支持下，TTS−自然 ΔSync-C 从历史音轨 +1.131 [95% CI +0.938, +1.325] 降至统一源 PCM 的 +0.054 [-0.183, +0.290]；INTERIOR 仍有 +0.335 [+0.009, +0.646]，不能宣称完全没有剩余效应。
- [mechanism] 当前 FFmpeg 8.0.1 的历史 AVI 预处理未指定音频 codec/码率：16k 单声道默认 MP3 24 kbps，24k 默认 MP3 32 kbps。解码到统一 16k 不能撤销先前压缩和延迟。
- [result] 去除波形估计的编码延迟后，同一声音的默认24k路径−16k路径：自然 +0.900 [+0.756, +1.043]，TTS +0.825 [+0.662, +0.982]；固定64 kbps 后分别为 −0.003、+0.001。
- [result] 固定视频、对齐延迟且统一窗口，分配自然16k/TTS24k 得到 TTS−自然 +1.308 [+0.989, +1.616]，交换路径得到 −0.418 [−0.787, −0.073]；两者均源PCM16 得到 +0.287 [−0.090, +0.648]。交换的均值反向不等于多数样本反向。
- [replication] 12 个 LRS3 真实视频，没有 TTS 或生成视频，全部同方向响应默认编码路径，平均 +0.896 [+0.610, +1.230]；固定64 kbps 后 +0.012 [−0.021, +0.048]。
- [validation] 独立 checker 复算1812个评分、核对2318个输入哈希、重算主要编码效应 bootstrap，PASS；最大评分误差0；5个专项测试通过，新源码Ruff通过。
- [resource] 初始 V100 8 MiB、0%；后续三次 GPU 预检遇到其他计算进程/占用，未干扰其任务。本轮所有新增模型前向使用CPU，复用经哈希核验的缓存视觉特征。
- [constraint] Ditto 为单说话人47对；探索性因果干预，未收集人工盲评。阶段窗口支持不同，不能跨表直接计算机制占比。不能推广为所有 TTS/TFG 均无真实增益。
- [constraint] 历史 Wav2Lip 已有相关采样率混杂先例；本轮是当前 Ditto 阳性队列上的直接复现、干预与真实视频复核。
- [artifact] 完整方法、区间、限制与产物：[实验报告]([redacted-local-path])；图 summary.png/pdf；协议及原始距离矩阵均在同一 run 目录。
- [decision] 在统一无损音轨协议下重新确认阳性参照之前，不再用这批原生高分优先支持“TTS发音动态更优”机制。保留历史协议分数，但注明编码混杂。
