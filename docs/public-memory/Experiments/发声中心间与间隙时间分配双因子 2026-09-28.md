## 问题与设计

已独立结项的 WORLD C/P/E 八角在共同 T 总长/全局 RMS 下显示局部时钟平均边 M_C 的 raw/guard20 Sync-C +0.135、99%CI[+0.015,+0.264]；母 RAW→WORLD 两臂及 gap 桥失败，不能转译成原生残差完整解释。本轮 outcome-informed 探索性跟进将旧 C 时钟在固定声学整包 F=N/T 下拆成 S/G 两因素各N/T，共2×2×2八角。相同旧74 eval、主71/15；四旧 controls 引用母 WORLD 格并 exact 桥，四新混合时钟格需生成真实音视频，不删样/拟合。

S 是两来源均只覆盖相邻匹配已知音素的中心到中心区间的**相对时间分配**；其中仍可能有边界和半音素，不能称纯音素内部时长。G 是其余所有区间，包括未匹配、停顿、未知及句首句尾；不是纯静音。取G来源原区间绝对时长后，把共同剩余时间按S来源相对时长分配，整句端点D固定。若S集合为空则S为空操作，仍保留身份。F固定同源完整 SP+F0/AP；同源S=G=F身份沿母原采样路径 exact，四新格按冻结 WORLD 插值/合成及固定RMS。

每声学背景4自配+4因素边×2方向交叉=12矩阵，两背景24/pair，raw/unit×guard20/valid/guard0/guard15及输入预封语义事件。主71/15四个预设 raw/guard20 C 分量 M_S(F=N)、M_G(F=N)、M_S(F=T)、M_G(F=T)各99%配对speaker bootstrap（20k PCG64 seed20260926）；M_S+M_G=该F背景旧 full-clock 差逐对精确闭合，保留条件边、I、G/E/I评价路径、B/D/anchor/all74和背景平均/差。区间覆盖和历史队列局限须显式说明；不按比例声称旧 native gap 解释。

## 模型和操纵边界

实际生成器沿母实验固定 image3/Wav2Lip GAN checkpoint（母技术 SHA ca9ab7b7b812c0e80a6e70a5977c545a1e8a365a6c49d5e533023c034d7ac3d8），评分用 SyncNet V2 权重 SHA 961e8696f888fce4f3f3a6c3d5b3267cf5b343100b238e79b2659bff2c605442。本轮机制结论只属于这组生成/评价系统，不能直接外推全部 TFG 模型或原 Ditto 总结。局部时钟操纵固定 SP/F0/AP 来源但改变其驻留时间，合成后还要将整句 RMS 配平，瞬时能量分布和 active 电平可能随之变化；只称固定全局 RMS 与总长下的时序操作，不称纯 timing 且瞬时声学量不变。
