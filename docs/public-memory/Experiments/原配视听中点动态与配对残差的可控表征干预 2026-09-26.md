# 原配视听中点动态与配对残差的可控表征干预

## Observations

- [status] concluded
- [question] 在保留原配anchor差向量时，单独改变视听中点轨迹的动态幅度，能否改变原配TTS−N的Sync-C优势？保持native主端点，不进行跨实例交换或新TFG。
- [cohort] sourcePCM、官方联合长度、固定缓存前端。动态云74中旧26cal全部可用，主eval为其余48/13speaker；全74探索桥接。静态云原74eval中71/15speaker满足N/C guard20；静态本地72/15满足N/Q1/Q2。无ASR/MFA内容门。静态本地cal有a1_025/Q2联合L38不足guard20，cal pooled用其余有效cell并列臂计数。
- [calibration] 各组只用旧26cal可用cell的raw guard20最佳lag pooled整数中位数，半整数向0取整。臂中位数差≤1且|k0|≤5为解释门。unit几何沿用相同冻结k0，不以eval选择。
- [definition] A'_t=A_(t+k0)，M=(A'+V)/2，R=(A'−V)/2。I=20..L−21；muM、sigmaM=sqrt(mean_I||M−muM||²)、rhoR=sqrt(mean_I||R||²)。M'=muM+alpha(M−muM)，R'=betaR；V'=M'−R'、Anew_(t+k0)=M'+R'。
- [support] M/R坐标域J要求0≤t<L且0≤t+k0<L。guard20查询i与原±15lag访问的i、i+s−k0全在J（|k0|≤5）；因此无需额外删query/插值/补零。所有访问坐标都变换，再恢复原audio索引。
- [intervention] 对每条T/N取alpha=sigmaN/sigmaT、beta=rhoN/rhoT；T向N四格与N向T倒数四格，Q1/Q2分别做后条内平均。主M-only处理效应与处理后T−N残余；R-only/both对照。另每臂固定alpha=.75/1/1.25、beta1剂量。
- [sensitivity] raw主；先将原embedding逐行L2归一化，再重新定义M/R/系数的unit几何敏感性。变换后不再次归一化。
- [statistics] 每speaker等权，20k PCG64 seed20260926 bootstrap99CI；报告C/B/D、固定k0距离、bestlag变化、系数和操纵效果。残余CI跨0不叫全解释，无百分比。
- [controls] identity、alpha/beta逆变换、M加预定时间常量全距离不变、M-only每个anchor差向量不变；独立直接重建与包含eps1e−6的平方距离二次式验证。
- [limits] M不是共享生理信号，R不是真实口型误差。这是每对语音的表示幅度归一化与计分干预，不是可部署训练或真实嘴型改善。
- [calibration-result] 动态共同k0=1，N/T臂中位数均1，各26cal；静态云k0=3，N/C均3各26cal；静态本地k0=3，N/Q1/Q2均3，cal计数26/26/25。所有解释gate通过；181有效calcells独立重算最佳lag一致、曲线误差≤7.153e−7。
- [baseline] raw guard20主分母：动态48/13speaker，N C=7.302、T C=8.243、ΔC=+0.941 [0.525,1.359]；静态云71/15，ΔC=+0.438 [0.228,0.625]；静态本地72/15，ΔC=+0.233 [0.013,0.439]。全部99CI，cal/eval ID分离但speaker不独立。
- [result] 动态主raw M-only：T→N处理效应-0.467 [-0.786,-0.114]，处理后T−N残余+0.475 [0.169,0.744]；N→T处理N的效应+0.563 [0.215,0.874]，残余+0.379 [0.040,0.649]。固定k0 anchor配对差保持不变，双方向均明确缩小原配分差，但正残余仍在。
- [unit-result] 动态unit原生ΔC=+0.066 [0.025,0.103]；T→N M-only效应-0.0187 [-0.0341,-0.0029]、残余+0.0476 [0.0165,0.0752]；N→T效应+0.0198 [0.0033,0.0363]、残余+0.0465 [0.0153,0.0742]。方向一致，不跨量纲算比例。
- [static-result] 静态云raw M-only T→N效应-0.153 [-0.464,0.196]、N→T效应+0.227 [-0.085,0.500]；静态本地分别-0.130 [-0.293,0.032]与+0.142 [-0.021,0.307]。静态M-only尚未确认，不能以处理后残余CI跨0宣称全解释。
- [distance] 动态T→N M-only：ΔB=-0.536 [-0.876,-0.139]，ΔDmin=-0.070 [-0.131,-0.006]，ΔD固定anchor=-1.59e−9；N→T对应ΔB=+0.544 [0.165,0.875]，ΔDmin=-0.018 [-0.063,0.004]，ΔDanchor=-4.57e−9。最佳lag可迁移，因此minD不受anchor不变性约束。
- [controls-result] 动态raw R-only两方向处理效应-0.051/+0.056均99CI跨0；both后T−N残余仍+0.405/+0.329且99CI为正。unit的R-only有更明确变化，几何会改变分量读数，不作生理分解。
- [dose-result] 动态raw固定alpha=.75时N/T的C变化-2.554 [-2.731,-2.370]/-2.638 [-2.813,-2.395]；alpha1.25时+3.037 [2.848,3.210]/+3.208 [3.018,3.354]。保持anchor差，表明该计分函数对中点动态幅度敏感；不单凭剂量响应解释原始T−N。
- [coefficient] 动态raw T→N alpha speaker均值0.958、配对中位数0.953 [IQR0.929,0.988]；beta均值1.012、中位数1.022 [0.949,1.060]。各条全部保留，无阈值/得分筛选。
- [verification] 578个pair×geometry、17,104,188直接距离及等量独立平方公式距离全部PASS；直接/平方式最大误差5.722e−6/5.300e−6；原生矩阵重放0，score复算0，尺度和统计误差5.329e−15。M-only anchor差向量float64误差2.220e−16、float32舍入1.788e−7；逆变换6.134e−15，M加常量距离误差3.815e−6。4项测试通过，2987源hash复核，1175产物/源码hash封存。
- [conclusion] 本轮确认了动态原配分差对视听中点轨迹幅度的可控敏感性，保留明确残余。未识别其来自声学、生成或SyncNet表征哪条路径；M不是共享生理信号、R不是真实嘴型误差。是否需要新speaker/生成确认交理论端，不自动追加新批。
