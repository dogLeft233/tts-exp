# 生成器音频窗口时钟与 TTS 视频迁移 2026-09-26

## 问题与冻结设计

用户要求继续，仍不依赖人眼。上一轮原生T视频按音素边界迁移仍−0.573；本轮检验音频锚点和生成视频时钟不一致是否造成残差。Wav2Lip inference.py每帧取从floor(80t)开始的16个mel列，hop=200/16000秒，约200ms窗口。窗口存在前视不意味着真正口部事件必在中心；以下是可证伪假说，不把架构窗口直接当作真值。

固定上一轮phone_transfer的38条评估样本、13说话人，不新增/筛选样本。设音频MFA音素边界映射为phi(N时间)=T时间。旧方法video_source=phi(t)。主干预固定L=100ms：video_source=phi(t+L)−L；另固定80ms敏感性和−100ms反方向对照，不按本批SyncNet结果选参数。所有条件保持相同输出帧数，原始T官方crop只做一次像素插值、FFV1，评价统一原始自然PCM；N identity和旧边界warp重评分作重放检查。主终点guard20下+100ms−旧边界，以及+100ms−N；报告C/B/D、固定N最佳偏移距离和方向对照。统计说话人等权、20,000 bootstrap seed20260926，95/99%；guard0/15敏感性。

预先检查identity phi在内部窗口对任何L仍是identity；线性phi的补偿仅为常数平移。端部clamp通过guard20控制，保存逐帧映射及sha。不训练模型、不搜索测试最优warp。仍是历史队列探索，同一源脸；不宣称独立确认或人类感知改善。若有效，优先验证固定时间补偿跨样本泛化和共有裁剪；若无效，不解释为所有窗口/时间机制不存在。

## 独立校准时钟补充（评分前登记）

读取上一轮固定26条校准集的原生PCM对角评分，N/T均为22条offset=−1、4条offset=0，中位数均−1帧。额外加入完全由校准集确定的L_N=L_T=40ms条件：phi(t+L_N)−L_T。此时尚未计算本轮迁移评分；100ms架构假说仍为原主比较，40ms是预先登记的校准派生次要比较，不对38条评估样本拟合参数。SyncNet原生offset是估计时钟的代理，不证明真正视觉事件时刻。

## 结果

38条/13说话人，guard20，说话人等权95%区间：

| 条件 | 相对旧音素边界ΔC | 相对自然视频ΔC |
|:--|:--|:--|
| 固定100ms | −0.235 [−0.429,−0.035] | −0.809 [−1.080,−0.582] |
| 固定80ms | −0.094 [−0.259,+0.112] | −0.667 [−0.896,−0.467] |
| 校准40ms | +0.042 [−0.045,+0.135] | −0.532 [−0.740,−0.324] |

反方向−100ms相对旧方法−0.749 [−0.983,−0.517]。正向100ms优于反向+0.514，但仍不如零补偿，方向对照不能冒充迁移成功。40ms相对N的ΔD=+0.504 [0.340,0.679]、固定N偏移距离+0.642 [0.464,0.822]、ΔB=−0.028 [−0.197,0.144]。迁移残差伴随匹配距离变差，不只是一条背景分布变化。

验证PASS：346次hash、684组分数、35,340个抽样距离、108个bootstrap汇总；分数/统计误差0，距离最大3.815e−6，映射独立算术8.882e−16。N与旧边界重放一致；校准/评估ID无交集。

固定前视时钟错配未被支持为可救回残差的主机制，不排除更复杂时序或生成前干预。后续转向3张静态源图的原生T mel生成前/后时间映射，保持无人工评分。
