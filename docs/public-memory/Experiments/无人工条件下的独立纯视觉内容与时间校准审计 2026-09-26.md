# 无人工条件下的独立纯视觉内容与时间校准审计 2026-09-26

用户要求继续探索，暂时不依赖人眼。恢复现成CMLR纯视觉VSR，读取嘴部视频，不输入音频。新建自动测量协议，不把旧要求人工盲评的实验冒充已完成。

## 冻结设计

1. 复用无损审计来源完整的74对、13说话人N/T/M视频与15条D子集；输入与转写严格hash绑定。文本使用已验证MFA清洗文本；OOV在读模型输出前记录，不替换成unk。先按可用文本/来源冻结名单。
2. 每说话人按样本ID取前2条作校准，其余作评估；不根据分数重分。所有模型权重冻结，沿用CMLR_V_WER8.0与官方嘴部处理。视频去音轨后验证帧/PTS相同，音频不进入VSR。
3. 每臂native/frozen/reversed三种视图；N/T另有共同长度matched/matched_frozen。目标文字与5条按字数差及ID确定的错误文本比较，计算字符归一化CTC NLL、margin M、动态增量Q=M(native)−M(frozen)、CER。保存完整logp及嘴部tensor。
4. 主校准仅看校准集N：目标严格top1比例≥0.60，Q>0比例≥0.70；native−frozen与native−reversed的说话人bootstrap95%CI下界>0。门未过不调阈值、不挑例，主效应仍报告为描述性不可判读。校准只验证内容端点，不自动成为毫秒同步或感知真值。
5. 主效应是评估集M−N的Q与原始margin；次要T−N及matched、D子集；按说话人bootstrap，报告95%/99%区间。原生T更好与同自然时钟M更好分开；不因VSR阳性改称自然音频同步已经改善。
6. 若内容测量有效，再决定时间定位/已知扰动等不依赖人眼的后续；新增分支先冻结再看结果。GPU开始前检查外部占用；复核独立CTC DP、媒体hash与统计，最终保存报告和BM。

## 已知时间干预的独立校准（在内容结果揭示前冻结）

实际文本词表审计得到68条可用、6条OOV，固定26条校准/42条评估。追加纯视觉CTC字符位置的forward-backward占用中心：26条校准N视频分别在开头补8帧（已知整体+320ms，原帧不丢失），以及保持总帧数的±240ms正弦局部时间变形。局部期望变化由已知映射的逆映射作用于原始视觉字符中心得到，不使用音频拟合参数；冻结帧在这种局部变形下不变，零响应作为负基线。

校准门：整体延迟的中位响应比在[0.75,1.25]；两种局部变形各自误差/零响应误差的跨片中位数≤0.5，且至少80%片段优于零响应。另须主内容校准通过。随后只在固定评估集上比较视觉字符中心与自然MFA字符中心的局部误差（扣除每句全局中位lag）；词序不完全匹配的条目记录缺失，不看结果选样。已知扰动响应通过也不能自动证明绝对嘴部事件时刻正确；校准失败则不解读细时间效应。协议在 runs/tts_independent_visual_20260926/timing/protocol.json。

## 原生TTS视频直接迁移分支（结果前冻结）

为区分“原生TTS视频无可用成分”和“MFA-linear特征映射/声码器丢失成分”，追加原生T视频直接重定时，无新音频重合成：N视频identity；T视频均匀变速到自然总时长；T视频按来源哈希绑定的实际N/T音频MFA词中心进行分段线性重定时。所有条件均用相同原始自然PCM评分，25fps线性像素插值、FFV1；主比较为原先42条评估集，另报全68条。错序/缺失MFA在结果前登记。该候选干预不需要VSR时间门，但不宣称音频词中心就是真实视觉时刻。

若独立VSR内容及时间校准都通过，才增加原生T视频按N/T视觉字符中心重定时条件；门不通过则不执行这一条件。全过程无SyncNet参数搜索。保留N/T各自历史官方脸裁剪（同一源脸）；裁剪差异、全脸运动变速和插值是边界，优先看T内部MFA与uniform对比，并报告相对N的实际替换结果。协议见raw_transfer/protocol.json。

## 主结果后的诊断分支

原生T内容优势为正、N时间校准通过，而原生T视频迁移仍失败后，追加两项明确标为事后的诊断，不改变原主门和分组：①固定26条校准T/M视频，重复同样的已知延迟和±240ms局部变形，检查N上的测量校准是否能外推到候选臂；②固定42条评估N视频，用已生成MFA/视觉映射先逆变形到T网格、再正变形回N网格，测量双次插值往返的Sync-C损失。后者只是处理损伤诊断，不把它当成与T单次重定时完全相等的反事实对照，也不机械地从主效应扣除来声称解释百分比。两项在各自新输出计算前登记。

## 音素粒度迁移敏感性（事后，输出前登记）

往返插值损伤很小，而原生T字中心MFA迁移仍为负，追加固定评估集的更细对齐。来源MFA phones序列事先审计：68条中61条完全一致；评估42条中38条一致，排除a1_036/a1_041/a1_075/a1_076，非按分数选样。分别采用匹配音素中心、音素起止边界重定时原始T视频，再配同一自然PCM；对比同38条N基线与原字中心MFA版本。边界映射对重复自然时刻的T锚点取均值，保持非递减，固定起止端点，不搜索SyncNet最优参数。这个事后敏感性不替换42条主结果，用于检查字级粒度是否遗漏收益。

## 实验结果与判读

### 队列与校准

实际68对、13名音频说话人，同一动态源脸；6条词表外文本在输出前排除。26条校准、42条评估，全部视频质检通过，D辅助子集评估仅6条/2说话人。统计为说话人等权，20,000次bootstrap，seed20260926；下列区间为95%，原始JSON还保存99%。纯视觉模型CMLR_V_WER8.0，不输入音轨，不使用LM beam decoder；官方嘴部预处理，去音轨前后帧hash/PTS一致。

N内容校准通过：正确文本对5个固定错文本strict top1=22/26，Q>0为23/26；动态Q=1.328 [1.010,1.660]，native−reversed=1.421 [1.075,1.774]。N已知320ms延迟中位响应比1.002，正/负240ms局部误差比分别0.386/0.327，通过固定门。正向局部门21/26优于零响应，接近80%阈值，不能夸大校准强度。事后T/M相同26条时间扰动也全部通过。

### 独立视觉内容与时间端点

| 42条评估比较 | 说话人等权差 | 95% CI |
|:--|--:|:--|
| 原生T−N 动态内容Q，nats/字 | +0.716 | [+0.435,+0.999] |
| 原生T−N 原始margin | +0.736 | [+0.424,+1.035] |
| 同帧数T−N 动态内容Q | +0.190 | [−0.114,+0.512] |
| 原生优势减去同帧数优势Q，事后交互 | +0.525 | [+0.374,+0.683] |
| M−N 动态内容Q | +0.274 | [+0.008,+0.530] |
| M−N 原始margin | +0.297 | [−0.013,+0.563] |
| M−N 自然MFA局部时间误差，ms | −13.268 | [−60.778,+20.268] |

Q=M(native)−M(frozen)，M为错文本平均归一化CTC NLL减正确文本NLL；不等同Sync-C。T原生greedy CER下降12.7个百分点，同帧数后仍下降7.7个百分点，所以不能说全部内容优势随时长匹配消失。但N/T绝对CER约120.7%/108.0%（插入可超过100%），不是可用识字精度或逐字视觉真值。M的CER反而增加11.9个百分点，Q的99%区间跨零，原始margin/时间误差也不确认改善，故M没有一致的独立收益证据。D仅2名评估说话人，不作稳定跨来源推断。

T内容Q增益与同ID原生PCM Sync-C增益，在13说话人均值上的Spearman为−0.412，95% CI[−0.845,+0.169]，置换p=0.162；M为+0.088，p=0.780。均属事后探索，未证明视觉内容增益解释Sync-C增益。

### 直接原生T视频迁移：绕过音频声码器

固定同一自然PCM，N经identity无损处理；42条评估集，guard20：

| 原生T视频重定时方法，相对N视频 | ΔSync-C | 95% CI |
|:--|--:|:--|
| 均匀变速 | −4.374 | [−4.923,−3.853] |
| 音频MFA字中心 | −0.994 | [−1.260,−0.741] |
| 视觉CTC字符中心 | −3.501 | [−4.097,−2.915] |

MFA相对均匀变速救回+3.380 [2.819,3.906]，但未超过自然驱动。全68条分别−4.428/−0.971/−3.392；guard0/15/20方向一致。失败不只存在于MFA-linear特征映射/声码器路径。

事后处理损伤对照：42条N视频先逆映射至T网格再正映射回N网格，MFA往返+0.039 [−0.008,+0.087]，视觉往返−0.058 [−0.202,+0.041]。没有主迁移量级的插值损伤；但两次插值不等于T单次插值，不能当严格反事实调整或解释百分比。

事后音素粒度敏感性：评估集38条、13说话人同音素序列。T音素中心重定时−0.561 [−0.774,−0.352]，音素起止边界重定时−0.573 [−0.798,−0.351]；音素中心较同38条字中心MFA改善+0.381 [0.215,0.562]。粒度有实质影响，仍未转为自然音频同步收益。4条phones错序预先排除，不能把38条结果冒充全42条主比较。

### 更新后的研究判断与停止边界

1. 支持“已经测试的TTS视频迁移方法不能增强自然音频同步”，且证据比只测试MFA-linear强：已绕过声码器，控制插值损伤，细化到音素中心/边界。
2. 不支持强版本“视频没有额外视觉信息”或“全部只是SyncNet偏好”：纯视觉动态内容端点有原生T优势；但内容可辨识性不是自然音频同步或人类感知质量。
3. 时间组织很重要：等帧数使内容优势显著缩小；字/音素级局部对齐比均匀变速强。不过播放速度、插值与VSR时间尺度偏好同时变化，不能声称已识别纯语速机制或精确解释占比。
4. 已知变形响应通过不等于跨臂绝对视觉时刻正确。CTC锚点迁移差不能反过来单凭SyncNet证明CTC错误；它说明当前锚点方案没有实用同步收益。
5. 与前两轮合并：Ditto旧队列有强评价编码混杂；Wav2Lip无损后保留具体配对优势，并有独立视觉可辨识性迹象，但自然时钟迁移未成功。剩余生成动态/评价器偏好尚未唯一分解。
6. 本轮完成现有队列的高辨识度自动对照，不再继续按分数搜索warp或追加近似指标。下一阶段应是预先固定的新源脸/TFG确认或跨臂绝对视觉时间标尺；无需把人工评审当作继续研究的唯一入口。没有宣称不存在其他迁移算法。
