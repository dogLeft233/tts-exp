# 新来源跨生成器与视觉验证 2026-09-10

按用户要求结合9月10日最新审计设计四个共享输入，并在服务器上按 spec 执行 P→A/B/C/D 的可审计流程。科学队列因新来源硬门禁阻塞，未宣称收益或阴性。入口为 `openspec/fresh-source-replacement-20260910.md`，完整契约在 `openspec/changes/probe-fresh-source-cross-generator/`。

Phone-core、参考交互和视觉动态均未建立新收益；旧视觉反转敏感性已通过。旧局部时间传递在评分敏感但生成响应未解决的情况下，不能直接归结为模型无时序控制。本轮转换为新source groups、跨生成器和独立视觉证据。

## 设计

A：固定direct重合成在Wav2Lip/Ditto上的自然音轨收益；C/direct同时作为D的解码处理对照。B：真实轨迹校准、动态/静态分解、缺失界限与两名人类评审的盲评。C：无插值整帧音频延迟是否产生相应嘴部响应，区分评分器shift控制与真正生成干预。D：测量/资产/预算门槛通过后，使用自克隆TTS的MFA-linear自然时钟候选，分别检验M−N和M−direct。

冻结12组，每组完整6–10秒，静态同参考图、前140帧统一媒体、原自然PCM评分。新来源需排除全部历史和封存source groups；设计期仅查了原始tar成员与既有池，未完成全部历史去重、质量筛选或实际cohort冻结。第一阶段128视频/124正式评分；D追加50/48；全套178/172，另最多8次工程重试。两小时GPU总墙钟，预算不足留断点关机，不扩容。先P/A/B并行开发，P后调度C，最多3worker+主agent；A统一执行生成。
