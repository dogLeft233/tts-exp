## Observations

- [status] concluded；仅CPU，GPU=0；仅父谱校准52原PCM，不读取eval波形或新分数；26对/260波形全部门与独立复核PASS。
- [result] 原T/N RMS差中位+8.767 dB、均值+7.772 dB，25/26 T更响；N增益中位+4.384 dB，T−4.384 dB，mcap触发0/26。LEVEL保存后两臂RMS最大相对误差1.169e−9，除g重构最大误差1.796e−8。float64谱形/R RMS最大差1.997e−12/3.553e−15 dB。
- [result] 原mean-log谱差中位10.029 dB；LEVEL 2.376、EQ 10.191、EQ_LEVEL 2.404 dB；去常数谱形差原/LEVEL 1.927，EQ/EQ_LEVEL 0.852 dB。52/52重构float64 EQ转FLOAT32与父pre_headroom逐样本一致。
- [conclusion] 全局电平及EQ组合操纵成立，归一化波形、相对floor谱形与R保持；绝对包络随增益变化，下游固定floor/非线性仍可能响应。RMS匹配不等同mean-log谱相等。本cal无SyncNet机制结论，等待root冻结后续GPU方案。
- [provenance] 协议SHA256 eb614be56487f80bf463bda948be7f6bc25cfc0b6fb27eac43afe60bd0ba434f；报告SHA256 08180a529df608b64ac69b922120583702d5de460a92d7bb534efb018a2f9155；独立实现不import主/父变换，重构误差4.441e−16；completion_hashes绑定535产物。
- [question] 当前Wav2Lip/cloud实验的原N/T电平差尚不能由历史Ditto/本地Qwen n10阴性排除；构造LEVEL和EQ_LEVEL以独立控制全局RMS。
- [protocol] r=sqrt(mean(x²))，m0=sqrt(rN*rT)，mcap=min(.98*rN/pN,.98*rT/pT,.98*rN/pEQ_N,.98*rT/pEQ_T)，m=min(m0,mcap)，处理增益g=m/r_arm。EQ直接调用父cal封存float64变换并恢复原臂RMS。RAW保留原PCM，identity直接PCM/32768→float32，LEVEL=x*g，EQ_LEVEL=EQ*g；baseline不缩放。
- [gates] 全部finite/同长度/无clip；identity保存与原PCM/32768逐样本一致；LEVEL及EQ_LEVEL两臂RMS匹配且各自达到m相对误差≤1e−5；除g恢复原x或EQ保存精度max误差≤1e−7；float64 cosine误差≤1e−10；平滑去常数mean-log谱形及R RMS最大差≤1e−8。float32不变量另报。静音r≤1e−8阻止评分，保留全部样本。协议计算前封存。
- [scope] 这是配对N/T测试时电平匹配，不是可部署单输入模型；不运行ASR/SyncNet/TFG，不按分数选择。
