## 问题与设计

在相同全局RMS与总样本数下，分解自然语音与TTS的局部时序、动态谱包络和声源轨迹的联合效应。上一轮实际共同T短时长的原配差约 +0.164 Sync-C；本轮不再以原来不同总长的 +0.254 为直接母基线。

以均匀变速母实验 N_WARP 和 T_ID 为两来源，全部输出16k mono FLOAT、相同nT、相同RMS=0.0376838172675746。8角因素C=局部clock、P=完整WORLD SP（含动态能量）、E=F0+AP。两来源exact known-phone中心用同一SequenceMatcher匹配，0/end及中心组成全域连续可逆映射；无recipient参数回退。未匹配、停顿、未知区通过连续插值纳入，C不能称纯phone时长。

26cal只做技术和操纵检查；74eval全部保留，正式common71/15speaker，实际生成592视频。每pair 8自配＋12边各2个交叉角=32矩阵，保留raw/unit与guard20/valid/guard0/guard15。CPU/GPU执行和独审由GPT-6 Sol high agents负责。
