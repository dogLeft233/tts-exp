# 电平生成效应的独立视觉内容校准 2026-09-27

使用冻结 CMLR encoder+CTC，对已封存 image3 生成的 N/T × RAW/LEVEL 视频完成 26cal 和 66eval 纯视觉内容验证。全部独立像素、CTC 与统计复核通过。自然臂内容改善未达到预设 Q/M 的 99% 合取标准；不证明效应为零。旧动态 512 视频的校准未转用到本次 224 固定 ROI。

## Observations

- [status] concluded
- [question] 全局电平均衡的生成端 Sync-C 效应是否伴随不读取音频的视觉内容辨识改善？
- [design] 父 26cal/74eval 不变；文本词表预评分排除 8 个 eval OOV 后 66eval/15 音频说话人，正式无 QC 缺失。OOV：a1_005（踝）、a1_015（榨）、a1_065（霆）、a1_071（呕）、a1_081（吗）、a1_082（掠）、a1_083（侣）、a1_090（寝）。全部 26cal/13 说话人可用，旧 68 文本为固定 decoy 池，旧 26cal 的目标与 5 错文本逐项复现；四格同 clip 候选相同。不与 SyncNet common71 混为同支持，不按分数删样。
- [calibration] 固定 N_RAW gate：strict top1≥0.60，Q>0 比例≥0.70，Q 和 native−reverse 的 speaker bootstrap95%CI 下界均>0，26cal 工程 QC 必须完整；失败记录测量无解释力，不放宽门、不换预处理。其它三格同门完整诊断。
- [metric] M 为 5 错文本平均 per-char CTC NLL 减正确文本 NLL；Q=Mnative−Mfrozen。固定 ΔN、ΔT 及 ΔT−ΔN、同支持 native gap；主自然臂改善需 Q 及原始 M 的 99%CI 同时正，CER/NLL 辅助。各臂 RAW/LEVEL 帧数与时间戳完全相同；N/T 原生时长未配平。逐句配对、说话人内平均后等权，20,000 speaker bootstrap，seed20260926，全部 54 组统计及 95%/99%CI 报告。
- [provenance] 已核验 400 视频 hash、无音轨 25fps/FFV1/224×224 与 200 组帧数相等；文本表 200 个源音频 hash 与父协议逐项一致。模型及配置哈希仍匹配，AVSR commit84c148a；当前源为单静态 image3 的固定 224 ROI，与旧 512 动态脸前端输入不同，故重新校准。
- [independence] 模型评分不读取音频波形、SyncNet 特征/权重/分数，不使用人眼判断；CMLR encoder+CTC 无 LM/beam 解码（官方 pipeline 初始化过 LM 资产但未用于评分）。已保存视频继承 SyncNet 预设 ROI 几何，因此不能宣称整个前处理独立。
- [storage] full-softmax 后保存目标/错文本/blank 列且不重归一化，另存全词表 greedy IDs/full-logp hash；首 cal 四格完整 native logp 及重复前向用于独立验证，无完整 crop tensor 缓存。两个视觉 run 合计 49.85MiB，低于 150MiB；封存磁盘余量 5.321GiB，GPU 已全部释放并交接。
- [calibration-result] 26cal 主 N_RAW 门 PASS：top1=16/26、Q>0=24/26，Q=1.718 [1.251,2.228]、native−reverse=1.767 [1.315,2.271]（95%CI）；N_LEVEL 辅助门 top1=15/26 未过，Q/reverse 仍正；T_RAW/T_LEVEL 门通过。N_RAW 仅刚过门，N_LEVEL 诊断失败并列保留，不能将 cal 差异用于处理效应推断。
- [result] 自然 ΔQ=+0.031992，95%CI[−0.025682,+0.097053]、99%CI[−0.039964,+0.117891]；自然 ΔM=+0.040186，95%CI[−0.017734,+0.101356]、99%CI[−0.034313,+0.120389]。预设 99% Q/M 合取失败，连 95% 也均跨零。
- [result] ΔT−ΔN：Q=−0.020192，99%CI[−0.135034,+0.090523]；M=−0.027755，99%CI[−0.118525,+0.064162]。同 66 native T−N Q：RAW +0.504742 [0.132608,0.875975]、LEVEL +0.484550 [0.143176,0.826480]（99%CI），均仍正，但 N/T 时长未配平。
- [auxiliary] 自然 CER Δ+0.024914，99%CI[−0.009559,+0.068737]；正确文本 NLL Δ+0.082471，99%CI[−0.091819,+0.260972]，点估计方向不配合改善且区间跨零，不能称显著恶化。四格绝对 CER 约 105%–118%，相对内容判别不等于准确读唇。
- [conclusion] LEVEL 生成端 Sync-C 改善尚未取得独立视觉内容改善证据；不是证明内容效应为零。Native TTS 相对内容优势保留，但受原生时长混杂，不能作为物理口型时刻、人类感知或无条件质量真值；不跨视觉66/SyncNet71支持计算中介比例。
- [validation] 校准 104 视频/11970 帧、正式 264 视频/30784 帧均与封存 BGR 像素/实际模型 RGB 输入逐一 hash 相同。校准 1872CTC 独立递推 max7.106e−15；正式 4752CTC max8.882e−15。首 cal 完整/稀疏同误差，repeat full logp 误差0。全部54组统计独立重建 max3.331e−16，差中差代数通过；4项针对性 pytest 通过。
- [execution] 按冻结 N_RAW 主门经 root 批准正式 66eval；新特征前写 score_lock、完整输入/代码/索引 seal，未更换预处理、门或支持。正式协议 SHA256 81551e5b374844ebd222b094757739131dbb64955d9110258cd026c233ce07d6；最终 artifact_hashes.json 覆盖1244个文件，final.json 状态 concluded。
- [report] 正式报告 runs/tts_level_visual_calibration_20260927/evaluation/report.md；同目录 summary.json、scores.json、statistics.csv、independent_pixels.json、independent_statistics.json、artifact_hashes.json、final.json。校准报告 runs/tts_level_visual_calibration_20260927/report.md；输入审计/方案 runs/tts_level_visual_audit_20260927/。
- [limit] 单静态图/历史队列，15 音频说话人不是15人脸；N_LEVEL 校准辅助门失败；224 ROI 与旧512动态源不同；content gate 不保证绝对嘴型时刻、人类感知或 SyncNet 真实准确性。辅助/探索指标未作多重检验家族校正。
