# SyncNet 编码偏差的码率频谱与表征机制拆解 2026-09-26

用户授权自主探索并要求翔实结论及 BM 持久保存。续接已有47对Ditto及12个真实视频编码交换结果。

## 冻结设计

1. 沿用全部47对Ditto和全部12个LRS3真实视频，固定视频与源声音；不按新结果筛样。
2. 对源PCM实施 16/24 kHz × 24/32/64 kbps × 默认/7500 Hz截止频率 MP3全因子；补充原PCM及零相位低通3500/4500/5500/6500/7500 Hz。去延迟仅用波形互相关，不用评分优化。
3. 同视频所有条件使用共同窗口，主分析去首尾20窗。保存完整距离矩阵、特征、音轨和哈希。
4. 主要比较：固定码率后的采样率效应、固定采样率后的码率效应、固定码率下解除默认带宽限制的效应；低通是否独立复现损失。每个队列分别汇总，95%/99%配对bootstrap，不选择显著子集。
5. 拆解 Sync-C=B−D，检查峰位置及固定峰距离；表征诊断比较音频向量模长和方向，并构造原始/编码的模长×方向交换（仅解释评分器，不当作物理音频干预）。
6. 后续根据结果检查统一PCM下的跨域TTS剩余效应；任何新增分支先冻结协议再看结果。已有阳性数据参与探索不冒充预注册独立确认。
7. 每次GPU使用前检查其他进程与占用；有冲突则CPU。保护已有工作树改动。

## 自适应后续设计（已执行）

- 主实验提示高频及剩余失真后，先冻结 mel_patch/protocol.json，再对全部106条视频执行7条件输入特征干预；最高3个Mel频带中心为5875/6519/7225 Hz。
- 特征干预阳性后，先冻结 band_swap/protocol.json，再执行5条件真实波形交换；以固定5.5 kHz互补滤波构造修复高频、损伤高频及RMS控制，不移动发音时间。
- 均为探索性因果定位；同一队列复用不冒充未见来源确认，内部特征替换和物理波形干预分别报告。
- 跨域真实视频响应已复核；英文原始TTS驱动WAV的完整来源链未获得，因此不把已压缩载体当作源音估计英文TTS剩余效应。

## Observations
- [status] concluded
- [question] 编码偏差主要由码率引发的频带截断、其他压缩失真、表征模长变化或对齐改变中的哪些路径产生？
- [result] 106条固定视频：18条件全因子/低通，7条件log-mel干预，5条件真实波形交换；3180次正常端点评分（含重放），另5724次表征诊断。不以评分次数作独立样本量。
- [result] 默认16k/24 kbps相对源PCM损失：自然−1.045、TTS−0.848、真实视频−1.097；固定16k升至32 kbps分别恢复+0.926、+0.784、+0.924。固定32/64 kbps后16/24k差异小。
- [mechanism] LAME自动低通随码率变化；24 kbps单声道名义截止约5850 Hz；实测6.5–7.5 kHz功率损失约47–49 dB。固定24 kbps放宽cutoff至7500 Hz能部分恢复，仍有高频带内压缩失真。
- [result] 仅PCM低通5.5k、无MP3/无时移：自然−0.901、TTS−0.712、真实视频−0.995；低通7.5k时损失很小。
- [result] 仅恢复最高3个log-mel频带：自然+0.967 [95%CI +0.847,+1.088]，TTS+0.829 [+0.682,+0.976]，真实视频+0.889 [+0.619,+1.209]；只恢复低频/能量救回很少，反向高频损伤显著降分。
- [result] 真实波形补回5.5k以上原音高频：自然+0.947 [+0.826,+1.070]（47/47正），TTS+0.815 [+0.652,+0.980]（45/47正），真实视频+0.940 [+0.684,+1.250]（12/12正）。
- [result] 上述修复分别回收编码损失90.7%、96.1%、85.7%；比例仅针对同声音编码损失，不是TTS总效应归因百分比。只恢复RMS分别+0.053、+0.063、+0.017。
- [mechanism] C=B−D：低码率既降低背景距离B，又增大最佳距离D；102/106最佳偏移不变。音频embedding模长/方向均参与，指定坐标Shapley分解方向贡献更大；单位范数后仍有编码损失。
- [conclusion] 本批原生TTS高分的重要混杂已定位到评价编码造成的高频损伤；证据优先支持测量链解释。不能据此认为生成了更准确嘴型。
- [constraint] Ditto单说话人47对，真实视频12来源；统一PCM后TTS−自然仍为+0.287 [−0.090,+0.648]，不能宣称零真实优势。没有新TFG生成或自然时间轴迁移，也没有人工盲评。
- [validation] 独立复算8904评分、4452哈希、177444距离元素、174个95%bootstrap区间，PASS；评分误差0，距离误差3.81e−06。新源码Ruff通过。三个CUDA阶段均通过空闲检查，结束后GPU空闲。
- [report] [完整报告]([redacted-local-path])；同目录summary.png/pdf、score_table.csv、所有协议/特征/原始矩阵/validation.json及provenance。
- [decision] 先以原始WAV与显式无损音轨重新确认阳性，再开展TTS发音动态和自然音频迁移机制研究。已压缩音轨转WAV不能恢复损坏。
