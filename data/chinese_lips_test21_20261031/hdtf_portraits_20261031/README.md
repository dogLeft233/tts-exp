# HDTF 参考人像分配

105条目标音频／21个音频说话人，20张HDTF人物图片；每位音频说话人的5句固定同一张人像，之后自然音频与TTS配对也应保持同图。

当前项目已有的20人子集含19男1女；女性人像ReneeEllmers用于中文音频说话人019和024，其他19张各分配一次，其余分配按seed 20261031固定随机顺序，不依据生成或同步分数。该子集未证实为模型官方测试集，HDTF是一些TFG模型的训练来源。跨身份配对不是同人真值。

AllenWest图取已有片段seg1的2秒处以避开闭眼，其余取诊断集已有的seg1图片。原始图片、时间、SHA等见assignments.json。音频来自上级manifest_release；13条源音频存在饱和。尚未执行模型人脸检测、TTS或生成。index.html浏览全部分配。
